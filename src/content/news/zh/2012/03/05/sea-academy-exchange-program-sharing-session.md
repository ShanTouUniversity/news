据悉，汕头大学学生处近日发布通知，将于2012年3月9日（星期五）晚上7:30在E阶203课室举行"海上学府"、墨尔本大学和惠特曼学院交换生项目分享会。

分享会将邀请蔡思颀、陈晨和叶梓健三位同学与大家分享他们在海外交流学习期间的学习经历和体会，并现场传授面试经验。

欢迎有兴趣的同学参加。

| 项目 | 内容 |
|------|------|
| 分享会主题 | "海上学府"、墨尔本大学和惠特曼学院交换生项目 |
| 分享时间 | 2012年3月9日（星期五）19:30 |
| 分享地点 | E阶203课室 |
| 分享嘉宾 | 蔡思颀、陈晨、叶梓健 |
| 发布单位 | 学生处 |
