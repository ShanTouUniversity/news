据悉，汕头大学学生处近日发布通知，2011—2012学年国家开发银行生源地信用助学贷款已全部发放，共68名同学获得放款。

请已获得国家开发银行生源地信用助学贷款的同学登录学生缴费信息查询系统查询个人缴费情况，并及时到财务处缴纳所欠余额。如对支付宝贷款账户有疑问，可查阅附件中的"助学贷款支付宝使用说明及相关问题汇总"。

| 项目 | 内容 |
|------|------|
| 贷款银行 | 国家开发银行 |
| 学年 | 2011—2012学年 |
| 放款人数 | 68人 |
| 缴费查询 | http://cwc.stu.edu.cn/StudentChargeQuery/frmStuentChargeQuery.aspx |
| 发布单位 | 学生处 |
