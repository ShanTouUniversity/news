据悉，2011 年度高校图书资料统计工作已经启动。为推进此项工作的开展，汕头大学图书馆于 3 月 5 日向校本部各资料室发出工作安排。

根据安排，各资料室须按照附件表格的要求填写本室图书资料数据，并在 3 月 15 日前将填妥的表格发送至图书馆指定邮箱 gnweng@stu.edu.cn，由图书馆统一汇总上报。

| 项目 | 内容 |
| ---- | ---- |
| 工作内容 | 2011 年度高校图书资料统计 |
| 涉及单位 | 校本部各资料室 |
| 填报要求 | 按附件表格填写数据 |
| 截止时间 | 3 月 15 日前 |
| 提交方式 | 发送至图书馆指定邮箱 |

此次统计是广东省高校图书资料年度统计工作的一部分，相关表格可在图书馆处获取。

> 来源：汕头大学 OA 通知（图书馆）
