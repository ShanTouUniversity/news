据悉，汕头大学教务处近日发布通知，因生物系黄冰心老师参加学校举办的三八妇女节教职工活动，原定于第2周周三（3月7日）AB节在E座203教室开设的《生物史话与生命奥秘》（开课班号：51729）上课时间推迟至BC节，地点不变。

请修读该课程的同学相互告知。

| 项目 | 内容 |
|------|------|
| 课程名称 | 生物史话与生命奥秘 |
| 开课班号 | 51729 |
| 原上课时间 | 第2周周三 AB节 |
| 调整后时间 | 第2周周三 BC节 |
| 上课地点 | E座203教室（不变） |
| 发布单位 | 教务处 |
