据悉，汕头大学文学院将于今年迎来第十一届原创戏剧晚会。经评委严格审核，在剧本征集大赛中获一等奖的作品《麦田里的红裙子》被确定为本届晚会演出剧本，剧组现面向全校公开招募演员。

文学院的原创戏剧活动已有十年历史。过去十年间，文学院先后为汕大师生呈现了《黑杰克的第三十一步阶梯》等十场戏剧作品，"文学院原创戏剧"品牌逐渐获得师生认可，也吸引了众多校园戏剧爱好者参与。

本次招募的具体安排如下：

| 项目 | 安排 |
| ---- | ---- |
| 招募对象 | 全校本科生及研究生，文学院学生及有戏剧、舞台经验者优先 |
| 报名时间 | 即日起至 3 月 23 日 22:00 |
| 报名方式 | 提交纸质报名表或电子报名表 |
| 面试时间 | 3 月 24 日（星期六）上午 9:00–11:00，下午 14:00–17:00 |
| 面试地点 | D 座教学楼 D403、D404 |

纸质报名表可交至钟WJ、黄CF、陈ZJ、孙W、范JW 处；电子报名表可发送至组委会邮箱。报名表及剧本简介可通过文学院获取。
