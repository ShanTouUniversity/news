据悉，学生处于3月23日发布通知，2011—2012学年第三批国家助学贷款合同签订工作安排公布。

接中国银行汕头分行通知，合同签订定于2012年3月27日15:00在E阶梯101教室举行。

## 安排

| 事项 | 内容 |
| --- | --- |
| 时间 | 2012年3月27日15:00 |
| 地点 | E阶梯101教室 |
| 对象 | 附件名单中的相关同学 |
| 所需材料 | 身份证、学生证、中行借记卡或借贷合一卡、黑色钢笔等 |
| 要求 | 提前15分钟到场核对合同、借据等资料 |
| 咨询电话 | 0754-82904749（助学工作管理中心） |
| 发布单位 | 学生处 |

签订名单见 OA 附件，为保护学生隐私本文不转载。

> ⚠️ 签订名单请前往 OA 系统查看原文附件。
