据悉，汕头大学学生处近日发布通知，为节约公共资源、实现资源循环利用，决定开展"绿色接力"单车循环计划，在全校范围内收集旧单车，修整一新后以免费出借的方式重新投入使用。

报名从3月14日至20日。有意捐献单车的同学请将姓名、学号、宿舍号、电子邮箱、手机号码及合适的上门回收时间发送至 11zjli1@stu.edu.cn 或拨打 675507。活动由至诚书院学生会、学生宿舍自我管理委员会承办。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 活动主题 | "绿色接力"单车捐献回收计划 |
| 目的 | 节约公共资源，实现资源循环利用 |
| 报名方式 | 发送个人信息至 11zjli1@stu.edu.cn 或致电 675507 |
| 报名所需信息 | 姓名、学号、宿舍号、电子邮箱、手机号码、上门回收时间 |
| 报名时间 | 3月14日至20日 |
| 承办方 | 至诚书院学生会、学生宿舍自我管理委员会 |
| 咨询电话 | 黎同学 675507 |
