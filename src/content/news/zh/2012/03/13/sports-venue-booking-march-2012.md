据悉，汕头大学体育部近日发布通知，新学期开始，网球场、体育馆内羽毛球场、体育馆内篮球场在满足体育课教学、运动队训练的基础上，即日起向全校师生开放预订。

预订需至少提前一天发邮件至 o_tyb@stu.edu.cn，缴费方式仅限于刷一卡通和校内转账。从本周起，每周三晚7:00—9:00体育馆内场地向教职工免费开放，不对外预订。体育场馆内严禁吸烟。

## 场馆预订信息

| 事项 | 内容 |
| --- | --- |
| 开放场馆 | 网球场、体育馆羽毛球场地、体育馆篮球场地 |
| 开放对象 | 全校师生 |
| 预订要求 | 至少提前一天发送邮件至预订邮箱 |
| 缴费方式 | 一卡通刷卡或校内转账 |
| 教职工福利 | 每周三19:00—21:00体育馆内场地免费开放 |
| 注意事项 | 场馆内严禁吸烟 |
| 预订邮箱 | o_tyb@stu.edu.cn |

> 来源：汕头大学 OA 通知（体育部）
