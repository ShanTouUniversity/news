据悉，汕头大学党委组织统战部近日发布通知，根据相关规定，处级以上领导干部须集中报告2012年个人有关事项。

学校要求副处级以上干部到组织统战部（行东405）领取《领导干部个人有关事项报告表》，以首次报告的形式如实、详细填报，不能简单填写"无变化"。报告表须由本人亲笔填写，用C4号信封密封并签名，于3月30日前交组织统战部。

## 报告安排

| 事项 | 内容 |
| --- | --- |
| 报告对象 | 学校副处级以上干部 |
| 领取地点 | 组织统战部（行东405） |
| 报告形式 | 首次报告，须如实详细填报 |
| 提交要求 | 本人亲笔填写，C4号信封密封并签名 |
| 截止日期 | 2012年3月30日 |

> 来源：汕头大学 OA 通知（党委组织统战部）
