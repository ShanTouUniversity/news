据悉，汕头大学资源管理处近日发布通知，2012年第二季度设备采购计划已开始申报。各单位须于2012年4月6日前以书面和电子文档形式报设备及物资管理办公室（原接待室）。

逾期报送者将延至2012年第三季度处理。计划填写需注意以下事项：2万元以内的设备只需填写《计划表》；2万元以上须填写《计划表》和《计划书》，并按审批权限报批；单价10万元以上的设备须填写《大型设备购置可行性报告书》；购置计算机须填写《申请购买计算机登记表》；购置空调须在备注栏注明安装地点及原有空调状况。

联系人：黄老师，电话82902558，邮箱zxhuang@stu.edu.cn。

## 申购注意事项

| 项目 | 要求 |
| --- | --- |
| 截止日期 | 2012年4月6日 |
| 申报方式 | 书面及电子文档 |
| 2万元以内设备 | 仅填写《计划表》 |
| 2万元以上设备 | 填写《计划表》和《计划书》，按审批权限报批 |
| 单价10万元以上设备 | 须填写《大型设备购置可行性报告书》 |
| 购置计算机 | 须填写《申请购买计算机登记表》 |
| 购置空调 | 备注栏注明安装地点及原有空调状况 |

> 来源：汕头大学 OA 通知（资源管理处）
