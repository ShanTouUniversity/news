据悉，汕头大学资源管理处近日发布通知，为改善校园环境及加强植物病虫害防治，将于3月25日至4月1日在校区（含龙泉园、成教学院）的绿地花木、果树及水沟进行喷药作业。

具体时间安排如下：

| 日期 | 喷药区域 |
|------|---------|
| 3月25日 | 附中、附小至精神卫生中心 |
| 3月26日 | 人工湖区域、运动场 |
| 3月27日 | 学术交流中心周围、P楼、学生宿舍区 |
| 3月28日 | 水库坝、789号楼、A-B教工宿舍区 |
| 3月29日 | 医科楼、新教学楼、G、H、I、J座学生宿舍 |
| 3月30日 | 校卫队办公场地周边、校门口、各校道、新图书馆外围 |
| 3月31日 | 食堂、行政楼周围 |
| 4月1日 | 龙泉园、成教学院 |

据悉，学校提醒广大师生员工注意喷药期间的个人安全，避免靠近作业区域。

> 来源：汕头大学 OA 通知（资源管理处）
