据悉，汕头大学资源管理处近日公布2012年1月份及寒假期间学生宿舍水电费。

1月份计量时间为1月1日至1月18日。寒假期间分两个时间段分别于2月7日和2月23日进行抄表。请同学们登录汕头大学水电费管理系统（http://power.stu.edu.cn/）进行查询，账号为各自校园网账号。如发现有错漏或有不清楚的地方，请填写《水电费核查申请表》并签名，于3月2日—8日上班时间交到水电中心（地址：科技楼旁，电话：2489）。如有所住宿舍与学生名单不符，请与辅导员办公室联系。期满未有异议，3月9日开始，将由网络中心通过一卡通扣缴。本次正常缴费时间为3月9日至13日。

| 项目 | 内容 |
|------|------|
| 查询时间 | 1月1日—1月18日 |
| 寒假抄表 | 2月7日、2月23日 |
| 异议截止 | 3月8日 |
| 扣缴时间 | 3月9日起 |
| 缴费时间 | 3月9日—13日 |
| 查询系统 | http://power.stu.edu.cn/ |
| 发布单位 | 资源管理处 |

> 来源：汕头大学 OA 通知（资源管理处）
