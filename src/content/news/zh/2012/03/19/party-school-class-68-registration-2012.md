据悉，党委组织统战部于3月19日发布通知，第六十八期“党的基本知识学习班”定于3月25日开学。

## 报到与学习安排

| 事项 | 内容 |
| --- | --- |
| 开学时间 | 2012年3月25日 |
| 领取通知书 | 请各党总支、直属党支部于3月20日前派员领取《入学通知书》 |
| 报到时间 | 3月23日13:30—17:00（中午照常办理） |
| 报到地点 | 党校办公室（行政楼东401） |
| 报到材料 | 党校录取通知书、一寸正面免冠照片一张（背面写明单位及姓名） |
| 小组长会议 | 3月23日21:00，行东311会议室 |
| 请假要求 | 确需请假者填写《党校学员请假审批表》，经党总支或团委审批后到党校办公室办理；无故缺课、缺考者取消资格 |
| 发布单位 | 中共汕头大学委员会党校、党委组织统战部 |

课程表、学员名单、请假审批表及学员守则等见 OA 附件。
