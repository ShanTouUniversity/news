据悉，汕头大学研究生学院近日发布通知，方正集团珠海PCB研究院将于2012年3月7日（周三）下午2:00—5:30在G301面向全校研究生举办专场宣讲会。

除了招聘简章中提及的信号类专业之外，该研究院还需要材料、化学和电子等专业研究生。欢迎相关专业或有志于从事该行业的研究生届时前往参与，现场接受简历并面试、录用。

| 项目 | 内容 |
|------|------|
| 招聘单位 | 方正集团珠海PCB研究院 |
| 宣讲时间 | 2012年3月7日（周三）14:00—17:30 |
| 宣讲地点 | G301 |
| 招聘岗位 | 信号类、材料、化学、电子等专业研究生 |
| 发布单位 | 研究生学院 |
