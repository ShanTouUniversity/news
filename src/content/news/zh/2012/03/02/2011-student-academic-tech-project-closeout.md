据悉，汕头大学共青团委员会近日发布通知，就2011年度学生课外学术科技立项工作总结及收尾工作进行部署。

自2011年度学生课外学术科技立项工作开展以来，各单位按照学校有关规定和要求开展了各项工作，共有181个项目通过立项，获得学校经费支持，其中154个项目通过中期审核。

校团委要求各相关单位及个人做好以下工作：

1. 各项目负责人按照所属学院要求认真做好收尾工作，按规定提交总结报告，由学院汇总并填写项目汇总表，提交学校备案；
2. 各院于3月16日之前完成终期评审并向校团委提交评审结果；
3. 各学院及时做好经费报销工作，于2012年4月1日前完成经费报销；
4. 各学院团委编制经费使用明细报表及效益评估报告，并完成2011年度学生课外学术科技立项工作总结，于2012年4月5日之前提交至校团委办公室。

| 项目 | 内容 |
|------|------|
| 立项总数 | 181个项目 |
| 通过中期审核 | 154个项目 |
| 终期评审截止 | 2012年3月16日 |
| 经费报销截止 | 2012年4月1日 |
| 工作总结提交 | 2012年4月5日 |
| 发布单位 | 共青团汕头大学委员会 |

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
