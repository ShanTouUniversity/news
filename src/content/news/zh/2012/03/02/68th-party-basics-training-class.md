据悉，汕头大学党委组织统战部近日发布通知，第六十八期党的基本知识学习班拟于3月份开学。

各单位须做好推荐初审和上报工作。各单位报送的学员，必须是递交入党申请书一年以上被列为重点培养对象的申请人员。《报名表》经党总支或直属支部签署意见并加盖公章后，于2012年3月15日前统一报党校办公室（行东401），同时将"学员名单汇总表"发Email至o_dxb@stu.edu.cn。经党校办公室复查后发出录取通知书。

| 项目 | 内容 |
|------|------|
| 班次 | 第六十八期 |
| 开学时间 | 2012年3月 |
| 报名截止 | 2012年3月15日 |
| 报送地点 | 行东401（党校办公室） |
| 报名邮箱 | o_dxb@stu.edu.cn |
| 发布单位 | 党委组织统战部 |
