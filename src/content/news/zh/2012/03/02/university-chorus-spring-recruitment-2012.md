据悉，汕头大学校合唱团近日发布2012年春季招新通告，面向全校学生招募新团员。

面试对象：全校学生，无需特殊音乐基础和乐器要求，有歌唱兴趣即可。

面试时间：2012年3月10日（周六）9:00—12:00、14:00—16:00。

面试地点：艺术教育中心大楼101音乐排练厅。

面试内容：听音模唱或自选歌曲片段展示（自选歌曲不分曲目类型，有乐器专长者可携带乐器现场展示）。

报名方式：
方式一：3月9日中午12点前从附件中下载报名表，填写后发送至10jrliu@stu.edu.cn；
方式二：3月10日下午4点前到面试地点现场报名参加面试。

建议采取第一种报名方式以节省等候时间。

| 项目 | 内容 |
|------|------|
| 招募单位 | 汕头大学校合唱团 |
| 面试日期 | 2012年3月10日（周六） |
| 面试时间 | 9:00—12:00、14:00—16:00 |
| 面试地点 | 艺术教育中心大楼101音乐排练厅 |
| 报名截止 | 3月9日12:00（邮件）或3月10日16:00（现场） |
| 主办单位 | 长江艺术与设计学院、艺术教育中心 |
