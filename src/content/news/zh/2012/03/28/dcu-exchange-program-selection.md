据悉，汕头大学文学院与爱尔兰都柏林城市大学人文与社会科学院已就交换生项目初步达成4年学生交换计划协议：从2012年秋季学期开始，双方每学期各自挑选5名本科生，赴对方学校参加课程学习。

## 选拔安排

| 项目 | 内容 |
| ---- | ---- |
| 选拔名额 | 5名 |
| 选拔范围 | 文学院2010级、2011级全日制本科生（2012年9月起为大二或大三） |
| 报名截止 | 2012年4月25日上午11点 |
| 提交地点 | 文学院团委办公室（文科楼南201），电子版发送至指定邮箱 |

申请人需填写交换生项目申请表，并提供GPA及排名证明、英文水平证明复印件。选拔将首先由学院组成小组对书面材料进行初审，确定笔试人选。

## 交换条件

据介绍，交换生在本校正常交纳学费，都柏林城市大学免收交换生学费，但国际旅费及在国外期间的生活费、住宿费等需自理，大约每月支出700至900欧元（约合人民币6000元至8000元）。

## 选拔标准

学院公布的选拔标准包括：

- 学业成绩优异；
- 具备一定的经济条件；
- 具有较强的英语听、说、读、写能力；
- 心智成熟、独立性强、具有团队精神；
- 认可并善于对外宣传介绍汕头大学及其办学特色。

此外，该项目分为一学期和两学期两种，申请表中选择"or Both"即表示服从调剂，学院有权根据实际情况调整。

据文学院表示，这一合作将是学院本科学生海外学习计划的良好开端，对本科生毕业后继续深造有促进作用，并将进一步提升汕头大学的国际影响力。
