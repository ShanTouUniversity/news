据悉，汕头大学公布2012年新生入学教育相关活动的大礼堂座位安排，供各学院组织新生参加。安排涉及汕头大学介绍、英语提升计划介绍、学分制说明会、安全保密教育、校纪校规教育、图书馆入馆教育、党的基本知识讲座和名家讲座等8项迎新活动。

## 座位安排

附件显示，工学院、法学院、理学院、长江新闻与传播学院、商学院、文学院、长江艺术与设计学院和医学院共8个学院的新生座位已作分区安排，新生总数为1775人。

| 学院 | 新生人数 | 大礼堂座位 |
| --- | ---: | --- |
| 工学院 | 360 | 第1—9行；第10行1—32号 |
| 法学院 | 172 | 第10行33—43号；第11—13行；第14行1—26号 |
| 理学院 | 199 | 第14行27—47号；第15—17行；第18行1—37号 |
| 长江新闻与传播学院 | 164 | 第18行38—45号；第19—21行；第22行1—17号 |
| 商学院 | 254 | 第22行18—47号；第23—26行；第27行1—39号 |
| 文学院 | 158 | 第27行40—46号；第28—30行；第31行1—13号 |
| 长江艺术与设计学院 | 175 | 第31行14—38号；第32—34行；第35行1—6号 |
| 医学院 | 293 | 第35行7—48号；第36—40行；第41行1—21号 |
| **合计** | **1775** | |

各学院应按安排组织新生准时参加相关活动。开学典礼的座位安排将另行通知，详细座位区间请以 OA 附件为准。
