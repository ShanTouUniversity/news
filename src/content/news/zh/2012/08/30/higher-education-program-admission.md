据悉，为提高高校在职青年教师和管理人员的管理理论水平与科研能力，经广东省学位办批准，汕头大学高等教育科学研究所启动 2012 年高等教育学专业研究生课程进修班招生，即日起接受报名，限额录取。

该班下设教育原理、教育管理两个研究方向，课程学习年限为两年，采用面授与自学相结合的方式，周末或寒暑假上课。

**证书与学位通道**

学员学完全部课程且成绩合格后，可获汕头大学颁发的《研究生课程进修班结业证书》。据校方介绍，该证书由广东省学位委员会办公室统一印制，具有较高社会认可度，可作为具有研究生同等学力的凭证及部分单位评聘职称的参考依据。完成课程并通过同等学力申请硕士学位考试和毕业论文答辩者，还可获得国家正式认可的硕士学位证书（教育部统一监制、统一编号）。

**招生与收费概览**

| 项目 | 信息 |
| --- | --- |
| 专业方向 | 教育原理、教育管理 |
| 学习年限 | 两年 |
| 上课方式 | 面授+自学，周末或寒暑假 |
| 招生对象 | 本科毕业或具有同等学力的在职人员（需所在单位同意） |
| 课程费 | 每学年8000元，共16000元 |
| 报名地点 | 汕头大学高等教育科学研究所 |
| 咨询电话 | 0754-82902974、82903301（石老师） |

报名者需提交身份证、毕业证、学位证复印件各一份，以及近期免冠白底一寸彩照四张和同一底板电子照，并填写学员登记表。申请硕士学位的论文指导及答辩等费用另行按学校有关标准收取。
