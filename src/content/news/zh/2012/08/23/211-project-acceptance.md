据悉，汕头大学于2012年8月23日发布文件（汕大发[2012]101号），就"211工程"三期重点学科建设项目的校内验收阶段工作作出全面部署。此次验收依据广东省"211工程"协调小组办公室关于三期建设验收工作的通知要求开展。

在广东省政府、有关主管部门及李嘉诚基金会的支持下，学校"211工程"三期重点学科建设项目此前已取得积极进展。校方表示，本次验收既是对项目投资效益的最终检验，也关系到学校能否顺利进入"211工程"后续建设行列。

## 关键节点与分工

| 事项 | 安排 |
| ---- | ---- |
| 领导机制 | 在学校"211工程"三期建设项目验收领导小组统一领导下开展工作 |
| 总结报告初稿 | 各重点项目须于9月5日前提交 |
| 数据支撑 | 设备、基建、人事、财务等职能部门即刻整理汇总相关数据 |

## 各单位被要求全力配合

根据文件要求，验收工作组成员在安排好本单位日常工作的同时，需具体组织、协调、指导本单位的项目验收，按工作日程表完成任务。验收项目所在单位的主管领导须将验收作为近期重点工作，在人力、物力上给予项目组充分支持。

此外，验收期间各单位应在保证教学科研正常秩序的前提下，尽量减少与验收无关的活动，一般不安排项目组人员外出。
