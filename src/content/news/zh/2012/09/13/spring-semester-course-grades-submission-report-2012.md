据悉，汕头大学教务处对2012年春季学期课程成绩提交情况进行检查。检查显示，绝大部分任课教师已通过学分制系统提交课程成绩；文学院基督教研究中心开设的“死亡与不朽：东西方哲学及宗教传统的探索”课程，在院系工作人员和领导多次提醒后仍未提交成绩。

该课程开课班号为52185。根据《汕头大学本科教学事故认定办法（试行）》相关规定，考试结束后未按要求录入或上报成绩，经提醒五天后仍未提交的，构成一般教学事故。教务处据此对该情况予以通报，并提醒各教学单位和任课教师遵守课程考核管理规定，维护正常教学秩序。

## 通报信息

| 项目 | 内容 |
| --- | --- |
| 学期 | 2012年春季学期 |
| 未提交课程 | “死亡与不朽：东西方哲学及宗教传统的探索” |
| 开课单位 | 文学院基督教研究中心 |
| 开课班号 | 52185 |
| 检查结果 | 绝大部分课程成绩已提交 |
| 认定结果 | 未按规定提交成绩的行为构成一般教学事故 |
| 依据 | 《汕头大学课程考核管理办法》《汕头大学本科教学事故认定办法（试行）》 |

> 来源：汕头大学 OA 通知（教务处）
