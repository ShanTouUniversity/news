据悉，汕头大学根据汕头市委组织部《关于选拔第13批市优秀拔尖人才的通知》（汕组通〔2012〕54号），启动第13批汕头市优秀拔尖人才校内推荐工作。学校各单位应动员符合条件的人员申报，并按规定完成推荐。

## 推荐要求

| 项目 | 内容 |
| --- | --- |
| 报送截止时间 | 2012年9月26日 |
| 报送单位 | 校党委组织统战部 |
| 呈报表 | 《汕头市优秀拔尖人才呈报表》一式5份；“所在单位意见”无需填写和盖章 |
| 业绩证明 | 不超过800字，由所在单位撰写，涵盖政治思想、工作科研及获奖情况等 |
| 证明材料 | 学历、学位、专业技术资格、获奖及荣誉证书等复印件，以及主要科研成果证明材料 |
| 电子材料 | 发送至 o_zzb@stu.edu.cn |
| 联系人及电话 | 纪荣信，82902345 |

推荐材料须按统一表格规格使用A4纸双面打印，复印件也须使用A4纸。各单位审核复印件后，应由核实人签名并加盖公章；逾期不再受理。
