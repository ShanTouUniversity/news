据悉，汕头大学法律援助研究中心面向法学专业大二及以上学生招募未成年人犯罪背景调查员，以继续推进相关调查项目。调查员将接受龙湖区人民法院委托，开展背景调查、撰写调查报告并出庭宣读报告，同时参与中心值班、法律咨询和公益活动。

## 招募信息

| 项目 | 内容 |
| --- | --- |
| 招募对象 | 法学专业大二及以上学生 |
| 报名时间 | 2012年9月15日至20日 |
| 选拔方式 | 笔试和面试，择优录取，具体时间另行通知 |
| 报名材料 | 下载并填写附件报名表 |
| 提交邮箱 | laclaw@stu.edu.cn |
| 邮件主题 | 年级+姓名+调查员报名 |
| 咨询电话 | 0754-82903457 |

有意报名者须按要求提交报名表。报名表及相关附件可通过原通知获取。
