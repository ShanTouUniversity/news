据悉，党委组织统战部于9月17日发布通知，第七十期“党的基本知识学习班”拟于10月开学，请各党总支、直属党支部做好推荐初审和上报工作。

## 报名安排

| 事项 | 内容 |
| --- | --- |
| 拟开学时间 | 2012年10月 |
| 推荐对象 | 递交入党申请书一年以上并被列为重点培养对象的申请人员 |
| 报送要求 | 《报名表》经党总支或直属支部签署意见并加盖公章后，于2012年9月28日前统一报党校办公室（新行政中心315）；同时将《学员名单汇总表》发至 o_dxb@stu.edu.cn |
| 名额分配 | 见 OA 附件 |
| 审核录取 | 经党校办公室复查后发出录取通知书 |
| 发布单位 | 党委组织统战部 |

名额分配及报名表格等详见 OA 附件。

> ⚠️ 名额分配及报名表格请前往 OA 系统查看原文附件。
>
