据悉，学生处于9月17日发布通知，组织开展新桥伟助学金评选工作。

福建新桥伟鞋服有限公司今年在广东省设立该助学金，资助一本高校贫困新生完成学业。

## 资助安排

| 事项 | 内容 |
| --- | --- |
| 资助对象 | 品学兼优、家庭经济困难的2012级新生 |
| 资助名额 | 5名（全省共30名） |
| 资助标准 | 大学期间全额学费 + 每月500元生活费；学费于每年开学前汇至个人账户，生活费按月发放 |
| 申请材料 | 申请表及《汕头大学家庭经济情况调查表》复印件 |
| 学院推荐 | 各学院（书院）推荐2名候选人 |
| 申请截止 | 2012年9月20日17:00前向学院（书院）团委提交 |
| 学院报送截止 | 2012年9月25日12:00前报送推荐名单及材料至助学工作管理中心（行政中心106） |
| 发布单位 | 学生处 |

详情及申请表见 OA 附件。

> ⚠️ 申请表请前往 OA 系统查看原文附件。
>
