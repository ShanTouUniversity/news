据悉，汕头大学已启动2013年度预算编制工作，各单位须根据统一安排编制本单位预算，并将预算案提交主管校领导审查。预算编制时间为9月10日至10月22日，预算案须于10月22日前发送至 o_cwc@stu.edu.cn。

## 预算编制重点

2013年学校实行统一预算管理，不再区分校内预算与基金会预算。各单位可申报教学改革专项、就业专项和自报专项三类项目；日常运转经费由财务处依据员工人数、学生人数和学时数等定额数据核定，各单位无需申报，招生专项由招生办统一申报。薪资支出由学校预算统筹，各单位申报预算无需列入。

教学改革专项用于支持先进本科教育，具体申报安排以教务处后续通知为准。各立项单位还须提交2012年度教改专项执行情况和成效总结，内容应有事实和数据支撑。就业专项须围绕学校与单位共同设定的关键绩效指标申报；“学科建设与科研提升”专项由学校另行设立，相关申报安排以科研处通知为准。自报专项则用于支持各单位提出的其他学校发展项目。

## 附表填写要求

| 附表 | 填写内容 |
| --- | --- |
| 表1 | 按学校编制数和9月实际人数填写预算单位基础数据 |
| 表2 | 填写2011年原定目标及实际完成情况 |
| 表3 | 填写2012年原定目标及前三季度完成情况 |
| 表4 | 分析2012年1至9月各预算项目的任务、目标完成情况和资金使用情况 |
| 表5 | 填写2013—2015年发展规划及2013年度实施要点 |
| 表6 | 填写就业专项经费申请项目的关键绩效指标 |
| 表7 | 填写自报专项经费申请项目的关键绩效指标 |
| 表8 | 汇总2013年度申报项目，与2012年度预算项目比较并说明 |

通知指出，各单位往年预算目标完成情况将直接影响2013年度可能获得的预算支持，因此应认真完成表2、表3和表4。医学院预算可按以往方法或参照校本部模式编制。
