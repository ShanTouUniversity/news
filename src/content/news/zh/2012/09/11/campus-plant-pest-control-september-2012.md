据悉，为改善校园环境卫生并加强植物病虫害防治，汕头大学资源管理处将于2012年9月15日至21日对校区（含龙泉园、成教学院）的绿地花木和果树进行分区喷药。学校提醒师生员工注意作业安全，禁止采摘校园果实食用。

## 分区作业安排

| 日期 | 作业区域 |
| --- | --- |
| 9月15日 | 学术交流中心周围、P楼、学生宿舍区 |
| 9月16日 | 汕大附中、附小至精神卫生中心 |
| 9月17日 | 水库坝、7/8/9号楼、A—B教工宿舍区 |
| 9月18日 | 医科楼、新教学楼、G/H/I/J座学生宿舍、校卫队办公场地周边、校门口、各校道、新图书馆外围 |
| 9月19日 | 食堂、行政楼周围 |
| 9月20日 | 人工湖区域、运动场 |
| 9月21日 | 龙泉园、成教学院 |

> 来源：汕头大学 OA 通知（资源管理处）
