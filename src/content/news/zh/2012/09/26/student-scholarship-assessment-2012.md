据悉，汕头大学将开展2011-2012学年学业优秀奖学金、专项奖学金和优秀学生奖学金评定工作。评定依据《汕头大学本科生奖学金管理办法》（汕大发〔2010〕125号）执行。

## 申请与评定安排

校本部本科生可于9月26日至10月10日登录奖学金网站提交申请。申请学业优秀奖学金的学生须满足评选学年GPA百分比位于同年级同专业前40%且无不及格科目的条件；优秀学生奖学金面向GPA百分比位于前10%、无不及格科目，并获得校级以上校园文化、公益活动或社会实践表彰的学生。用于统计的GPA截至10月10日，申请人需及时确认成绩已完整录入。

学术科技突出贡献奖、文体突出贡献奖、社会服务贡献奖、杰出领导才能奖四类专项奖学金，以及学术科技活动积极分子奖、校园文化活动积极分子奖、社会服务积极分子奖、校园服务积极分子奖四类专项奖学金，均不得在各自组别内重复申请。

| 环节 | 时间安排 |
| --- | --- |
| 学院（书院）、校团委成立评审小组并报送名单 | 10月10日前 |
| 申请学业优秀奖学金材料筛选及入围名单公示 | 10月中旬，公示3天 |
| 报送四类专项奖学金推荐名单及申请表 | 10月17日前 |
| 完成优秀学生奖学金初选并报送推荐人选 | 10月22日前 |
| 学校评审专项奖学金及优秀学生奖学金 | 10月底至11月初 |
| 学院（书院）评选四类专项奖学金积极分子并报送结果 | 11月初 |

专项奖学金名额和推荐名额按有关单位比例分配，优秀学生奖学金推荐名额按评选名额1:1.5确定。评选结果将通过学生事务系统、校内办公信息网或奖学金网站公布。

申请过程中如有疑问，可通过 `xyli@stu.edu.cn` 咨询。学校提醒，奖学金系统此前处于测试状态，通知发布后提交的申请方为有效申请，测试期间提交的申请表将被删除。
