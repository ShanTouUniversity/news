据悉，党政办公室与资源管理处于9月7日联合发布通告，公布新行政中心车辆停放安排，通告自9月10日起施行。

## 安排要点

| 事项 | 内容 |
| --- | --- |
| 架空层东侧南北向通道 | 机动车行驶通道兼消防通道，不设固定泊位 |
| 架空层南侧 | 电瓶车停放点 |
| 架空层东侧 | 摩托车、自行车停放区 |
| 指定泊车点1 | 新行政中心北侧道路两侧（约60个泊位） |
| 指定泊车点2 | 新行政中心西侧十号路停车点（约40个泊位） |

为确保消防安全，新行政中心架空层区域不设汽车固定泊位。请全体师生员工服从保卫部门管理，共同营造良好校园环境。
