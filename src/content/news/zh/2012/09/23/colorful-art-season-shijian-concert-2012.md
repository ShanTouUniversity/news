据悉，长江艺术与设计学院艺术教育中心邀请香港专业无伴奏合唱剧团“一铺清唱”到汕头大学演出《石坚》2012年特别版。本场演出将于9月28日19:30在学校大礼堂举行，作为“五彩缤纷艺术季·2012秋”的首场演出，为师生提供现场欣赏无伴奏合唱剧场的机会。

## 演出与取票信息

| 项目 | 内容 |
| --- | --- |
| 演出作品 | 《石坚》2012年特别版 |
| 演出团体 | 香港专业无伴奏合唱剧团“一铺清唱” |
| 演出时间 | 9月28日19:30 |
| 演出地点 | 汕头大学大礼堂 |
| 取票地点 | 艺术教育中心309室 |
| 普通师生取票时间 | 9月26日9:30—12:00、14:30—17:00 |

艺术粉丝的取票时间以校内办公信息网发布的艺术粉丝通行证通知为准。其他师生可凭个人一卡通登记取票；艺术粉丝须凭“2012年五彩缤纷艺术季·秋”艺术粉丝通行证登记。门票先到先得，派完即止。

演出相关简介、节目内容及其他安排详见 OA 通知附件。演出谢绝12岁以下儿童入场。
