据悉，为更好引导学生社团发展、表彰表现突出的社团及个人，共青团汕头大学委员会决定于2012年10月开展2011—2012学年度"汕头大学优秀学生社团""优秀学生社团会长"及"优秀学生社团工作者"评选活动。

## 评选安排

校团委要求社联及所属各学生社团对照评选方案及条例，认真组织自评与推选工作。此前已提交过评优材料的社团无需重复提交。

| 项目 | 详情 |
|------|------|
| 组织单位 | 共青团汕头大学委员会 |
| 评选奖项 | 优秀学生社团、优秀学生社团会长、优秀学生社团工作者 |
| 评选学年度 | 2011—2012学年度 |
| 材料提交截止时间 | 2012年10月15日 |
| 提交材料 | 《优秀学生社团自评表》《优秀学生社团会长和工作者申请表》及相关材料电子版 |
| 提交邮箱 | 11xmzheng@stu.edu.cn |
| 咨询 | 郑同学 |
| 后续信息发布 | 社联主页 http://asso.stu.edu.cn/Asso/ 及郁金香BBS站社联版面 |

本次评选的具体条例及表格详见附件。
