据悉，研究生学院于10月26日转发国家留学基金管理委员会通知，第四届国际研究生奖学金信息说明会已于10月20日、24日分别在北京、成都举行，将于10月27日在广州（大学城广外体育馆 9:00—17:00）举行，为有意赴海外留学的在校学生提供与海外名校面对面交流的机会。

## 说明会安排

| 事项 | 内容 |
| --- | --- |
| 名称 | 第四届国际研究生奖学金信息说明会（前三届为“国家公派研究生项目奖学金信息说明会”） |
| 时间地点 | 10月20日北京、10月24日成都、10月27日广州（大学城广外体育馆 9:00—17:00） |
| 承办单位 | 北京大学、四川大学、广东外语外贸大学及东方国际教育交流中心 |
| 参会外方 | 来自英国、美国、加拿大、澳大利亚、法国、德国、荷兰、新西兰等15个国家的近70所世界知名大学及部分驻华使馆，包括牛津、剑桥、乔治城、麦吉尔、澳大利亚国立大学等 |
| 活动形式 | 开放式咨询、国家留学基金委及外方院校专场讲座，外方院校还将预约部分报名学生进行一对一面谈 |
| 报名方式 | 在线注册参加，可与海外院校代表现场交流 |
| 咨询电话 | 010-66411821-692/632/634 |
| 官方网站 | www.csc.edu.cn/edufair |
| 专题介绍 | www.cscdf.org/igsf |
| 主办单位 | 国家留学基金管理委员会秘书处 |

自2009年举办以来，前三届已为100余所高校和近2万名学生搭建了奖学金信息交流平台，2011年参会人数已超7000人，预计本届将超1万人。该说明会已成为海外名校推介研究生教育、招收中国优秀学生的重要年度盛会。

> 来源：汕头大学 OA 通知（研究生学院、国家留学基金管理委员会）
