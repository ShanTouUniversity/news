2012 年度广东省教育科学“十二五”规划项目启动申报，汕头大学科研处面向校内有关单位征集项目。该项目为自筹经费项目，申请课题应围绕建设教育强省、率先实现教育现代化和打造南方教育高地，聚焦广东教育改革发展中的重大现实和理论问题。

申请课题应立足广东，体现相关学科研究新水平和地方特色，推进理论创新和实践问题研究，并具有原创性和开拓性。鼓励以论文、研究报告作为最终成果申报。

| 项目 | 要求 |
| --- | --- |
| 经费 | 自筹经费 |
| 学校申报限额 | 8项 |
| 项目负责人 | 每人限报1项；未完成国家社科基金、全国教育科学规划、教育部、广东省哲学社会科学规划或广东省教育厅科研项目的负责人不得申报 |
| 项目组成员 | 作为其他项目成员参加申报不超过2项 |
| 研究期限 | 论文或研究报告1—2年；专著2—3年 |
| 申请书初次提交 | 11月1日前将电子版发送至 ljwang@stu.edu.cn |
| 终稿上传及纸质材料 | 11月7日前登录网上申报系统上传终稿，并向科研处提交A4纸双面印制申请书一式2份 |

申请人须通过网上申报系统申报，并按课题内容从 14 个学科组选择所属领域编号：教育基本理论与教育史（jk001）、教育心理学（jk002）、教育信息技术（jk003）、比较教育（jk004）、德育（jk005）、教育经济与管理（jk006）、教育发展战略（jk007）、基础教育（jk008）、高等教育（jk009）、职业技术教育（jk010）、成人教育（jk011）、体育卫生美育（jk012）、民族教育（jk013）和国防军事教育（jk014）。教育信息技术和国防军事教育项目分别由专门机构组织，不在本次申报范围内。

联系人为黄玉梅、黄楠，联系电话 86502563、82902563。网上申报流程和申请书见原通知附件。
