汕头大学互助学习中心（SLC）公布多媒体软件入门学习班录取结果。此前发布的报名通知得到各学院学生响应，共有 50 名学生报名成功，具体名单见原通知附件。

SLC 多媒体软件学习班由导生提供入门指导。需要进一步学习软件操作或希望获得一对一服务的学生，可登录预约中心（[booking.stu.edu.cn](http://booking.stu.edu.cn/)）预约导生交流。

| 项目 | 信息 |
| --- | --- |
| 学习班 | SLC多媒体软件入门学习班 |
| 报名结果 | 50名学生报名成功 |
| 服务内容 | 导生提供多媒体软件入门指导 |
| 深入学习 | 通过预约中心预约导生交流或一对一服务 |
| 预约平台 | [booking.stu.edu.cn](http://booking.stu.edu.cn/) |

为保护学生隐私，本文不公开录取学生名单及其他个人信息。

> 来源：汕头大学 OA 通知（学生处）
>
> ⚠️ 录取学生名单请前往 OA 系统查看原文附件，本文不公开学生个人信息。
