汕头大学理学院化学系启动 2012 年度校友奖学金评选。该奖学金由化学系校友倡议设立，并以 22.28 万元捐款作为启动基金，旨在鼓励优秀学生报考化学系，支持在校学生勤奋学习、积极进取，并帮助家庭经济困难学生。

奖学金面向理学院化学系品学兼优、家庭经济困难的全日制本科生，每年奖励 20 名，其中 8 名名额用于一年级学生，每名奖励人民币 2,500 元。

| 项目 | 信息 |
| --- | --- |
| 奖学金 | 汕头大学化学系校友奖学金 |
| 申请对象 | 理学院化学系品学兼优、家庭经济困难的全日制本科生 |
| 年度名额 | 20名，其中一年级学生8名 |
| 奖励标准 | 每人人民币2,500元 |
| 启动基金 | 校友捐款22.28万元 |
| 申请截止 | 2012年10月29日（星期一）16:00前 |
| 提交地点 | 理学院团委，理科楼354 |
| 材料要求 | 填写申请表，双面打印并签名后提交 |

有意申请者须按要求填写申请表，打印并签名后在截止时间前提交。申请表见原通知附件。

> 来源：汕头大学 OA 通知（理学院、学生处）
>
> ⚠️ 校友奖学金申请表请前往 OA 系统查看原文附件。
