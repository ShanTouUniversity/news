据悉，科研处于10月10日发布通知，组织申报2013年度国家体育总局体育哲学社会科学研究项目。

## 申报安排

| 事项 | 内容 |
| --- | --- |
| 项目类别 | 重点项目、一般项目、青年项目 |
| 申报条件 | 重点和一般项目负责人需具副高以上职称或处级以上职务；青年项目负责人需获硕士以上学位、无副高职称且39周岁以下 |
| 限报要求 | 每人限报1项，课题组成员最多参与2项；在研局管体育社科及国家社科基金项目负责人不得申报；学校限报3项 |
| 研究周期 | 重点项目1—2年，一般和青年项目一般为1年 |
| 材料提交 | 10月24日前发送《申请书》《活页》电子版至 ljwang@stu.edu.cn 形式审查；10月31日前提交纸质版《申请书》一式2份、《活页》一式6份至科研处并发送电子版终稿 |
| 联系人 | 黄玉梅、黄楠 |
| 联系电话 | 86502563、82902563 |
| 发布单位 | 科研处 |

项目指南及申报表格见 OA 附件。
