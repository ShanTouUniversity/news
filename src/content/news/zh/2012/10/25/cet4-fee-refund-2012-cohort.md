根据广东省教育考试院通知，汕头大学 2012 级本科生不能参加 2012 年下半年大学英语四级考试。教务处已委托财务处将相关报名学生每人 16 元报名费退回个人“一卡通”账户。

相关学院须通知报名学生自行查询账户。如对退费有疑问，可联系教务处学务科。具体退费名单以原通知附件为准，本文不公开学生名单及个人信息。

| 项目 | 信息 |
| --- | --- |
| 考试 | 2012年下半年大学英语四级考试 |
| 涉及对象 | 2012级本科报名学生 |
| 调整事项 | 2012级本科生不能参加本次考试 |
| 退费金额 | 每人16元 |
| 退费方式 | 退回个人一卡通账户 |
| 查询方式 | 学生自行查询一卡通账户 |
| 咨询部门 | 教务处学务科 |

> 来源：汕头大学 OA 通知（教务处）
>
> ⚠️ 退费名单请前往 OA 系统查看原文附件；本文不公开学生个人信息。
