根据汕头市委组织部《关于选拔第 13 批市优秀拔尖人才的通知》，汕头大学经专家组评审，并经学校第八次党委常委会讨论通过，拟推荐包能胜、胡忠、郑怀平三位教授为第 13 批汕头市优秀拔尖人才人选，现予公示。

| 项目 | 信息 |
| --- | --- |
| 评选 | 第13批汕头市优秀拔尖人才 |
| 推荐人选 | 包能胜、胡忠、郑怀平三位教授 |
| 评审流程 | 专家组评审、学校第八次党委常委会讨论通过 |
| 公示截止 | 2012年10月26日12:00前 |
| 反馈部门 | 学校党委组织统战部 |
| 反馈方式 | 书面、来人或来电反映 |
| 联系电话 | 82902345 |
| 联系邮箱 | o_zzb@stu.edu.cn |
| 依据文件 | 汕组通〔2012〕54号 |

对公示人选有不同意见者，可于截止时间前向党委组织统战部反映。单位材料须加盖公章，个人反映须签署真实姓名。
