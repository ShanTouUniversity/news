根据广东省教育厅相关文件要求，汕头大学开展 2012—2013 学年度普通高校退役士兵学费资助工作。学校要求各学院、书院加强政策宣传，组织符合条件且自愿申请的学生提交材料。

本次资助对象为考入高校的退役士兵，不包括复学退役士兵。申请人须已退役一年以上且目前在校就读；在校期间应征入伍服义务兵役，或退役一年内入学的学生，不享受该项资助。资助按学年申请，每次只能申请当学年的学费，金额按实际学费标准确定，每人每学年不超过 6000 元。

| 项目 | 信息 |
| --- | --- |
| 资助年度 | 2012—2013学年度 |
| 适用对象 | 考入高校、退役一年以上且目前在校就读的退役士兵 |
| 不适用对象 | 复学退役士兵；在校入伍服义务兵役者；退役一年内入学者 |
| 申请方式 | 填写《普通高等学校退役士兵学费资助申请表》 |
| 资助标准 | 按学费标准确定，每人每学年不超过6000元 |
| 纸质材料截止 | 2012年11月5日 |
| 递交地点 | 教育管理科（行政中心106） |
| 电子材料 | 发送至zpchen@stu.edu.cn |

2011—2012 学年度入学、符合条件但上一年度漏报的学生，可在本年度补报，合计申请两个学年的资助，并在申请表备注栏说明；上一年度已申请资助的学生，可继续申请本年度资助。申请表须如实填写，服役期间须注明具体起止年月，不得随意涂改。

> 来源：汕头大学 OA 通知（学生处）
