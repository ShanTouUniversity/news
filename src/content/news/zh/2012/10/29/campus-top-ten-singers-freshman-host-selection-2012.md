汕头大学第二十届校园十大歌手大赛将于 2012 年 11 月启动。为给新生提供展示和实践平台，校团委、学生会面向 2012 级新生选拔大赛主持人。入选者将接受往届优秀主持人培训，并在本届比赛中与往届主持人共同主持。

报名者需具备较强的语言组织与表达能力，普通话标准流利，能够大方自信地开展主持、活跃现场气氛，并具备临场应变、认真负责和倾听沟通等能力。

| 项目 | 信息 |
| --- | --- |
| 选拔对象 | 2012级新生 |
| 报名截止 | 2012年10月30日12:00 |
| 面试时间 | 2012年10月31日14:00，具体安排另行通知 |
| 选拔时间 | 2012年11月3日14:00 |
| 面试及选拔地点 | 7号楼726会议室 |
| 报名材料 | 校内办公信息网下载的报名表 |
| 提交邮箱 | 12dscai@stu.edu.cn |

报名者须填写报名表，并按通知要求命名邮件主题和报名表后发送至指定邮箱。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
