为提升校内通信的便捷性，汕头大学网络与信息中心面向校内教职工征集汕头本地中国移动手机号码，统一办理或登记校园集群网络。各单位须收集本单位愿意加入或已经加入校园集群网的教职工号码，并按附件格式填写、加盖单位公章，于 10 月 19 日前提交至网络与信息中心一楼一卡通窗口。

校园集群网用户可享受群内免费通话和免月租费等优惠。原已加入校园网的教职工完成本次登记后，自 11 月起免收集群网月租费；加入校园集群网的手机与群内手机、学校新固定电话互打免费。

| 项目 | 信息 |
| --- | --- |
| 登记对象 | 校内教职工使用的汕头本地中国移动手机号码 |
| 登记范围 | 愿意加入或已加入校园集群网的教职工 |
| 提交截止 | 2012年10月19日前 |
| 提交地点 | 网络与信息中心一楼一卡通窗口 |
| 材料要求 | 按附件格式填写，并加盖所在单位公章 |
| 主要优惠 | 群内免费通话、免月租；集群手机与群内手机及学校新固定电话互打免费 |
| 联系人 | 黄乐斯 |
| 联系电话 | 86503423 |
| 联系邮箱 | o_wlzx@stu.edu.cn |

校园集群网手机拨打学校固定电话时，拨“88”加固定电话号码后四位；固定电话拨打手机时使用手机短号。登记表及具体格式见原通知附件。
