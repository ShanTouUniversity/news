汕头大学工学院公布 2012 年度国家奖学金拟评人选。根据学校国家奖学金、国家励志奖学金和国家助学金评定工作安排，工学院国家奖学金评选委员会经过面试考核评议，拟推荐 3 名学生为工学院 2012 年度国家奖学金获得者。

为保护学生隐私，本文以姓氏和名字拼音首字母标注学生姓名。拟推荐人选为 09 级电子专业胡Y、09 级计算机专业周JF和 09 级机电专业许FJ。

| 项目 | 信息 |
| --- | --- |
| 奖项 | 工学院2012年度国家奖学金 |
| 拟推荐人数 | 3人 |
| 评定方式 | 工学院国家奖学金评选委员会面试考核评议 |
| 拟推荐人选 | 胡Y（09级电子）、周JF（09级计算机）、许FJ（09级机电） |
| 公示截止 | 2012年10月23日17:00 |
| 反馈地点 | 工南210工学院团委 |
| 联系电话 | 0754-82902986 |
| 联系邮箱 | yaoyi@stu.edu.cn |

对拟推荐人选有异议者，可在公示期内向工学院奖学金评审小组反映。单位提交的材料须加盖公章，个人提交的材料须签署真实姓名。

> 来源：汕头大学 OA 通知（工学院）
