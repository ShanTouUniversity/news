据悉，汕头大学工会于10月18日发布公示，经校工会女职工委员会投票，拟推荐理学院物理系实验室为汕头市“巾帼文明岗”候选单位。

## 公示信息

| 事项 | 内容 |
| --- | --- |
| 拟推荐单位 | 理学院物理系实验室 |
| 推荐事由 | 参评汕头市“巾帼文明岗” |
| 决定程序 | 校工会女职工委员会投票 |
| 异议截止 | 2012年10月20日前 |
| 受理方式 | 书面形式向学校工会反映；单位反映需加盖公章，个人反映需签署真实姓名 |
| 联系电话 | 82902983 |
| 电子邮箱 | o_xgh@stu.edu.cn |
| 发布单位 | 工会 |

有不同意见的单位和个人请在规定时间内按要求反映。

> 来源：汕头大学 OA 通知（工会）
