汕头大学理学院公布 2012 年“潘毓刚奖学金”和“森德利化工奖学金”评审结果。申请截止后，理学院共收到潘毓刚奖学金申请 51 份、森德利化工奖学金申请 39 份，评审委员会根据相关评审条例确定 8 名学生为两项奖学金候选人。

| 项目 | 信息 |
| --- | ---: |
| 潘毓刚奖学金申请 | 51份 |
| 森德利化工奖学金申请 | 39份 |
| 申请总数 | 90份 |
| 两项奖学金候选人 | 8名 |
| 结果反馈截止时间 | 11月8日（星期四）下班前 |
| 受理单位 | 理学院团委 |
| 联系电话 | 82902779 |

候选人名单载于 OA 原文附件。对评审结果有不同意见的学生，可在公示期内以书面、到访或来电方式向理学院团委反映；个人反映情况须签署真实姓名。为保护学生隐私，本文不转载候选人姓名。

> 来源：汕头大学 OA 通知（理学院）
>
> ⚠️ 两项奖学金候选人名单请前往 OA 系统查看原文附件。
