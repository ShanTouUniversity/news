汕头大学团委和汕头大学青年志愿者协会公布 2011—2012 年度曙光助学工程“活动积极分子”表彰决定，共有 82 名学生获授该称号。

过去一年，曙光助学工程志愿者面向汕头市困难家庭子女持续开展义务助学和帮教活动。相关服务获得市民及有关部门的肯定，也促进了学校与汕头市的精神文明建设。

| 项目 | 信息 |
| --- | --- |
| 表彰项目 | 曙光助学工程“活动积极分子” |
| 表彰年度 | 2011—2012年度 |
| 获表彰人数 | 82名学生 |
| 表彰单位 | 共青团汕头大学委员会、汕头大学青年志愿者协会 |
| 主要服务 | 面向困难家庭子女开展义务助学和帮教 |

获表彰学生名单载于 OA 原文附件。为保护学生隐私，本文不转载个人姓名。校团委同时号召全校学生学习志愿服务先进，践行“奉献、友爱、互助、进步”的志愿者精神。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
