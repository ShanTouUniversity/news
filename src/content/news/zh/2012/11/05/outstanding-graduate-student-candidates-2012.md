汕头大学研究生学院公布 2012 年度“优秀研究生”评审结果。各研究生培养单位完成初评推荐后，研究生学院组织校内专家评审，确定 11 名研究生为一等奖候选人、39 名研究生为二等奖候选人，共计 50 人。候选人涉及无机化学、海洋生物学、计算机应用技术、结构工程、新闻学、行政管理等多个研究生专业。

| 类别 | 人数 |
| --- | ---: |
| “优秀研究生”一等奖候选人 | 11名 |
| “优秀研究生”二等奖候选人 | 39名 |
| 合计 | 50名 |

具体名单载于 OA 原通知附件。鉴于名单涉及学生姓名、专业年级及导师等个人信息，本文仅保留评审人数和类别，不转载个人名单。

## 公示信息

| 项目 | 信息 |
| --- | --- |
| 公示截止时间 | 2012年11月9日 17:00前 |
| 反馈方式 | 书面反映、到访或来电 |
| 受理单位 | 研究生学院 |
| 联系电话 | 82904000 |

单位或个人如有不同意见，可在公示期内向研究生学院反映；个人反映情况须签署真实姓名。
