汕头大学公布 2012 级新生乙肝疫苗接种安排，以加强校园预防保健工作。对于既往未接种过乙肝疫苗，且乙肝表面抗原、乙肝表面抗体检测均为阴性的学生，校方建议接种三针乙肝疫苗。

接种遵循自愿、自费原则。按照汕头市防疫站收费标准，进口乙肝疫苗每针 78 元。接种前须先完成乙肝表面抗原和表面抗体检查。

| 项目 | 信息 |
| --- | --- |
| 检查地点 | 校医院二楼化验室 |
| 抽血时间 | 11月7日至16日，上午8:30—9:30 |
| 周末安排 | 周六、周日不安排抽血 |
| 结果领取 | 抽血次日下午领取检查结果 |
| 后续安排 | 领取结果后登记并预约接种时间 |
| 疫苗费用 | 进口乙肝疫苗每针78元 |

上述安排仅面向符合接种建议条件且自愿接种的 2012 级新生。本文不涉及任何个人检测结果或健康记录。

> 来源：汕头大学 OA 通知（资源管理处）
