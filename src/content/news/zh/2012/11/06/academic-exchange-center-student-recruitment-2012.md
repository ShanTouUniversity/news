汕头大学学术交流服务中心面向校本部在读男生招聘钟点工，岗位包括餐厅服务员和楼层服务员。中心位于日月湖畔，主要接待来自不同地区和国家的来访领导、嘉宾学者及商界人士。

| 项目 | 信息 |
| --- | --- |
| 招聘岗位 | 餐厅服务员、楼层服务员 |
| 招聘对象 | 汕头大学校本部在读男生 |
| 薪酬 | 按小时计薪 |
| 报名截止 | 2012年11月10日前 |
| 报名邮箱 | `stuacc@stu.edu.cn` |
| 联系人 | 翁小姐、李小姐 |
| 联系电话 | `82902668`、`82904138` |
| 咨询时间 | 8:30—18:00 |

应聘者应具备较强的英语和粤语听说能力，大学英语四级考试合格者优先；同时需具备一定的社交技巧和应变能力，仪表端正、态度和蔼。报名材料包括求职申请表和一寸正面照片，面试时间将通过邮件另行通知。

为保护应聘者隐私，本文不转载原通知关于面试时携带个人证件原件的要求；应聘者可直接向学术交流服务中心咨询具体面试材料。
