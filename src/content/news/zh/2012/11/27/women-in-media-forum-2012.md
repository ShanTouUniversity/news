据悉，长江新闻与传播学院将于12月1日举办“Women in Media”论坛，全球各大权威媒体机构杰出女性媒体代表将共同出席。

## 活动安排

| 事项 | 安排 |
| --- | --- |
| 主题 | Women in Media 全球各大权威媒体机构杰出女性论坛 |
| 主持人 | 倪青青副院长（普利策奖获得者） |
| 主论坛时间 | 12月1日（星期六）晚19:30—21:30 |
| 主论坛地点 | 图书馆科报厅 |
| 另设分场 | 12月1日早间及下午在ACC和学院玻璃房安排各位嘉宾单独分享交流会 |
| 发布单位 | 长江新闻与传播学院 |
| 发布时间 | 2012年11月27日 |

论坛面向对电视、报纸、广播、通讯社及公关感兴趣的师生开放，现场将设开放互动环节。

## 嘉宾名单

| 嘉宾 | 机构与职务 |
| --- | --- |
| Marsha Cooke | 美国哥伦比亚广播公司（CBS）亚太地区总编辑兼电视新闻制片人 |
| Normandy Madden | 美国品牌娱乐公司 Thoughtful Media Group（TMG）亚太地区高级副总裁 |
| Mary Kay Magistad | 国际公共广播电台 The World（Public Radio International）资深驻外通讯员 |
| 王晓清 | 中央电视台（CCTV）大型节目主持人、电视节目编导、导演、制片人 |
| 洪晓燕（Carrie Hong） | 路透社驻香港债券新闻（资本市场）记者 |
| 谢汉兰 | 美国知名华裔女作家、记者、编辑和民权活动人士 Helen Zia |

更多详情可查看新闻学院官网活动预告 http://media.stu.edu.cn/?p=15105。
