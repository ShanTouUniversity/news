据悉，长江新闻与传播学院将于11月28日晚在图书馆报告厅举办周三电影放映活动，放映影片《偷自行车的人》（The Bicycle Thief）。

## 观影安排

| 事项 | 内容 |
| --- | --- |
| 影片 | 《偷自行车的人》（The Bicycle Thief，1948） |
| 时间 | 2012年11月28日19:00—22:00 |
| 地点 | 图书馆报告厅 |
| 主持人 | Peter Herford |
| 座位 | 课程150个席位外另对公众开放50席，先到先得，学生凭一卡通进场 |
| 主办单位 | 长江新闻与传播学院 |

影片为意大利新现实主义经典代表作，是导演维托里奥·德·西卡最负盛名的作品。故事背景为第二次世界大战前后的罗马，男主角好不容易找到张贴海报的工作，却在首日被偷走赖以谋生的自行车，遂与儿子四处寻车，最终无奈铤而走险。全片以简练故事和生活化表演，生动呈现战后罗马社会面貌，曾获第22届奥斯卡最佳外语片奖等多项荣誉，并被评为影史经典之一。

欢迎全校师生前来观赏。

> 来源：汕头大学 OA 通知（长江新闻与传播学院）
