汕头大学学生处心理健康教育与咨询中心将举办第三届大学生心理剧比赛，主题为“新生活，心快乐”。比赛以大学生常见心理问题为创作素材，旨在推动心理健康知识在校园传播，丰富心理健康教育形式。

### 参赛与作品要求

比赛面向汕头大学全体在校师生，参赛者可自由组队，每队不超过 15 人。作品须为大学生原创，内容思想健康、主题鲜明，体现心理学知识和心理辅导技能，剧情生动并具有艺术表现力。

参赛形式包括音乐剧、话剧、小品、哑剧和歌舞剧等，时长约 10—15 分钟；对白或旁白以普通话为主，可适当使用英语或方言。参赛队伍自行准备道具，进入决赛的队伍将获得适当比例的道具补助。

### 赛制与奖项

| 项目 | 安排 |
| --- | --- |
| 报名和剧本提交 | 11月16日至12月1日 |
| 初赛培训 | 入选初赛的队伍参加剧本创作、表演技巧等培训 |
| 初赛 | 12月23日现场表演 |
| 决赛 | 下学期举行 |
| 一等奖 | 1名，奖金1,000元及奖状 |
| 二等奖 | 2名，每名奖金600元及奖状 |
| 三等奖 | 3名，每名奖金300元及奖状 |
| 最佳人气奖 | 1名，奖金200元及奖状 |

纸质剧本和电子版材料须按心理健康教育与咨询中心原通知要求提交，电子版剧本及咨询邮箱为 `o_xlzx@stu.edu.cn`，机构咨询电话为 82903380。
