汕头大学科研处将举办“汕头大学学科发展与研究绩效分析——基于 SCI/ESI/InCites 权威数据与分析工具”讲座，邀请汤森路透知识产权与科技集团产品与解决方案专家马亚鹏作报告。

| 项目 | 信息 |
| --- | --- |
| 讲座题目 | 汕头大学学科发展与研究绩效分析——基于SCI/ESI/InCites权威数据与分析工具 |
| 报告人 | 马亚鹏 |
| 报告人单位 | 汤森路透知识产权与科技集团 |
| 报告时间 | 11月19日（星期一）10:00—11:00 |
| 报告地点 | 科学楼205会议室 |
| 主要对象 | 分管科研的院长、学科带头人和科研骨干、重点实验室负责人、学科建设与科研管理部门工作人员、学院科研秘书 |

报告将围绕汕头大学科研产出与影响力、学校学术成果与相关机构的多角度比较，以及学科发展和科学研究面临的机遇与挑战展开。其他感兴趣的师生也可参加。

> 来源：汕头大学 OA 通知（科研处）
