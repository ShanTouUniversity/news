汕头大学各学院（书院）已完成国家助学金申请初审。由于仍有少量名额，学校再次开放国家助学金申请系统，以扩大资助覆盖范围。

有意申请的学生须于 2012 年 11 月 5 日（星期一）中午 12:00 前登录奖学金网站提交申请：[国家助学金申请系统](http://www.scholarship.stu.edu.cn/chinese/applyIntro2.aspx)。

| 项目 | 信息 |
| --- | --- |
| 申请项目 | 国家助学金 |
| 申请对象 | 有意申请且符合相关条件的学生 |
| 提交截止 | 2012年11月5日（星期一）12:00前 |
| 提交方式 | 登录汕头大学奖学金网站在线申请 |
| 申请原因 | 初审后仍有少量名额，为扩大资助覆盖面再次开放系统 |

具体申请资格和系统操作要求以奖学金网站及学校相关资助规定为准。

> 来源：汕头大学 OA 通知（学生处）
