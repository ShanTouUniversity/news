据悉，汕头大学科研处于11月2日转发广东省教育厅《关于申报2012年国家级星火计划等备选项目的通知》（粤教科办函【2012】29号），面向全校征集有意愿申报的老师。

根据安排，有意申报的教师应及时与科研处联系，并对照各类项目的申报条件准备材料，于11月5日前将申报材料送至科研处。项目类别、申报条件等具体信息可查阅通知附件。

## 申报要点

| 事项 | 安排 |
| ---- | ---- |
| 项目范围 | 2012年国家级星火计划等备选项目 |
| 材料报送截止 | 2012年11月5日 |
| 报送地点 | 科研处 |
| 联系人 | 胡云翔、朱长盛（电话 82902813） |
