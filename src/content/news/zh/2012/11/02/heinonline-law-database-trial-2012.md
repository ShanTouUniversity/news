汕头大学图书馆开通 HeinOnline 法律全文期刊数据库试用，试用期至 2012 年 11 月 30 日。该数据库以法律文献为核心，覆盖政治、国际关系和外交等领域，采用 PDF 全文浏览格式。

数据库收录全球 2000 余种法学期刊、675 卷国际法领域著作、10 万余个案例、2000 余部法学经典学术专著以及美国联邦政府报告等全文资料，具有较高的学术参考价值。

| 项目 | 信息 |
| --- | --- |
| 数据库 | HeinOnline法律全文期刊数据库 |
| 试用截止 | 2012年11月30日 |
| 覆盖领域 | 法律、政治、国际关系、外交等 |
| 资源类型 | 法学期刊、国际法著作、案例、学术专著和美国联邦政府报告等 |
| 图书馆入口 | [HeinOnline数据库](http://www.lib.stu.edu.cn/dbdetail.aspx?id=349) |
| 意见反馈 | 图书馆学科服务部，电话3247；lqxie@stu.edu.cn、zhzeng@stu.edu.cn |

师生可通过汕头大学图书馆数据库入口进入 HeinOnline，按页面提示登录并选择 Law Journal Library 或其他相关文库。为避免公开数据库试用凭据，本文不转载用户名和密码；具体访问方式以图书馆原通知为准。
