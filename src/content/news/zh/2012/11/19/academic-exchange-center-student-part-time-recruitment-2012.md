汕头大学学术交流服务中心面向校内学生招聘钟点工，岗位包括餐厅服务员和楼层服务员。该中心承担校内来宾接待服务，岗位工作可为学生积累服务和社会实践经验。

| 项目 | 信息 |
| --- | --- |
| 招聘岗位 | 餐厅服务员、楼层服务员 |
| 薪酬方式 | 按小时计薪 |
| 招聘对象 | 汕头大学在校男生 |
| 申请截止时间 | 2012年12月20日 |
| 申请邮箱 | `stuacc@stu.edu.cn` |
| 面试安排 | 通过邮件另行通知 |
| 咨询电话 | 82902668、82904138（08:30—18:00） |

应聘者须具备较强的英语和粤语听说能力，具备全国大学英语四级成绩者优先，同时应具备一定的社交和应变能力，仪表端正、态度和蔼。申请时须将求职表和一寸正面照片通过电子邮件发送至指定邮箱；面试时按要求携带身份证及其他相关证件原件。

> 来源：汕头大学 OA 通知（资源管理处）
>
> ⚠️ 求职申请表请前往 OA 系统查看原文附件；具体面试要求以招聘单位通知为准。
