“新世纪人文论坛”第一百一十四期将围绕“漫谈联合国翻译——以教科文组织为例”展开。南京大学外国语学院院长、博士生导师朱刚教授将结合其在联合国教科文组织翻译处工作的经历，讨论翻译与政治、文化及社会知识之间的联系。

| 项目 | 信息 |
| --- | --- |
| 论坛 | 新世纪人文论坛第一百一十四期 |
| 主题 | 漫谈联合国翻译——以教科文组织为例 |
| 主讲人 | 朱刚教授 |
| 主讲人单位 | 南京大学外国语学院 |
| 时间 | 11月21日（星期三）19:30—21:30 |
| 地点 | 学术交流中心三号会议室 |
| 参加对象 | 全校师生 |

朱刚兼任全国美国文学研究会秘书长、教育部高校外语专业教学指导委员会委员，主要从事英美文学、批评理论和翻译学教学与研究。他曾在多所海外高校访学，并在联合国教科文组织翻译处担任译员和译审。报告将介绍翻译研究所关注的字面意义背后的深层文化含义。

> 来源：汕头大学 OA 通知（文学院）
