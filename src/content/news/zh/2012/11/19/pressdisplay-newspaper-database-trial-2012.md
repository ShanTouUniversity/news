汕头大学图书馆开通 PressDisplay 全球报刊数据库试用，面向全校师生读者提供来自世界各地的数字化报刊资源。该数据库收录来自 95 个国家的 2200 多份知名报刊，覆盖汉语、英语、俄语、德语、日语和韩语等 55 种语言，读者可同步获取每日更新的报刊内容。

| 项目 | 信息 |
| --- | --- |
| 数据库 | PressDisplay全球报刊数据库 |
| 资源范围 | 95个国家、2200多份报刊、55种语言 |
| 内容特点 | 每日同步获取全球报刊的数字化内容 |
| 试用截止时间 | 2012年12月31日 |
| 访问入口 | <http://www.lib.stu.edu.cn/dbdetail.aspx?id=359> |
| 反馈渠道 | 图书馆学科服务部，电话 86503247 |

图书馆欢迎师生读者在试用期间使用该数据库，并向学科服务部反馈使用评价和意见。

> 来源：汕头大学 OA 通知（图书馆）
