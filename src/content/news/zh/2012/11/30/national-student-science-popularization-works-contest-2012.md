汕头大学团委面向全校学生征集作品，组织参加 2012 年全国大学生科普作品创作大赛。该赛事由中国科协科普部、共青团中央学校部、教育部科技司和高校学生司共同组织，旨在鼓励大学生参与科学传播社会实践，提升创新创业能力。

参赛作品须为原创科普作品，主题鲜明，并兼具思想性、科学性、艺术性和通俗性。作品形式包括图文类、音视频类和动画类，动画类可包含 Flash、Flash 页面专题、HTML5 科普资源及科普游戏等。

| 项目 | 信息 |
| --- | --- |
| 赛事 | 2012年全国大学生科普作品创作大赛 |
| 参赛对象 | 汕头大学全校学生 |
| 作品要求 | 原创，兼具思想性、科学性、艺术性和通俗性 |
| 作品类型 | 图文、音视频、动画及科普游戏等 |
| 校内提交截止 | 2012年12月24日 |
| 创作阶段 | 2012年7月至12月31日 |
| 初评及推荐 | 2013年1月 |
| 终评及表彰 | 2013年2月至3月 |
| 宣传推广 | 2013年4月至6月 |

有意参赛的学生可通过中国数字科技馆网站 <http://www.cdstm.cn/> 了解赛事详情，并按校内安排将作品提交至团委相关邮箱。获选作品后续将进入初评推荐、终评表彰及宣传推广环节。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
>
