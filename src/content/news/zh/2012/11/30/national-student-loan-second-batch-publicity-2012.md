汕头大学学生处公布，2012—2013 学年第二批国家助学贷款申请共有 93 名学生通过助学工作管理中心审核，现面向校内进行公示。

公示期截至 2012 年 12 月 7 日。单位或个人如有异议，可在截止日期前以书面形式、来访或电话方式向学生处助学工作管理中心反映。单位反映情况须加盖公章，个人反映须署真实姓名。

根据中国银行汕头分行的工作安排，本批次国家助学贷款合同计划于 2012—2013 学年春季学期初签订。

| 项目 | 信息 |
| --- | --- |
| 申请批次 | 2012—2013学年第二批 |
| 贷款类型 | 国家助学贷款 |
| 审核通过人数 | 93名学生 |
| 公示截止 | 2012年12月7日 |
| 异议受理 | 学生处助学工作管理中心 |
| 联系电话 | 86504749 |
| 合同签订安排 | 2012—2013学年春季学期初 |
| 经办银行 | 中国银行汕头分行 |

学生处提醒，相关单位和个人应通过正式渠道反映意见，并按后续通知办理合同签订手续。
