汕头大学商学院与工学院联合举办首届电子商务实践项目，围绕汕头市对外出口的遥控玩具开展运营策划和商业实践。项目旨在培养学生创新、团队协作和社会适应能力，帮助学生运用所学知识分析市场、解决实际问题。

### 项目与团队要求

参赛团队须围绕遥控汽车、遥控飞机等遥控玩具系列产品，分析目标消费人群的消费水平和偏好，并提出网络营销方法和运营策略。项目以团队形式开展，每队不少于 3 人，年级不限；鼓励跨学院、跨专业合作，且每队成员至少来自 3 个不同的学院或书院。每队须确定队长并完成团队命名。

### 项目日程

| 阶段 | 时间 |
| --- | --- |
| 活动报名 | 即日起至11月25日23:00前 |
| 网商大讲堂 | 11月21日14:00 |
| 提交运营方案 | 12月2日23:00前 |
| 团队答辩 | 12月5日14:00 |
| 入围培训 | 12月8日19:30 |
| 商业实践 | 培训后至2013年5月 |

答辩通过的前三支队伍进入电子商务商业实践环节。方案排名第一的团队可优先选择以下一种实践方式：一间已开通的淘宝店和一间拍拍店、一间已开通的淘宝店和一间当当店，或其他推广销售方式。实践期约半年，最终根据项目期间店铺销售额确定获胜团队；相关网店将提供产品和物流，学生团队主要负责营销推广与客服。

### 鼓励计划

| 项目 | 安排 |
| --- | --- |
| 团队销售奖励 | 按团队销售额的10%提成作为奖励 |
| 超额销售奖励 | 超出原定销售额部分的40%作为奖励提成 |
| 实习推荐 | 表现优秀者可获电商实习岗位推荐 |
| 项目结题 | 在规定时间内完成结题的队伍可获得正式实习证明 |

有意参加者须按主办单位要求提交报名材料，具体报名渠道和材料格式以 OA 原文为准。项目主办单位为汕头大学商学院、工学院，承办单位为商务实践中心和 ModernTop-Union。
