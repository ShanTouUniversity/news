第七届广东大学生校园文化艺术节“飞 YOUNG 青春”广东大学生校园微电影大赛启动报名。广东省共青团、教育、文化部门和省学联希望通过微电影创作活跃高校校园文化，鼓励青年学生发挥个性特长，记录社会和校园生活，展现积极向上的精神风貌。

| 项目 | 信息 |
| --- | --- |
| 赛事 | “飞YOUNG青春”广东大学生校园微电影大赛 |
| 赛事背景 | 第七届广东大学生校园文化艺术节 |
| 创作方向 | 使用身边的简易拍摄工具，从不同角度记录社会和校园生活 |
| 参与对象 | 汕头大学学生 |
| 报名材料 | 《报名表》 |
| 校内提交截止时间 | 12月9日前 |
| 提交邮箱 | `o_tw@stu.edu.cn` |
| 校内推荐方式 | 校团委根据实际报名情况择优推荐 |

有意参赛学生须根据大赛通知填写报名表，并在截止时间前提交至校团委。具体作品要求、赛制和报名材料格式以转发通知的 OA 原文附件为准。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
>
> ⚠️ 大赛详细通知、报名表和作品要求请前往 OA 系统查看原文附件。
