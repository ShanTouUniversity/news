汕头大学工学院将举办第二届“MT-IDEAS”创意设计大赛，并在赛前开展“激发新意，创享未来”培训，帮助学生拓展创新思路、构思创意作品。培训面向全校师生，地点为 E 阶 202。

培训嘉宾为袁应亮，现为 MT 企业创新俱乐部创始人、汕头大学 2008 级计算机专业毕业生及汕头市辰谷科技公司创始人。

| 项目 | 信息 |
| --- | --- |
| 大赛 | 第二届“MT-IDEAS”创意设计大赛 |
| 赛前培训 | “激发新意，创享未来” |
| 培训时间 | 11月17日 |
| 培训地点 | E阶202 |
| 报名截止时间 | 11月21日23:00 |
| 作品提交截止时间 | 11月23日 |
| 初赛 | 11月25日 |
| 决赛 | 12月1日 |
| 组织单位 | 工学院团委、工学院MT企业创新俱乐部 |

大赛旨在鼓励学生树立创新意识、提升创新能力，营造校园创新氛围。具体参赛要求以工学院发布的赛事安排为准。

> 来源：汕头大学 OA 通知（工学院）
