汕头大学学生处发布 2011—2012 学年学校奖学金拟获奖名单公示。根据《汕头大学本科生奖学金管理办法》，学校在各学院（书院）推荐、相关评审委员会评审或助学工作管理中心审核的基础上，拟评定 1,746 名学生获得不同类别奖项。

| 奖项类别 | 拟获奖人数 |
| --- | ---: |
| 优秀学生奖学金 | 20名 |
| 一等学业优秀奖学金 | 177名 |
| 二等学业优秀奖学金 | 422名 |
| 三等学业优秀奖学金 | 626名 |
| 学术科技突出贡献奖 | 10名 |
| 杰出领导才能奖 | 10名 |
| 社会服务突出贡献奖 | 10名 |
| 文体突出贡献奖 | 10名 |
| 学术科技活动积极分子奖 | 47名 |
| 校园文化活动积极分子奖 | 150名 |
| 社会服务积极分子奖 | 140名 |
| 校园服务积极分子奖 | 144名 |
| **合计** | **1,746名** |

公示期内如有不同意见，应于 11 月 16 日（星期五）12:00 前向学生处助学工作管理中心（行政中心 106 室）提交书面材料，具体反馈要求以 OA 原文为准。

> 来源：汕头大学 OA 通知（学生处）
>
> ⚠️ 拟获奖学生名单请前往 OA 系统查看原文附件；本文不转载学生姓名及个人信息。
