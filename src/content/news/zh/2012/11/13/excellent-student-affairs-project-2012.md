据悉，学生处于11月13日发布通知，组织推荐参加广东省高校学生事务管理精品项目评选。

为贯彻落实中央及省关于加强和改进大学生思想政治教育的意见，推进学生事务管理的科学化、专业化，省高校学生工作专业委员会决定开展“精品项目”评选，现启动校内推荐工作。

## 评选安排

| 事项 | 内容 |
| --- | --- |
| 评选对象 | 由辅导员或学生工作团队持续开展三年以上并取得明显育人成效、影响广泛的学生工作项目 |
| 评选程序 | 项目主体向学生处申报 → 学生处评审并向省推荐1个候选项目 → 省专业委员会评审表彰 |
| 申报材料 | 《高校学生事务管理精品项目申报表》1份 + 以项目名为名的5000字左右项目材料（需含项目名称、理念、运作、效果、特色等） |
| 提交截止 | 2012年11月23日前 |
| 提交地点 | 学生教育管理科（行政中心106） |
| 电子版 | 以“学院名称+精品项目”命名打包发至 lslin@stu.edu.cn |
| 发布单位 | 学生处 |

申报表及撰写规范见 OA 附件。
