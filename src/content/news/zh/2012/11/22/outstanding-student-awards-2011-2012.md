汕头大学发布 2011—2012 学年优秀学生表彰决定，对在学习、学生工作、科技创新、社会服务和校园文化活动等方面表现突出的学生予以奖励。评定工作依据学校本科生奖学金管理办法进行。

### 表彰类别与人数

| 表彰类别 | 人数 |
| --- | ---: |
| 优秀学生奖学金 | 20人 |
| 一等学业优秀奖学金 | 177人 |
| 二等学业优秀奖学金 | 422人 |
| 三等学业优秀奖学金 | 626人 |
| 学术科技突出贡献奖 | 10人 |
| 杰出领导才能奖 | 10人 |
| 社会服务突出贡献奖 | 10人 |
| 文体突出贡献奖 | 10人 |
| 学术科技活动积极分子奖 | 47人 |
| 校园文化活动积极分子奖 | 150人 |
| 社会服务积极分子奖 | 140人 |
| 校园服务积极分子奖 | 144人 |

按照相关规定，获得国家奖学金的学生不再重复颁发优秀学生奖学金。具体获奖名单见学校 OA 原文附件，本文不转载学生姓名。
