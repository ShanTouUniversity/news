汕头大学图书馆开放中国资讯行（国际）有限公司搜数网数据库试用，试用期截至 2013 年 2 月 9 日。搜数网面向统计和调查数据提供专业检索服务，师生可在试用期间访问使用。

| 项目 | 信息 |
| --- | --- |
| 数据库 | 搜数网 |
| 试用截止日期 | 2013年2月9日 |
| 访问链接 | [图书馆数据库详情页](http://www.lib.stu.edu.cn/dbdetail.aspx?id=358) |
| 年鉴资源 | 5604多本 |
| 统计表格 | 116万张 |
| 数据时间范围 | 1949年至今 |
| 覆盖区域 | 全国31个省级行政区、254个地级市及县级行政区域，并含部分台港澳和国际地区 |
| 行业范围 | 54个行业大类 |

试用评价和意见可反馈至图书馆学科服务部，电话 `3247`，邮箱 `yxu@stu.edu.cn`。

> 来源：汕头大学 OA 通知（图书馆）
