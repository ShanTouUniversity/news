据悉，汕头大学西区36套教工宿舍修缮工程自2012年8月21日开工以来，施工过程中陆续发现多项原设计未涵盖、需据实增补的项目。资源管理处基建办经初步估算，上述预增项约需增加造价9.50万元，累计增幅在学校规定的10%以内。

## 主要增项情况

| 类别 | 具体内容 |
| ---- | ---- |
| 外墙 | 玻璃马赛克拆除后发现原墙体不平整、垂直度差，需增加抹灰底层厚度 |
| 地面 | 底层室内地面存在6cm高差，需增加混凝土找平层 |
| 门禁配件 | 原设计无门槛、门吸、窗帘盒、防蚊纱网，增设花岗岩门槛、不锈钢门吸、胶合板窗帘盒及不锈钢防蚊纱网 |
| 安全防护 | 厨房窗位于楼梯平台，为安全增设不锈钢防盗罩 |
| 水电设施 | 增设空调机出口墙孔、排油烟孔、空调机排水管道及排油烟管道；增设楼梯平台排水管及地漏；PVC地漏高度不符要求改为不锈钢地漏 |
| 卫生间 | 原设计无纸盒、毛巾架、热水管道，增设不锈钢纸盒、双管毛巾架及控制热水角阀；淋浴器、台盆因增设热水管道而增加混合水龙头 |

根据《汕头大学基建工程招标投标管理实施办法》的规定，基建办已对该项目预增项造价予以公示。如有不同意见，可在11月12日下午5:30前以书面形式向监察审计处或基建办反映。

> 来源：汕头大学 OA 通知（资源管理处基建办）
