汕头大学学生处和学生宿舍自我管理委员会启动第五届“我寝我秀”宿舍文化比赛，主题为“同一追求，‘家’随我秀！”。活动面向在校本科生，旨在丰富校园生活、促进宿舍成员及宿舍之间交流，展现学生社区文化。

| 项目 | 信息 |
| --- | --- |
| 比赛主题 | 同一追求，“家”随我秀！ |
| 参赛对象 | 在校本科生 |
| 活动时间 | 即日起至2012年12月7日 |
| 活动地点 | 科学报告厅 |
| 报名时间 | 11月12日至16日 |
| 组织单位 | 学生处、学生宿舍自我管理委员会 |

比赛以团队形式参加，每队 2—8 人；少于 4 人的团队，其成员所在宿舍不得超过 3 间。节目形式不限，可选择情景剧、才艺表演、小品、魔术、多口相声、舞蹈或合唱等，内容须健康、积极向上。

### 报名与奖励

参赛者可在宣传活动当天现场报名，也可领取纸质报名表，填写后投入各楼座宿委会宣传栏处或金三角的指定回收袋。电子报名表可通过 OA 系统下载，填写方式和提交渠道以原文为准。

| 奖项 | 数量及奖金 |
| --- | --- |
| 最精彩节目奖 | 1名，最高650元 |
| 最高人气奖 | 1名，最高600元 |
| 才艺表演奖 | 若干名，最高500元 |

表演时长为 5—10 分钟的队伍可获得完整活动比赛纪念光盘。相关咨询可关注新浪微博“@汕大宿委会”。
