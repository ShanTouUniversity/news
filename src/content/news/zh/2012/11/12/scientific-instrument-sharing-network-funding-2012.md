汕头大学中心实验室（分析测试中心）面向科研课题组发布广州地区科学仪器协作共用网专用资金申请安排。汕头大学是该协作网成员单位，符合条件的项目可申请网上仪器检测服务并享受检测费七折或六折优惠。

| 项目 | 信息 |
| --- | --- |
| 协作平台 | 广州地区科学仪器协作共用网（[www.gzsin.cn](http://www.gzsin.cn)） |
| 申请对象 | 汕头大学科研课题组 |
| 可申请项目 | 国家、广东省、中科院、广州市科技计划项目（含自然科学基金项目）；省级以上重点实验室、省公共实验室；入网单位与企业联合技术攻关项目 |
| 检测费优惠 | 七折或六折 |
| 受理方式 | 协作网管委会办公室随时受理 |
| 审核办理时限 | 形式审核合格后5个工作日内 |
| 咨询电话 | 82902740 |
| 咨询邮箱 | `yjlin@stu.edu.cn` |

课题组应向协作网管委会办公室（网办）提出申请。形式审核合格后，网办将在 5 个工作日内发放《专用资金使用卡》，或向申请单位返回加盖印章的《优惠检测登记表》。具体申报说明和办理流程以 OA 原文附件为准。

> 来源：汕头大学 OA 通知（中心实验室）
>
> ⚠️ 具体申报说明和流程请前往 OA 系统查看原文附件。
