为帮助 2012 级新生建立心理档案，汕头大学学生处将于 2012 年 11 月 3 日组织新生进行心理测评。计算机教学中心提供支持，学生可在规定时间内于教学楼 E 座 101、102 机房免费完成测试。

每名学生完成测评的时间为 60 分钟。学生登录心理咨询中心测评系统后，应先阅读测试说明，完善个人基本资料并修改初始登录信息，再进入“我的测试”完成全部 3 个量表。完成后可在“我的报告”查看个人测试结果，并通过“预约与咨询”提交咨询问题、选择咨询员及查看心理咨询中心的预约信息。

### 参加提示

测评账号应使用学校分配的个人账号登录，具体登录信息以学校通知为准。学生在校期间可使用个人账号查看咨询中心发送的预约信息。本文不公开学号、密码及任何学生测评结果。

| 项目 | 信息 |
| --- | --- |
| 测评对象 | 2012级全体新生 |
| 时间 | 2012年11月3日（星期六） |
| 地点 | 教学楼E座101、102机房 |
| 方式 | 心理咨询中心测评系统在线完成 |
| 时限 | 每人60分钟 |
| 内容 | 完成全部3个量表 |
