据悉，汕头大学教务处近日向文学院发布通知，转达全国高等学校外语专业教学指导委员会英语专业口试办公室关于2012年英语专业四级口语统测的报名安排。

根据通知，2012年英语专业四级口试统测时间定于2012年5月12日上午8:30举行。报名对象仅限于2010年入学的英语专业本科生。报名费为每人80元，采用网上报名方式，网上报名时间从2012年2月28日至3月7日。报名学生需在学分制专题网站上完成网上报名流程，财务处将于3月8日从报名学生的一卡通账户中统一扣取报名费。如扣款不成功，则报名失败。

| 项目 | 内容 |
|------|------|
| 考试时间 | 2012年5月12日 上午8:30 |
| 报名对象 | 2010年入学的英语专业本科生 |
| 报名费用 | 80元/人 |
| 报名时间 | 2012年2月28日—3月7日 |
| 缴费方式 | 3月8日从一卡通账户统一扣取 |
| 发布单位 | 教务处 |

> 来源：汕头大学 OA 通知（教务处）
