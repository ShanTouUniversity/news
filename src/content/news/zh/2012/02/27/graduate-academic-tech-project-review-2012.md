据悉，汕头大学研究生学院近日发布通知，将对2011年研究生课外学术科技立项项目进行终期评审。

根据学校关于研究生开展课外学术科技立项的通知和立项研发控制进度表要求，所有获得立项的项目负责人须于2012年3月8日前将书面的结项报告书（包括指导教师评价和签名）和立项作品提交到研究生学院郑枫超老师处（G座204室），并发电子版至邮箱o_yjsxsb@stu.edu.cn。立项作品包括已发表的研究论文、创业计划、专利、已建立的模型、调查报告、建议书等成果。

研究生学院提醒，未按规定提交结项报告书的项目，将被视为自动放弃项目，需收回项目追加经费。

| 项目 | 内容 |
|------|------|
| 评审类型 | 终期评审 |
| 截止时间 | 2012年3月8日 |
| 提交地点 | 研究生学院 G座204室（郑枫超老师） |
| 电子版邮箱 | o_yjsxsb@stu.edu.cn |
| 发布单位 | 研究生学院 |
