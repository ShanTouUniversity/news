据悉，长江艺术与设计学院于近期举办《中国记忆·王受之素描速写展》，面向全校师生开放参观。

展览以"中国记忆"为主题，展出王受之教授的多幅素描速写作品，通过画笔记录中国近现代历史变迁与社会风貌。

| 项目 | 内容 |
|------|------|
| 展览名称 | 中国记忆·王受之素描速写展（China, A Memory - Drawing & Sketch of Wang Shouzhi） |
| 展览时间 | 2012年2月7日—3月7日 |
| 展览地点 | 长江艺术与设计学院美术馆 |
| 主办单位 | 长江艺术与设计学院 |

展览展出多幅作品，欢迎师生前往观展。
