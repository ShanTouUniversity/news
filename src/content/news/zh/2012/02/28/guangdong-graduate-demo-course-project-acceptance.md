据悉，汕头大学研究生学院近日发布通知，根据广东省学位办《关于开展广东省研究生示范课程建设项目中期检查及结项验收工作的通知》（粤学位办〔2012〕8号）要求，将组织开展2012年广东省研究生示范课程建设项目结题验收工作。

验收范围为2009年立项的广东省研究生示范课程建设项目。项目所在单位须按照《广东省研究生示范课程建设项目实施管理暂行办法》的有关要求，对照立项项目申请书，组织专家组（不少于5人，其中校外专家不少于3人）进行初步验收，并完成项目结项验收报告书。

研究生学院提醒各单位认真组织该项工作，严格制订验收工作程序，安排专人跟进项目实施情况，确保项目进度和质量。请相关单位在2012年4月26日前将结项验收书面材料一式两份报送研究生学院，同时将电子文档发送至xwb@stu.edu.cn。

| 项目 | 内容 |
|------|------|
| 验收范围 | 2009年立项的广东省研究生示范课程建设项目 |
| 验收方式 | 专家组初步验收（不少于5人，校外专家不少于3人） |
| 截止时间 | 2012年4月26日 |
| 材料要求 | 书面材料一式两份 + 电子文档 |
| 报送邮箱 | xwb@stu.edu.cn |
| 发布单位 | 研究生学院 |
