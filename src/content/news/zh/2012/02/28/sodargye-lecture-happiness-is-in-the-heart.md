据悉，汕头大学至诚书院将于2012年3月2日（星期五）晚举办第十一期至诚讲坛，邀请著名学者索达吉堪布作题为"幸福的根本是心"的专题演讲。

索达吉堪布是四川甘孜炉霍人，"上海慈惠公益基金会"名誉理事长，著名慈善理论家、活动家、翻译家。他学识渊博，讲课不持稿却引经据典、妙语连珠，对佛教教证公案如数家珍，同时对古今中外各个领域的知识均有涉猎，从孔孟老庄到秦皇汉武、唐宗宋祖，从分子原子到量子场和真空，都能深入浅出地讲授。近年来曾先后应邀到北京大学、清华大学、人民大学、复旦大学、南京大学等高校开展交流，与众多知识分子共同探讨幸福人生真谛。

| 项目 | 内容 |
|------|------|
| 讲坛主题 | 幸福的根本是心 |
| 主讲人 | 索达吉堪布 |
| 讲座时间 | 2012年3月2日（星期五）19:30—21:30 |
| 讲座地点 | 新图书馆报告厅 |
| 主办单位 | 至诚书院 |
| 报名方式 | 3月1日17:30前登录 http://activity.stu.edu.cn/ 预约 |

热诚欢迎全校师生参加。
