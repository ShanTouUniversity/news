据悉，汕头大学至诚书院与文学院联合举办第九期职业生涯规划分享会，邀请2011届毕业生、《羊城晚报》记者赖丽思回校分享其大学生活及择业就业经历。

赖丽思是汉语言文学2011届毕业生，至诚书院首期入住宿生，2011年汕大奖章获得者。她曾在2010年暑假获李嘉诚基金会赞助，参加香格里拉高级项目。分享会主题为"我的大学和我的新闻之路"。

| 项目 | 内容 |
|------|------|
| 分享会主题 | 我的大学和我的新闻之路 |
| 主讲人 | 赖丽思（《羊城晚报》记者，汕大2011届毕业生） |
| 分享时间 | 2012年3月3日（周六）10:00—11:30 |
| 分享地点 | 科学楼205科报厅 |
| 主办单位 | 文学院、至诚书院 |
| 报名截止 | 2012年3月1日 22:00 |
| 录取通知 | 3月2日中午前邮件通知 |

有意参加的同学请以"年级+专业+姓名+手机号-分享会（九）报名"为标题发送邮件至 o_zctw@stu.edu.cn 报名。

> 来源：汕头大学 OA 通知（文学院、至诚书院）
