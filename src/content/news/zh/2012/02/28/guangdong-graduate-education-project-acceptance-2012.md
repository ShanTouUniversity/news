据悉，汕头大学研究生学院近日发布通知，根据广东省学位办《关于开展广东省学位与研究生教育改革研究项目中期检查及结题验收工作的通知》（粤学位办〔2012〕7号）要求，将组织开展2012年学位与研究生教育改革研究项目结题验收工作。

验收范围为2010年立项的面上项目和自筹项目。项目所在单位须按照《广东省学位与研究生教育改革研究项目实施管理暂行办法》的有关要求组织成果鉴定和初步验收，完成后填写结题验收表。

研究生学院提醒各单位认真组织该项工作，严格制订验收工作程序，安排专人跟进有关项目的实施情况，确保项目实施的进度和质量。请相关单位在2012年4月24日前将结题验收的书面材料一式两份报送研究生学院，同时将电子文档发送至xwb@stu.edu.cn。

| 项目 | 内容 |
|------|------|
| 验收范围 | 2010年立项的面上项目和自筹项目 |
| 截止时间 | 2012年4月24日 |
| 材料要求 | 书面材料一式两份 + 电子文档 |
| 报送邮箱 | xwb@stu.edu.cn |
| 发布单位 | 研究生学院 |
