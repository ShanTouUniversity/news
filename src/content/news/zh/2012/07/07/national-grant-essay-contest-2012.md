据悉，学生处于7月7日转发省教育厅通知，组织开展“国家资助 助我成长”主题征文活动。

活动由广东省教育厅主办，旨在宣传国家和省学生资助政策，展现家庭经济困难学生资助工作成就，加强励志感恩教育。根据全国学生资助管理中心通知精神，面向获得国家资助的高校、中职及普高在校生和当年毕业生征集稿件。

## 征文要求

| 事项 | 内容 |
| --- | --- |
| 主题 | 国家资助 助我成长 |
| 对象 | 获国家资助的在校生及当年毕业生 |
| 字数 | 正文不超过4000字，题目体裁不限 |
| 内容 | 体现受助学生不畏困难、积极进取、奋发学习、自立自强、诚信感恩、成长成才的精神面貌 |
| 要求 | 严禁抄袭、未公开发表、获奖作品使用权归主办方 |
| 格式 | A4纸、页边距2厘米、行距1.25倍，正标题小二黑体加粗等（详见附件） |

## 评选与投稿

| 事项 | 内容 |
| --- | --- |
| 奖项 | 优秀征文奖分四类各设一等奖10名、二等奖20名、三等奖30名；另设优秀组织奖 |
| 评审方式 | 逐级选送、逐级评审，省厅聘请专家终评，部分优秀作品报送全国 |
| 投稿方式 | 填写《征文推荐表》连同Word稿件发至指定邮箱，邮件主题注明“助我成才征文+姓名+学院” |
| 截止时间 | 2012年8月26日 |
| 承办单位 | 省学生助学管理中心及广东教育杂志社 |

征文推荐表及投稿邮箱见 OA 附件，已作隐私保护不在此转载。
