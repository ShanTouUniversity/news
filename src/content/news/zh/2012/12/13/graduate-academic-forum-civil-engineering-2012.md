汕头大学第八届研究生学术论坛土木工程分论坛将于 2012 年 12 月 15 日（星期六）上午 8:00 至 12:00 在 E204 举行。论坛由研究生学院主办、土木工程方向承办，主题为“土木工程研究”，面向全校研究生及对学术研究感兴趣的本科生，欢迎教师参加指导。

本场论坛安排 12 项研究报告，主题涵盖岩土工程、结构工程、建筑材料、工程模拟、地理信息系统和房地产估价等方向：

| 研究主题 | 主要内容 |
| --- | --- |
| 软土动力性能 | 汕头淤泥质软黏土的动力性能分析 |
| 钢结构分析 | 顶底角钢的弹塑性分析 |
| 泡沫混凝土 | 膨胀石墨对泡沫混凝土保温与力学性能的基础研究 |
| 桩基承载性能 | 基于 ABAQUS 的竖向荷载下超长单桩承载性能研究 |
| 林火模拟 | 基于地理元胞自动机的林火蔓延三维动态模拟 |
| 房地产估价 | GIS 技术与模糊理论的应用 |
| 断裂演化 | 界面非均匀破裂演化规律 |
| 木材防水 | 环氧树脂胶粘剂涂覆木材的防水性能试验 |
| 混凝土界面 | 预填骨料混凝土界面性能分析 |
| 连接耗能 | 斜支撑半刚性连接的耗能模拟 |
| 半刚性节点 | 基于 ABAQUS 的双腹板、顶底角钢半刚节点性能分析 |
| 超长桩研究 | 基于无网格法的超长桩承载性能研究进展 |

论坛还邀请李庚英、吴鸣和刘纪陆担任特邀嘉宾。通过研究成果展示和学术讨论，论坛旨在拓展研究生学术视野，促进学科交流和研究成果传播。
