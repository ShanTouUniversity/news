汕头大学工会启动 2012 年度全国巾帼建功标兵校内推荐工作。全国妇联计划在 2013 年“三八”国际妇女节期间开展全国城乡妇女岗位建功先进集体和先进个人评选表彰，汕头市妇联分配汕头大学 1 个全国巾帼建功标兵推荐名额。

学校各单位可推荐符合条件的先进女性个人。候选人应在本职岗位业绩突出、职业技能和服务表现优秀，在单位或行业具有示范带动作用，并具备良好职业道德、务实作风和文明服务素养，原则上应已获得省级或行业系统荣誉称号。

| 项目 | 信息 |
| --- | --- |
| 推荐奖项 | 全国巾帼建功标兵 |
| 汕大推荐名额 | 1个 |
| 表彰时间 | 计划于2013年“三八”国际妇女节期间 |
| 推荐对象 | 校本部各单位先进女性个人 |
| 主要事迹字数 | 不超过1500字 |
| 校内截止时间 | 2012年12月17日（星期一）下班前 |
| 报送材料 | 推荐名单及先进个人推荐表 |
| 报送单位 | 校工会 |
| 报送邮箱 | `o_xgh@stu.edu.cn` |

推荐材料中的主要事迹应突出重点、文字简练。各单位须在截止时间前将推荐名单和推荐表发送至校工会，由学校按程序完成校内推荐。
