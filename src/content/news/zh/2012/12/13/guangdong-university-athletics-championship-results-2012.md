2012 年广东省大学生田径锦标赛于 12 月 9 日在华南理工大学结束。汕头大学田径队在比赛中获得男子 1500 米银牌和男子 800 米铜牌，另有 2 个第五名、2 个第七名和 1 个第八名，共 11 人次取得名次。

本届比赛共有全省 69 所高校、1,167 名运动员参加。汕大田径队由丁凤华老师担任教练，12 名队员参加甲组 7 个项目，最终团体总成绩排名第 15，男子组总分排名第 10。

| 成绩 | 项目或统计 |
| --- | --- |
| 银牌 | 男子1500米 |
| 铜牌 | 男子800米 |
| 第五名 | 2项 |
| 第七名 | 2项 |
| 第八名 | 1项 |
| 获奖人次 | 11人次 |
| 汕大参赛队员 | 12名 |
| 参赛项目 | 甲组7个项目 |
| 团体总成绩 | 第15名 |
| 男子组总分 | 第10名 |
| 教练 | 丁凤华老师 |

汕大田径队在比赛中的表现体现了队员的竞技水平和团队协作精神。
