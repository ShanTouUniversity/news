汕头大学发布汕大发〔2012〕158 号文件，公布《汕头大学教职员工绩效考核办法（试行）》。该办法经 2012 年 11 月 20 日第 14 次校领导会议讨论通过，自发布之日起实施，原《汕头大学教职员工学年度考核管理暂行办法》（汕大发〔2009〕114 号）同时停止执行。

新办法面向全职聘用人员，建立学年度考核和聘期考核制度。学年度考核是聘期考核的组成部分，也是下一聘期岗位和等级聘任的重要依据，考核记录和结果存入个人档案。学年度考核周期为每年 8 月 1 日至次年 7 月 31 日，通常在夏季学期进行；考核期内在校工作时间不足半年的教职员工一般不参加当年度考核。

### 考核组织和内容

学校成立考核领导小组，负责审定各单位学年度考核结果，考核领导小组办公室设在人事处。各单位可单独或联合成立考核小组，专业学院考核小组至少由 5 人组成，其他单位至少由 3 人组成，并负责制定本单位考核细则、审核考核结果。

考核对象包括专任教师、行政管理人员、教辅类专业技术人员和工勤技能人员等全职聘用人员。学校按照聘用合同约定的岗位职责，综合考核教职员工的德、能、勤、绩、廉：

| 考核对象 | 重点内容 |
| --- | --- |
| 教师 | 教学、科研和服务；教学工作是重点，鼓励将主要精力投入教学和创新人才培养 |
| 中初级管理人员 | 工作态度、工作能力、工作作风、协作精神和工作实绩 |
| 高级管理人员 | 廉洁自律、政策水平、领导能力、工作态度、工作作风、协作精神和工作实绩 |
| 教辅类专业技术人员 | 服务教学科研的态度、业务技术水平和岗位职责履行情况 |
| 工勤技能人员 | 服务态度、操作技能、安全生产、工作数量和质量及任务完成情况 |
| 学术单位负责人 | 战略规划与实施、教学质量、教育改革、人才引进、招生就业、科研和学科建设、考核聘任及领导能力 |

### 结果等级和程序

绩效考核结果分为五个层次：非常优秀、超越期望、符合期望、需要提高和不合格。其中，前两档分别对应优秀和合格等级，符合期望对应合格等级，需要提高对应基本合格等级，不合格对应不合格等级。各单位推荐“非常优秀”的人数不得超过实际参加考核人数的 15%；“非常优秀”和“超越期望”合计人数不得超过实际参加考核人数的 30%。

教师须在夏季学期第一周提交相应考核登记表和年度工作表，由系或相应机构从教学、科研、服务三方面开展初步评价并与被考核人沟通，学院考核小组在前四周内审议结果。行政、教辅和工勤人员按岗位职责、工作实绩和服务质量接受单位考核；学术单位负责人和高级管理人员按相应管理职责接受逐级评价和学校考核领导小组审定。

各单位应在夏季学期前四周内完成评价、沟通和结果报送，并告知被考核人。学校考核领导小组办公室将在校内办公信息网上公示单位推荐的优秀等级人员名单，公示结束后公布最终优秀等级名单。

| 项目 | 规定 |
| --- | --- |
| 考核周期 | 每年8月1日至次年7月31日 |
| 实施时间 | 夏季学期，原则上前四周完成单位考核 |
| 最高等级比例 | “非常优秀”不超过实际参评人数15% |
| 前两档合计比例 | “非常优秀”与“超越期望”合计不超过30% |
| 结果用途 | 聘期考核、续聘、岗位聘任和绩效工资等 |
| 申诉期限 | 被告知考核结果之日起5个工作日内 |

考核结果主要用于聘期考核、人员续聘及岗位聘任建议，并与绩效工资挂钩。对“需要提高”的人员，学校可视情况调整岗位或薪酬；对“不合格”的人员，可视情况采取降职或解聘等处理。教职员工如对单位或分管校领导审核的结果有异议，可依照汕大发〔2012〕27 号文件提出校内申诉，或向学校考核领导小组办公室投诉。
