据悉，长江艺术与设计学院艺术教育中心于12月26日发布通知，公布本学期《戏剧欣赏与戏剧批评》课程期末考核安排。

选修该课程（开课班号56562，任课教师林克欢）的同学，需在2012年12月31日12:00前完成并提交期末考核论文。

## 考核安排

| 事项 | 内容 |
| --- | --- |
| 课程 | 《戏剧欣赏与戏剧批评》（班号56562，任课教师林克欢） |
| 题目 | 简述你对《戏剧欣赏与戏剧批评》课程的理解 |
| 字数 | 1000至1200字 |
| 提交截止 | 2012年12月31日12:00前 |
| 提交方式 | 电子版发送至 o_ysjyzx@stu.edu.cn |
| 发布单位 | 长江艺术与设计学院、艺术教育中心 |

请选修该课程的同学相互告知并按时提交，具体要求见 OA 原文。

> 来源：汕头大学 OA 通知（长江艺术与设计学院、艺术教育中心）
