汕头大学理学院团委启动第十四次课外活动立项申报，面向学院学生会、青年志愿者协会、明理报、无线电俱乐部、各系团总支、班级及其他学生团队征集活动方案。

本次申报围绕“明理笃行、博识专能”的人才培养理念，鼓励学生通过自我管理、自我教育和自我服务活动提升团队合作、沟通协作和领导能力。申报项目分为公益奉献、体育精神、职业拓展、人文素养、领袖才能、创新创造六大主题，活动形式不限。

| 项目 | 信息 |
| --- | --- |
| 申报批次 | 理学院第十四次课外活动立项 |
| 申报对象 | 学生组织、各系团总支、班级及学生团队 |
| 主题类别 | 公益奉献、体育精神、职业拓展、人文素养、领袖才能、创新创造 |
| 活动形式 | 不限 |
| 报名截止 | 2012年12月6日12:00 |
| 答辩时间 | 初定2012年12月12日 |
| 初审部门 | 理学院团委 |

申报团队需下载并填写《汕头大学理学院课外活动立项申报表》，按要求提交电子版。理学院团委将依据《理学院课外活动立项申报及管理办法》对方案进行初审，后续通过答辩确定立项项目。入选活动将为学生提供拓展视野、锻炼能力和参与校园服务的机会。

> 来源：汕头大学 OA 通知（理学院团委）
>
