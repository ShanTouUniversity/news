汕头大学保卫处发布户籍服务安排，为户口已迁入汕头大学但尚未变更身份证户口所在地的学生、教职工及家属提供集中办理服务。学校方面表示，相关人员约有 654 人；2012 年新生户口落户工作也已基本完成，公安机关已做好相应办理准备。

办理服务安排在 2012 年 12 月每周三 14:30 至 17:00 进行，地点为校邮局二楼保卫办。需要办理的人员应按通知准备数字相片质量检测回执、照片及身份证原件，身份证原件仅供现场核对。

| 项目 | 信息 |
| --- | --- |
| 服务事项 | 变更身份证户口所在地 |
| 适用人群 | 户口已迁入汕头大学但尚未办理变更的学生、教职工及家属 |
| 涉及人数 | 约654人 |
| 办理时间 | 2012年12月每周三14:30—17:00 |
| 办理地点 | 校邮局二楼保卫办 |
| 保卫办电话 | 86503436 |
| 户籍室电话 | 82756003 |

办理人员应按要求携带材料，并以现场工作人员指引为准。新生户口所在地变更手续也纳入此次公安机关服务准备范围。
