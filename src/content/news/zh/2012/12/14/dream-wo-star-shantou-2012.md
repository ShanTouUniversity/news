据悉，共青团汕头大学委员会、学生社团联合会与职业规划与发展协会于12月14日发布通知，将承办首届广东大学生“梦想沃之星”职场风采挑战赛汕头赛区比赛。

该赛事由团省委、省学联与广东联通联合举办，以“梦想与沃同行”为主题，通过分赛区比赛、专业培训及全省决赛开展职业技能比拼，促进就业创业。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 对象 | 全校学生（不限年级专业） |
| 时间 | 2012年12月25日19:00—21:00 |
| 地点 | 科学报告厅 |
| 主题演讲 | 做最优秀的自己，主讲人：广东卫视主持人王牧笛 |
| 主办 | 校团委承办汕头赛区 |
| 报名时间 | 12月13日至17日 |

## 报名与选拔

| 环节 | 内容 |
| --- | --- |
| 报名方式 | 微博报名：制作图片长微博形式的微博个人秀，含姓名、照片、联系方式、院校年级专业、主要经历及梦想宣言，发布话题#“梦想沃之星”挑战赛-汕头大学赛区报名#并@广东学联等三账号，成功报名可参与抽奖 |
| 晋级方式 | 报名微博转发量赛区第一直接晋级；其余由联通专员与学校老师组成评委团按内容50%、创意30%、人气20%筛选7人晋级，共8人参加现场赛 |
| 现场赛 | 以“秀出未来最优秀的自己”为主题，每人8分钟（自我介绍1分钟、主题展示4分钟、专家提问3分钟），评委团与学生评审团分别打分，决出3名选手晋级全省决赛 |

评分涵盖表达、形象、内容、创意及应变能力各20%。其他奖项及详情见 OA 附件。
