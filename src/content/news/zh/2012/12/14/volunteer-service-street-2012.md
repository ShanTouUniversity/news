汕头大学青年志愿者协会联合各学院青年志愿者协会和至诚书院“常青藤”服务学习协会，将于 2012 年 12 月 16 日在学校步行街举办“12·5 国际志愿者服务日”之“校内服务一条街”活动。活动旨在服务师生，推广“奉献、友爱、互助、进步”的志愿者精神。

活动期间，各志愿服务组织将设置不同主题的服务摊位：

| 组织 | 服务内容 |
| --- | --- |
| 文学院青年志愿者协会 | 在校门口、金三角等位置提供出市区便利服务；开设粤语、潮汕话和普通话纠正等方言小课堂；在力所能及范围内帮助有需要的同学解决问题 |
| 医学院青年志愿者协会 | 提供基础健康服务和急救知识教学，开展止血包扎、心肺复苏等应急技能介绍；通过宣传短片、折纸活动和知识问答推广关爱自闭症儿童理念 |
| 新闻学院青年志愿者协会 | 设置“爱心墙”，收集校园生活中的求助和互助需求；收集书刊、报纸等可循环利用物资，用于公共用品、公益组织或慈善机构 |
| 商学院青年志愿者协会 | 介绍养生汤、糖水、凉茶及其他日常食品的制作方法，并提供样品供师生品尝 |
| 理学院青年志愿者协会 | 通过“理青协邮局”免费在校内寄送明信片，传递祝福 |
| 法学院青年志愿者协会 | 开展吊扇清洁美化服务，具体登记和服务安排以现场要求为准 |
| 艺术学院青年志愿者协会 | 开展毛线公仔制作、现场头像速写、中国结编制、书法演示和 DIY 手绘明信片义卖，义卖收入捐给残疾人联合组织 |
| 工学院青年志愿者协会 | 提供电风扇、电饭煲、热水器、应急灯、音箱和电灯等电器的义务维修，并通过“心灵呼唤”倡导参与志愿服务和健康生活 |
| 至诚书院“常青藤”服务学习协会 | 设置大型互动墙，提供任务互助、物品交流和公益物资收集等服务，并与新闻学院青年志愿者协会合作开展物资公益项目 |

活动地点为汕头大学步行街。部分服务有名额、范围或现场登记等具体要求，师生可到相应摊位了解安排。涉及互助留言和物资收集的服务，应遵守现场管理要求，不在公开区域留下不必要的个人联系方式。
