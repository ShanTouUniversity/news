汕头大学学生处启动 2013 年度“汕头大学境外进修资助计划”评选准备工作，向各学院征集境外候选学校补充名单。该计划由李嘉诚基金会资助，支持学术表现优异、具备创新发展潜能的汕大学生到中国大陆境外的优秀学府进修，培养具有国际经验和视野的人才。

目前计划只接受本科生赴境外修读硕士的申请。学生最多可申请 3 所学校，且申请学校须列入学校提供的候选名单。学生处参考世界大学排名列出了世界排名前 200 名的学校，各学院还可从专业角度补充推荐未进入前 200 名、但在相关专业领域具有较高素质和学术地位的境外院校。

| 项目 | 信息 |
| --- | --- |
| 计划 | 2013年度汕头大学境外进修资助计划 |
| 资助方 | 李嘉诚基金会 |
| 当前申请对象 | 本科生赴境外修读硕士 |
| 学校申请数量 | 最多3所 |
| 候选学校要求 | 必须来自学校候选名单 |
| 补充名单内容 | 前200名之外、专业实力和学术地位较高的境外院校 |
| 提交截止 | 2012年12月24日 |
| 提交邮箱 | xyli@stu.edu.cn |
| 负责单位 | 学生处 |

各学院须于截止时间前将补充学校名单发送至学生处。李嘉诚基金会将结合各学院意见，确定 2013 年度计划候选学校名单。
