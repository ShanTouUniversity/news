为回顾和展示 2012 年校园文化活动，汕头大学学生处计划编印《汕头大学 2012 年校园文化巡礼·海报集》，现面向各有关单位征集本年度组织开展的校园文化活动海报稿。征集范围包括各类文体活动、讲座和工作坊等。

各单位应于 12 月 31 日前按学生处指定方式提交材料。海报应为电子版，优先提交 AI、CDR、PSD 等格式的设计原稿；如提交 JPG 图片，分辨率须不低于 300 dpi（300 像素/英寸）。同时应填写《2012 年活动海报说明》，与海报稿一并放入文件夹，文件夹按“单位—活动名”命名。

| 项目 | 信息 |
| --- | --- |
| 征集内容 | 2012年校园文化活动海报稿 |
| 活动范围 | 文体活动、讲座、工作坊等 |
| 提交截止 | 12月31日 |
| 推荐格式 | AI、CDR、PSD等设计原稿 |
| 图片要求 | JPG分辨率不低于300 dpi |
| 附加材料 | 《2012年活动海报说明》 |
| 文件夹命名 | “单位—活动名” |
| 负责单位 | 汕头大学学生处 |

材料提交渠道由学生处另行指定。相关单位如有疑问，可通过 82903299 或 `o_xsc@stu.edu.cn` 联系李老师。

> 来源：汕头大学 OA 通知（学生处）
