汕头大学第六届阳光体育冬季长跑活动将于 2012 年 12 月启动，主题为“热爱祖国从体育锻炼开始”。活动由汕头大学体育运动委员会组织，面向各学院和至诚书院开展，旨在通过持续长跑锻炼增强学生耐力、磨炼意志并培养集体意识。

起跑仪式定于 12 月 8 日（星期六）15:30 在校训碑处举行，各学院和书院须组织不少于 60 名学生参加，环校道跑一圈，距离约 2 公里。2012 年 12 月至 2013 年 4 月期间，各单位还将按活动日程组织每周环校道长跑，原则上每次不少于 100 名学生参加。

| 项目 | 安排 |
| --- | --- |
| 活动主题 | 热爱祖国从体育锻炼开始 |
| 活动时间 | 2012年12月至2013年4月30日 |
| 起跑仪式 | 2012年12月8日15:30，校训碑处 |
| 长跑路线 | 环校道一圈，约2公里 |
| 起跑仪式规模 | 各学院（书院）不少于60名学生 |
| 常规活动规模 | 各单位每次不少于100名学生 |
| 结束统计 | 2013年4月30日17:00 |

各学院和书院学生会还应利用早操及下午课外活动时间组织集体长跑，以每人每天 2,000 米作为参考距离基数，记录并统计参与人数和里程。每周一由各单位学生会体育部长向体育部办公室报送上周总人数、总里程及活动照片，统计结果将作为优秀单位奖和优秀个人奖评选的重要依据。

### 活动安排

| 日期 | 内容 |
| --- | --- |
| 12月8日 | 全校起跑仪式 |
| 12月17日 | 开始统计每周课外长跑人数和里程 |
| 12月19日 | 至诚书院环校道长跑 |
| 12月26日 | 文学院环校道长跑 |
| 2013年1月16日 | 学期小结 |
| 2月27日 | 重新启动活动及体育部长会议 |
| 3月6日至4月24日 | 工学院、法学院、商学院、长江新闻与传播学院、长江艺术与设计学院、医学院、研究生学院和理学院依次组织环校道长跑 |
| 4月30日 | 活动结束，截止统计里程 |
| 5月7日至15日 | 优秀单位奖候选、评选及总结表彰 |

学校还将把长跑纳入体育课教学内容，将男生 1000 米和女生 800 米列为考试项目，占体育课总成绩的 20%。活动结束后，评选小组将评出 4 个“优秀单位奖”和 30 个“优秀个人奖”，分别颁发奖杯和奖状。优秀单位评选将重点考察组织宣传、参与覆盖、完成长跑里程及活动安全等情况。
