为提升科学楼会场管理和服务水平，汕头大学科研处在网络中心支持下启动科学楼会场网上预约系统试运行。系统覆盖科学楼报告厅和 205 会议室，自 2012 年 12 月 5 日起开放。

系统目前仅限汕头大学教职工登录预约。预约人需从科研处主页进入“汕头大学科学楼会场预约系统”，依次选择“活动和场地预约”“我的事务”“科学楼场馆预约”等功能，待预约审核通过后打印《科学楼会场预订单》，由主办单位负责人签章，再送至科学楼门房。

| 项目 | 信息 |
| --- | --- |
| 系统 | 汕头大学科学楼会场网上预约系统 |
| 试运行时间 | 2012年12月5日起 |
| 可预约场地 | 科学楼报告厅、科学楼205会议室 |
| 预约对象 | 汕头大学教职工 |
| 审核后流程 | 打印预订单、主办单位负责人签章、送至科学楼门房 |
| 使用前要求 | 阅读《使用须知》 |
| 意见反馈 | o_kyc@stu.edu.cn |
| 咨询电话 | 86502583 |

科研处欢迎教职工在试运行期间提出意见和建议。具体使用规则以系统页面和科研处发布的《使用须知》为准。

> 来源：汕头大学 OA 通知（科研处）
