汕头大学学生处启动 2012 年度学生工作系统“金凤奖”评选，旨在表彰先进、加强学生工作队伍建设，并促进学生培养质量提升。评选依据《汕头大学学生工作系统“金凤奖”评选办法》开展。

评选对象包括学生处、校团委、人民武装部工作人员，以及各学院、书院学生工作者。申报人须在汕头大学连续工作 3 年以上，曾未获得同一奖励，由本人提出申报并经上级领导确认，在本职工作中取得显著成绩。

评选重点考察工作投入和工作成绩，包括是否模范履行岗位职责、持续投入学生工作，以及在学生培养、服务和支持方面作出突出或持续性贡献。

| 项目 | 信息 |
| --- | --- |
| 奖项 | 学生工作系统“金凤奖” |
| 评选年度 | 2012年度 |
| 评选对象 | 学生处、校团委、人民武装部及学院（书院）学生工作队伍人员 |
| 工作年限 | 在汕大连续工作3年以上 |
| 其他条件 | 未获同一奖励、工作成绩显著、经上级领导确认 |
| 申报截止 | 2012年12月15日 |
| 报送地点 | 学生处106室 |
| 联系电话 | 86503299 |

申报材料包括《学生工作系统“金凤奖”申请表》、候选人工作自述以及上级领导对候选人工作表现的说明。申报人须在截止日前将材料报送学生处 106 室，并按要求提交表格电子版。
