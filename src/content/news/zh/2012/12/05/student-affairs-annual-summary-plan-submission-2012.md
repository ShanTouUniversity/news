汕头大学学生处部署各学院、书院 2012 年度学生工作总结和 2013 年度工作计划报送工作。各单位需围绕学校育人目标，总结过去一年的工作经验和特色，并结合学校及本单位发展目标谋划下一年度工作。

总结和计划应覆盖奖助贷、思想教育、互助学习、社区辅导、就业、创业、素质拓展、校园文化建设及团务等学生工作领域。涉及重大工作或活动的，应列明启动和结束时间。

| 材料 | 主要要求 |
| --- | --- |
| 2012年度学生工作总结 | 总结工作经验、特色和实际成效，涵盖学生工作及团务工作 |
| 2013年度学生工作计划 | 依据学校和学院（书院）发展目标制定，明确重点工作 |
| 重大工作及活动 | 列明启动和结束时间 |

各学院、书院须于 2012 年 12 月 20 日前将纸质材料交至学生处 106 室，纸质材料需加盖学院党总支印章；电子文档按要求发送至学生处工作邮箱。

| 项目 | 信息 |
| --- | --- |
| 报送单位 | 各学院、各书院 |
| 截止时间 | 2012年12月20日 |
| 纸质材料地点 | 学生处106室 |
| 纸质材料要求 | 加盖学院党总支印章 |
| 电子材料 | 发送至学生处工作邮箱 o_xsc@stu.edu.cn |
| 负责部门 | 汕头大学学生处 |

学生处将以年度总结和计划为基础，进一步梳理各单位学生工作的成效与重点安排。

> 来源：汕头大学 OA 通知（学生处）
