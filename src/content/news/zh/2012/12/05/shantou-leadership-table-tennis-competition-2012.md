汕头市体育局将于 2012 年 12 月 22 日至 24 日举办“国寿杯”领导干部乒乓球比赛，汕头大学工会面向符合条件且有意参赛的校内人员征集报名。比赛地点为汕头市乒乓球学校。

赛事面向各区（县）、市直、中直、省直驻汕单位及驻汕部队的现职和离退休副处级以上领导干部。比赛设团体赛、男子单打、女子单打和男女混合双打项目，混合双打允许跨单位组合，但跨单位组合不超过一对。

| 项目 | 信息 |
| --- | --- |
| 比赛 | 汕头市“国寿杯”领导干部乒乓球比赛 |
| 时间 | 2012年12月22日至24日 |
| 地点 | 汕头市乒乓球学校 |
| 参赛对象 | 现职和离退休副处级以上领导干部 |
| 比赛项目 | 团体、男子单打、女子单打、男女混合双打 |
| 报名截止 | 2012年12月10日 |
| 代表队会议及抽签 | 2012年12月12日15:00，汕头市乒乓球学校 |
| 汕大报名渠道 | 校工会 |
| 校工会电话 | 82902983 |

团体赛每单位报名 3 名队员，男子单打分为现职和离退休副厅级以上干部组、现职和离退休副处级以上干部组，前一组别选手可参加后一组比赛；女子单打不分组。团体赛第一阶段采用循环赛，第二阶段采用淘汰赛及附加赛；单打和双打赛制根据报名情况确定。所有比赛采用五局三胜、每局 11 分制，执行中国乒协《乒乓球竞赛规则（2011）》。

团体赛和各单项均奖励前 8 名（参赛人数不足时按规程递减录取）。团体赛第一名至第八名奖金分别为 1,000 元、800 元、700 元、600 元和 400 元；男子单打、女子单打及混合双打各单项第一名至第八名奖金分别为 600 元、500 元、400 元、300 元和 200 元。各参赛队的食宿、交通等费用自理。

需说明的是，OA 通知正文将赛事称为“第三届”，所附竞赛规程标题称为“迎新年第五届”，本文因此不对届次作统一判断，具体以组委会正式发布为准。
