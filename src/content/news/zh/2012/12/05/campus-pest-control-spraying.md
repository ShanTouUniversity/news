据悉，为进一步改善校园环境卫生、加强植物病虫害防治，汕头大学资源管理处将于12月16日至23日期间，对校区及成教学院的绿地花木、果树及水沟进行喷药作业，并提醒师生员工在此期间注意安全。

## 分区喷药日程

| 日期 | 作业区域 |
| ---- | -------- |
| 12月16日 | 附中、附小至精神卫生中心 |
| 12月17日 | 人工湖区域、运动场 |
| 12月18日 | 学术交流中心周围、P楼、学生宿舍区 |
| 12月19日 | 水库坝、789号楼、A-B教工宿舍区 |
| 12月20日 | 医科楼、新教学楼、G/H/I/J座学生宿舍 |
| 12月21日 | 校卫队办公场地周边、校门口、各校道、新图书馆外围 |
| 12月22日 | 食堂、行政楼周围 |
| 12月23日 | 成教学院 |

## 灭蚊行动先行展开

在喷药作业之外，学校还将于本月8日至9日加强学生宿舍区及新行政中心的灭蚊工作。报道称，相关区域的门窗须在7日下班后全部关闭，以配合灭蚊作业的开展。

> 来源：汕头大学 OA 通知（资源管理处）
