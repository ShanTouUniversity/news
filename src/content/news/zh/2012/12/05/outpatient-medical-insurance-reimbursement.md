据悉，近日不少教职工就城镇职工基本医疗保险普通门诊费用统筹政策向学校咨询。资源管理处就此发布说明，介绍相关政策要点。

根据《关于实施城镇职工基本医疗保险普通门诊医疗费用统筹的意见》（汕人社发〔2012〕2号），该文件已于2012年7月2日在校内办公信息网公布。自2012年7月1日起，参保人到定点医疗机构就医时，医疗保险统筹基金将按50%的比例支付其门诊基本医疗费（含一般诊疗费），每人每月限额为20元。

| 项目 | 内容 |
| ---- | ---- |
| 政策依据 | 汕人社发〔2012〕2号文 |
| 实施时间 | 2012年7月1日起 |
| 报销比例 | 门诊基本医疗费的50%（含一般诊疗费） |
| 限额标准 | 每人每月20元 |
| 2012年7—12月累计额度 | 120元 |

需要注意的是，年度末剩余额度将归还医保基金、清零处理，不结转到下一年度。

此外，校医院作为汕头市基层定点医疗机构，其为教职工提供的基本门诊医疗服务费用已列入医保统筹基金支付范围，教职工可直接在校医院就诊享受上述报销待遇。
