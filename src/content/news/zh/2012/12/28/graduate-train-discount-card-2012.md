据悉，研究生学院于12月28日发布通知，提醒全体研究生集中办理火车优惠卡购买、充磁及研究生证注册章加盖等事宜，相关业务办理截止时间为12月31日。

## 办理背景

自10月份研究生学院发布火车票学生优惠卡购买及充磁通知以来，仍有部分研究生陆续提出办理需求。根据铁道部规定，自2011年录取的学生起，需购买火车优惠卡的，须在教育部学信网上登记火车优惠站点等信息后方可办理。

## 办理安排

| 事项 | 安排 |
| --- | --- |
| 办理内容一 | 火车优惠卡购买及充磁 |
| 办理内容二 | 研究生证加盖注册章 |
| 办理对象 | 全体研究生（需办理者） |
| 截止时间 | 12月31日前，逾期不再办理 |
| 办理方式 | 以班级为单位集中办理 |
| 受理地点 | 研究生学院学生工作办公室（新行政中心401）/ 加盖注册章至各自专业学院 |
| 前置要求 | 2011年及以后录取且需购卡者须先在学信网登记优惠区间 |

研究生学院特别提醒，未加盖注册章的研究生将无法购买半价火车票，请需办理的同学在截止时间前以班级为单位收齐后至各自所在专业学院加盖注册章。

> 来源：汕头大学 OA 通知（研究生学院）
