汕头大学图书馆发布 Web of Science 数据库使用说明。学校已开通 SCI、SSCI 和 A&HCI 访问权限，汤森路透集团同时向学校赠送 Current Chemical Reactions（CCR）、Index Chemicus（IC）和 Medline 访问权限。

### 数据库及可访问年限

| 数据库 | 可访问年限 |
| --- | --- |
| Science Citation Index Expanded（SCI） | 2003年至今 |
| Social Sciences Citation Index（SSCI） | 2003年至今 |
| Arts & Humanities Citation Index（A&HCI） | 2003年至今 |
| Index Chemicus（IC） | 1993年至今 |
| Current Chemical Reactions（CCR） | 1986年至今；另含1840—1985年INPI文档信息 |
| Medline | 1950年至今 |

SCI覆盖自然科学和工程领域，SSCI覆盖政治、经济、法律、教育、心理、地理和历史等社会科学领域，A&HCI覆盖哲学、文学、语言学、音乐、艺术、建筑、亚洲研究、历史和考古等人文艺术领域。IC和 CCR 侧重有机化合物及化学反应信息，Medline则覆盖生物医学、临床医学、药学和公共卫生等主题。

### 访问与培训

- Web of Knowledge 入口：<http://webofknowledge.com>
- 图书馆数据库入口：<http://www.lib.stu.edu.cn/dbdetail.aspx?id=317>
- 产品培训：<http://ip-science.thomsonreuters.com.cn/productraining/>
- 应用技巧：<http://ip-science.thomsonreuters.com.cn/searchtips/WOKsearchtips/>
- 在线大讲堂：<http://ip-science.thomsonreuters.com.cn/2012wokonline/>

图书馆提醒师生，使用数据库时可参考相关培训资源，结合主题、引文和化学结构等检索方式查找研究资料。
