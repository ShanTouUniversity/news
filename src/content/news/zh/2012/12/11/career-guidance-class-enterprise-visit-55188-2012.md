根据课程大纲安排，汕头大学开课班号 55188《就业指导》课程将调整为企业参观活动。原定第 13 周星期四（12 月 13 日）第 8、9 节在 E 座阶梯 202 教室进行的课程，改为前往广东奥飞动漫文化股份有限公司开展实践学习。

修读该班课程的学生须于 2012 年 12 月 16 日（星期日）上午 9:20 在校训碑处准时集合并上车。课程任课教师为苏文记、王斌。

| --- | --- |
| 课程 | 就业指导 |
| 开课班号 | 55188 |
| 原授课时间 | 第13周星期四（12月13日）第8、9节 |
| 原授课地点 | E座阶梯202教室 |
| 实践安排 | 企业参观 |
| 参观单位 | 广东奥飞动漫文化股份有限公司 |
| 集合时间 | 2012年12月16日9:20 |
| 集合地点 | 校训碑 |
| 任课教师 | 苏文记、王斌 |
| 发布部门 | 学生处 |

学生处提醒修读该课程的学生相互转告，并按时到指定地点集合。
