汕头大学资源管理处基建办公示西区 36 套教工宿舍修缮工程预增项。该工程于 2012 年 8 月 21 日开工，施工过程中根据现场实际情况和设计、防雷等要求增加部分项目，初步估算需增加工程造价约 5.50 万元，预增项造价累计在学校规定的 10% 以内。

| 预增项目 | 原因或内容 |
| --- | --- |
| 一级浪涌保护器 | 根据设计院及防雷所要求增加 |
| 室外电力电缆 | 实际施工长度较暂定设计数量增加30.4米 |
| 室外排水沟井及管道 | 根据施工实际需要增加 |
| 室外给水管道 | 原设计图纸未包含，施工中增设 |
| 室外混凝土散水坡、排污管道、化粪池及门前混凝土地坪 | 原有设施破损，重新铺设或修建 |

| 项目 | 信息 |
| --- | --- |
| 工程 | 汕头大学西区36套教工宿舍修缮工程 |
| 开工时间 | 2012年8月21日 |
| 预计增加造价 | 约5.50万元 |
| 预增项累计 | 低于学校规定的10% |
| 意见反馈截止 | 2012年12月13日17:30 |
| 反馈方式 | 书面向监察审计处或基建办反映 |
| 发布部门 | 资源管理处基建办 |

如对预增项有不同意见，相关单位或个人可在截止时间前以书面形式向监察审计处或基建办反映。

> 来源：汕头大学 OA 通知（资源管理处基建办）
