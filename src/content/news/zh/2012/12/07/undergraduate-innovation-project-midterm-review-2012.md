汕头大学教务处将对部分 2011 年立项、项目实施时间为一年半或两年的大学生创新实验项目开展中期检查。检查旨在了解项目研究进展、阶段性成果、经费使用和下一步计划，并为后续结题评审提供依据。

各项目组须于 2013 年 1 月 4 日前，将中期检查表、项目进展日志及阶段性成果材料提交至新行政中心三楼教务处事务窗口。纸质材料一式两份，同时发送电子版至 `wtyang@stu.edu.cn`。

| 项目 | 要求 |
| --- | --- |
| 检查对象 | 2011年立项、实施期为一年半或两年的项目 |
| 检查材料 | 中期检查表、项目进展日志、阶段性成果证明材料 |
| 成果材料 | 论文、研究报告、研发实物等，可附图片和文字介绍 |
| 提交截止 | 2013年1月4日 |
| 纸质材料 | 一式两份，交新行政中心三楼教务处事务窗口 |
| 电子材料 | 发送至 wtyang@stu.edu.cn |
| 负责部门 | 汕头大学教务处 |

中期检查表将记录项目研究进展、阶段性成果、存在问题及解决思路、下一阶段任务和时间安排，以及经费使用情况。项目进展日志则用于记录实验过程、研究数据、问题讨论、心得体会和项目组研讨会议。

中期检查结果将作为项目结题评审的重要依据。检查不通过的项目须限期整改，书面整改方案报送教务处综合科，经专家检查通过后方可继续实施并使用第二期项目经费；整改仍未达标的项目将终止实施。

项目咨询可联系教务处项目负责人，电话 86502736。项目组应按照要求开展自查，如实提交材料，为后续研究和项目验收做好准备。
