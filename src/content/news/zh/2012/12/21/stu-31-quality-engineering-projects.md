据悉，广东省教育厅于2012年12月19日发布通知（粤教高函〔2012〕204号），公布2012年度广东省高等学校教学质量与教学改革工程本科类立项建设项目结果。汕头大学在精品视频公开课、精品资源共享课、实验教学示范中心、省级教学改革项目、专业综合改革试点项目、大学生实践教学基地、人才培养模式创新实验区等7类项目中，共有31个项目获得立项。

此外，学校省级"大学生创新创业训练计划项目"获得推荐名额100项。2012年度，全校共获资助经费532万元，其中包含国家工程教育中心资助的100万元。

各项目类别立项及资助情况如下：

| 项目类别 | 立项数 | 资助金额 |
| -------- | ------ | -------- |
| 大学生创新创业训练计划项目 | 推荐名额100项 | 100万元 |
| 国家工程教育中心 | 1项 | 100万元 |
| 实验教学示范中心 | 2项 | 150万元 |
| 大学生实践教学基地 | 5项 | 75万元 |
| 专业综合改革试点项目 | 2项 | 50万元 |
| 高等教育教学改革项目 | 15项 | 27万元 |
| 精品资源共享课 | 4项 | 20万元 |
| 精品视频公开课 | 1项 | 10万元 |
| 人才培养模式创新实验区 | 2项 | 待确定 |

从立项情况看，医学院在实践教学基地和教学改革项目中占据多个席位，其中临床技能综合培训中心入选大学生实践教学基地；土木工程设计导论入选省级精品视频公开课；医学影像教学示范中心和化学实验教学中心分别获得75万元资助，是单体资助额度较高的项目之一。

根据省厅要求，各立项项目须严格按照申报计划推进建设工作，确保建设进展与成效达到预期目标。教务处表示，将对各立项项目进行跟踪管理，并配合省厅做好项目检查和验收工作。
