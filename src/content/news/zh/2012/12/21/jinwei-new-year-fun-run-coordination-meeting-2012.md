为落实汕头市体育局关于举办迎新年“金味”万人健身跑活动的安排，并结合学校正在开展的第六届全国亿万学生阳光体育冬季长跑活动，汕头大学计划组织校本部各学院、书院 300 名学生参加相关活动。

体育部将于 12 月 24 日（星期一）16:00 在汕大体育馆多媒体教室召开联席会议，协调活动组织工作。学生处、各学院和书院辅导员办公室须安排 1 名教师参加；校学生会及各学院、书院学生会须安排 1 名相关负责人参加。

| 项目 | 信息 |
| --- | --- |
| 活动 | 汕头市迎新年“金味”万人健身跑活动 |
| 学校计划参加人数 | 300名校本部学生 |
| 联席会议时间 | 2012年12月24日（星期一）16:00 |
| 联席会议地点 | 汕大体育馆多媒体教室 |
| 参会单位 | 学生处、各学院和书院辅导员办公室、校学生会及各学院和书院学生会 |
| 参会人员 | 各相关单位1名教师或学生会负责人 |
| 负责单位 | 汕头大学体育部 |

> 来源：汕头大学 OA 通知（体育部）
