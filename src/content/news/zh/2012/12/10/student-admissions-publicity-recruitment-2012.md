因招生宣传和咨询工作需要，汕头大学招生办公室拟面向在校本科生和研究生招聘 10 名学生招生宣传员。岗位将为学生提供参与招生咨询、校园接待和宣传内容制作的实践机会。

### 招聘条件

应聘者应品学兼优，了解并认同学校办学理念和办学特色，能够投入时间参与招生宣传工作；同时应具备较好的计算机和网络应用能力、文字和口头表达能力，以及沟通、耐心和责任意识。曾参加寒暑假招生宣传或中学母校探访活动者，在同等条件下优先考虑。

### 工作内容

- 通过新浪微博、百度贴吧、百度知道、腾讯高考、新浪高考等网络平台介绍学校和招生信息，回答咨询；
- 协助接待来访汕头大学的中小学师生；
- 协助开展中学母校探访、招生宣传短片摄制和招生宣传品创作比赛等活动。

| 项目 | 信息 |
| --- | --- |
| 招聘岗位 | 学生招生宣传员 |
| 招聘人数 | 10名 |
| 招聘对象 | 在校本科生、研究生 |
| 报名截止 | 2012年12月16日（星期日）17:00 |
| 报名方式 | 填写简历表并发送至 o_zsb@stu.edu.cn |
| 面试安排 | 简历初选后另行通知 |
| 工作酬劳 | 按学校勤工俭学岗位标准发放 |
| 负责部门 | 招生办公室 |

有意应聘者须填写附件简历表，并在截止时间前发送至招生办公室邮箱。通过简历初选者进入面试，具体时间和地点由招生办公室另行通知。
