汕头大学教务处启动 2012—2013 学年夏季学期实习课程评估工作。参与该学期实习课程的学生须在 2012 年 12 月 10 日至 21 日期间，登录学分制系统完成课程评估。

学生登录系统后，可依次进入“课程评估”和“查看待评估实习课程”，选择 2012—2013 学年夏季学期的实习课程进行评价。未在规定时间完成评估的学生，须向教务处提交书面说明，否则无法查看实习课程成绩。

| 项目 | 信息 |
| --- | --- |
| 评估时间 | 2012年12月10日至12月21日 |
| 评估对象 | 2012—2013学年夏季学期开设的实习课程 |
| 参加对象 | 参与相关实习课程的学生 |
| 系统路径 | 学分制系统 → 课程评估 → 查看待评估实习课程 |
| 负责部门 | 教务处 |

### 需要评估的课程

| 开课单位 | 课程代码及名称 |
| --- | --- |
| 中文系 | CHI5050 毕业实习 |
| 外语系 | ENG4800 Internship |
| 公管系 | PAM3070 专业实习 |
| 化学系 | CHE4431 实习 |
| 生物系 | BIO3383 生产实习 |
| 计算机系 | CST7111 生产实习 |
| 电子系 | EEG7200 生产实习 |
| 土木系 | CIV7200 生产实习 |
| 机电系 | MEC7301 生产实习 |
| 艺术设计系 | ADE4713 专业实习2 |
| 新闻学院 | JOU2202 中期实习 |

教务处请各学院（系）教务员协助通知相关学生，按时完成实习课程评估任务。

> 来源：汕头大学 OA 通知（教务处）
