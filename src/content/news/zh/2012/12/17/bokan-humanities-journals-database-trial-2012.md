汕头大学图书馆推出博看网人文社科期刊数据库试用，面向全校师生读者提供中文期刊和杂志资源。图书馆介绍，该平台收录 3600 多种、4 万多本期刊杂志，并持续更新资源；新刊上线时间基本与纸质版发行时间同步，过刊也可继续查阅。

平台覆盖时政新闻、文摘文学、文艺体育、管理财经、文化艺术、科学技术和教育教学等内容，收录《半月谈》《中国新闻周刊》《北京文学》《中国企业家》《世界博览》《科学之友》和《中国教师》等刊物。读者可根据平台提供的条件选择原文原貌多媒体版、电子版、语音版或下载版阅读。

| 项目 | 信息 |
| --- | --- |
| 资源名称 | 博看网人文社科期刊数据库 |
| 资源规模 | 3600多种、40000多本期刊杂志 |
| 更新情况 | 每天更新约100本杂志，每年增加20000本以上（按图书馆通知介绍） |
| 阅读方式 | 多媒体版、电子版、语音版、下载版 |
| 访问入口 | [图书馆数据库详情页](http://www.lib.stu.edu.cn/dbdetail.aspx?id=252) |
| 反馈部门 | 图书馆学科服务部 |
| 反馈电话 | 86503247 |

图书馆欢迎师生在试用期间使用该数据库，并向学科服务部反馈使用评价和意见。通知未列明具体试用截止日期，读者可通过图书馆数据库详情页查看当前访问状态。

> 来源：汕头大学 OA 通知（图书馆）
