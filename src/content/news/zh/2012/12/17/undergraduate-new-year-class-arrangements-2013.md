根据汕头大学党政办公室发布的元旦放假安排，教务处公布本科生课程调换方案。2013 年元旦期间，部分工作日和周末课程按以下方式调整：

| 日期 | 教学安排 |
| --- | --- |
| 2013年1月1日（星期二） | 课程停课 |
| 2013年1月2日（星期三） | 与2013年1月5日（星期六）的课程对调 |
| 2013年1月3日（星期四） | 与2013年1月6日（星期日）的课程对调 |

各教学单位应据此通知相关本科生，并按照调换后的日期组织教学。学生应结合所在学院和课程安排确认具体上课时间。

| 项目 | 信息 |
| --- | --- |
| 适用对象 | 本科生课程 |
| 停课日期 | 2013年1月1日 |
| 调换日期 | 2013年1月2日与1月5日；1月3日与1月6日 |
| 发布单位 | 汕头大学教务处 |

> 来源：汕头大学 OA 通知（教务处）
