汕头大学教务处和网络与信息中心提醒校园网用户，MYSTU 学习平台计划在元旦后升级，并将整合 Webmail 邮件系统。新版平台基于新的互联网标准开发，继续使用 IE6 或 IE7 访问可能出现无法登录、页面样式混乱等问题。

MYSTU 开发团队推荐使用 Google Chrome 浏览器。习惯使用 Windows XP 及系统自带 IE 浏览器、且不使用 Chrome 的用户，建议升级至 IE8 或更高版本；使用 Windows 7 自带 IE8 的用户，建议通过自动更新升级到 IE9 或更高版本。升级中的 MYSTU 版本将支持 IE8、IE9，但学校仍建议使用更新的浏览器。

用户可访问 `https://my.stu.edu.cn/browser/upgrade.html`，通过页面下方链接下载安装或升级浏览器。如需技术支持，可联系：
