汕头大学人事处通知，2012 年职称申报材料已取回。相关学院和部门须于 12 月 28 日前派员到新行政楼 312 会议室，领取本单位人员的申报材料。

领取单位包括：文学院、理学院、工学院、法学院、商学院、长江艺术与设计学院、长江新闻与传播学院、英语语言中心、社科部、体育部、高教所和图书馆。

| 项目 | 信息 |
| --- | --- |
| 材料 | 2012年职称申报材料 |
| 领取对象 | 上述相关学院和部门 |
| 截止时间 | 2012年12月28日 |
| 领取地点 | 新行政楼312会议室 |
| 办理方式 | 各单位派员领取本单位人员材料 |
| 组织单位 | 人事处 |

本文仅报道材料领取安排，不涉及教职工个人申报内容。

> 来源：汕头大学 OA 通知（人事处）
