据悉，国家留学基金管理委员会与美国乔治城大学合作设立的博士后奖学金项目已开放申请，申请截止日期为2012年3月20日。汕头大学国际交流合作处近日转发相关通知。

该项目于2006年设立，旨在促进乔治城大学与中国一流高校的学术交流。获资助学者将在乔治城大学从事1至2年博士后研究，与相关领域专家合作并有机会在高水平英文学术期刊发表成果。2012年度资助领域涵盖化学、物理、生物技术、计算机、神经科学、药理学和生理学。

## 申请条件

| 条件 | 要求 |
|------|------|
| 获得博士学位时间 | 2007年3月20日至2012年3月20日期间 |
| 身份 | 中国高校或科研机构正式教职人员或博士后第一年研究人员 |
| 语言 | 具有较高英语水平 |
| 学术能力 | 具备良好学术基础及科研能力 |
| 既往资助 | 如曾获留学基金委资助，须回国满5年方可再次申请 |

## 资助内容

| 项目 | 内容 |
|------|------|
| 生活津贴 | 每年至少3万美元 |
| 医疗保险 | 乔治城大学教职工医疗保险 |
| 旅费 | 中美往返机票一张 |
| 学术资源 | 可使用乔治城大学图书馆及其他学术资源 |

## 申请流程与时间安排

| 时间 | 环节 |
|------|------|
| 3月20日前 | 分别向乔治城大学博士后项目管理办公室及留学基金委提交完整申请材料（无需提前联系导师） |
| 4月 | 乔治城大学对通过初审者进行英文面试，通过者免考全国外语水平考试（WSK/PETS5） |
| 5月 | 乔治城公布录取名单并抄送留学基金委备案 |
| 4—7月 | 留学基金委组织专家评审并公布最终录取名单 |
| 8—9月 | 获录取者办理派出手续，赴华盛顿开展研究 |

申请材料方面，需向乔治城大学提交申请表及两封推荐信（发送至 cscfellowship@georgetown.edu），同时按留学基金委要求提交相应材料。

项目详情可访问乔治城大学项目官网 http://china.provost.georgetown.edu/csc/ 及留学基金委官网相关页面。
