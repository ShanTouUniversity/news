汕头大学启动2012年度专业技术资格申报和评审工作。此次工作依据广东省教育厅、人力资源和社会保障厅相关文件开展，涉及高校教师专业技术资格以及实验、工程、图书资料等系列专业技术资格的申报、认定和评审。

申报中、高级专业技术资格须执行广东省现行专业技术资格条件，继续教育证明须覆盖2010年和2011年课程。海外高层次留学回国人员通过绿色通道申报时，须为回国后首次申报，提交在国外取得的业绩成果，并获得3名以上国内同行专家认可或推荐；境外学历（学位）还须按规定办理认证。学校同时将教师师德、教学能力、教学水平和教学效果纳入评审，对弄虚作假、学术不规范或严重教学事故按规定处理。

申报人须先向所在基层单位提交材料。申报高校教师专业技术资格（含评审和认定）须通过广东省教师职称网上申报系统填报，网址为 [rsc.gdhed.edu.cn](http://rsc.gdhed.edu.cn)。基层单位和学校相关职能部门将分别审核材料、教学和科研情况；人事处还将对申报材料进行全校公示7个工作日。通过学科组和学校教师专业技术资格评审委员会评审后，材料报广东省教育厅评审或审批。

### 时间安排

| 时间 | 工作事项 |
| --- | --- |
| 7月2日前 | 申报人向所在单位报名并提交论文代表作申请表 |
| 7月3日前 | 各单位向人事处报送人员登记表及代表作复印件等材料；学校开展网上申报培训 |
| 7月4日 | 人事处将代表作匿名送校外专家鉴定 |
| 8月16日前 | 申报人向所在单位提交网上填报材料 |
| 8月18日前 | 各单位向人事处提交全部材料 |
| 8月20日至28日 | 开展评前公示及科研、教学和研究生教学材料审核 |
| 9月起 | 组织学科组评审等工作并整理材料报送省级部门 |

申报评审高级职称收费780元/人，其中包括论文鉴定费200元；需要答辩的另收答辩费140元/人。中级职称评审费为450元/人，初级评审或认定费为280元/人。费用可按规定从个人工资账户扣缴，也可到财务处自行缴纳；材料受理后，无论评审是否通过，费用均不退还。相关材料请报送人事处（行东406）。
