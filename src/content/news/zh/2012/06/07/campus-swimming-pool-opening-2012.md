据悉，根据6月5日第7次校领导会议决定，汕头大学游泳池自6月9日起面向全校师生开放。开放时间安排如下：

| 日期 | 开放时间 | 备注 |
| --- | --- | --- |
| 6月9日至10日 | 17时至18时30分 |  |
| 6月11日至15日 | 17时45分至19时15分 | 17时30分前为体育课时间 |
| 6月16日起 | 17时至18时30分 |  |

自2012年起，游泳票不再使用，改为一卡通刷卡管理，费用为5元/次。体育部提醒入场师生注意安全、遵守泳池规定，爱护设备并保持文明行为。泳池已加装闭路监控设施。

> 来源：汕头大学 OA 通知（体育部）
