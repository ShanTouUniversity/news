据悉，汕头大学工学院第三期服务学习立项答辩会已于6月1日举行。评委对参加答辩的各立项项目进行了公平、公正的评审，学院根据评审结果，并结合项目类型及实际效果，最终决定对4个项目予以立项资助。

## 获立项项目

| 序号 | 项目名称 |
| ---- | ---- |
| 1 | 与你相伴 助你前行 |
| 2 | 弘扬传统 传承关爱 |
| 3 | 暖心沁香 真情义剪 |
| 4 | 爱心义教系列活动 |

学院希望各获准立项的项目组认真做好活动组织工作，结合服务学习理念，按计划要求完成各项工作。
