据悉，汕头大学党政办公室发布《关于学校放暑假的通知》（汕大党政办[2012]4号），公布了2012年暑假及夏季学期的具体安排。

## 师生假期安排

根据校历，在校学生暑假时间为7月1日（星期日）至8月18日（星期六），其中2011级本科学生军训由学生处另行安排。在校生须于8月19日注册，8月20日（星期一）夏季学期正式上课。新生则于9月2日报到；秋季学期学生9月16日注册，9月17日（星期一）正式上课。

教师从7月4日（星期三）开始放暑假，8月17日（星期五）回校做开学准备并按各系安排指导新生选课，8月20日起进入夏季学期教学。学校要求各教学单位充分利用夏季学期开展教研活动，并安排没有修课的学生适当参加社会实践；各研究生培养单位及导师按培养计划自行安排教学、科研及实践活动。

| 时间节点 | 安排 |
| --- | --- |
| 7月1日 | 在校学生开始放暑假 |
| 7月4日 | 教师开始放暑假 |
| 8月17日 | 教师回校做开学准备、指导新生选课 |
| 8月19日 | 在校生注册 |
| 8月20日 | 夏季学期上课 |
| 9月2日 | 新生报到 |
| 9月16日—17日 | 秋季学期注册、上课 |

## 留校与安全事项

暑假期间留校住宿的学生需向学生宿舍区辅导员办公室提出申请，由该办公室和学生社区管理服务中心统一安排住宿。学校同时要求各学院及相关职能部门对假期回家的师生开展安全教育，提高师生假期人身和财产安全意识。

## 行政后勤实行轮休制度

依据汕大党政办[2009]08号文件精神，行政、教辅和后勤服务人员继续执行寒暑期工作制度：暑假期间各单位必须提供正常行政服务；鉴于暑期全校性活动较少，各单位可结合工作实际适当安排工作人员轮休（7月4日至8月15日）。此期间上述人员工作时间调整为上午8:30—11:30、下午3:00—5:00，轮休人员须保持通讯畅通、按需到岗。8月16日起，全体行政教辅后勤人员恢复正常上班时间。

各单位须在6月26日下午下班前将暑假值班人员名单报党政办公室汇总。
