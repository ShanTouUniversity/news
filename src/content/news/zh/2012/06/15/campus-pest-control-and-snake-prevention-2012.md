为加强校园植物病虫害防治，汕头大学资源管理处计划于6月18日至25日在校区及龙泉园、成教学院等区域对绿地花木、果树和水沟进行分区喷药。师生员工应注意作业安全，严禁采摘校园果实食用。

| 日期 | 作业区域 |
| --- | --- |
| 6月18日 | 人工湖区域、运动场 |
| 6月19日 | 学术交流中心周围、P楼、学生宿舍区 |
| 6月20日 | 水库坝、789号楼、A—B座教工宿舍区 |
| 6月21日 | 医科楼、新教学楼、G—J座学生宿舍 |
| 6月22日 | 校卫队办公场地周边、校门口、各校道、新图书馆外围 |
| 6月23日 | 食堂、行政楼周围 |
| 6月24日 | 附中、附小至精神卫生中心沿线 |
| 6月25日 | 龙泉园、成教学院 |

此外，资源管理处近日将在宿舍区投放硫磺粉，以进一步加强防蛇工作。相关区域人员应留意现场安全提示。

> 来源：汕头大学 OA 通知（资源管理处）
