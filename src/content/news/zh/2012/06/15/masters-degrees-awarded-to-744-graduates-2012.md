汕头大学第八届学位评定委员会第一次会议于6月15日召开，审议了744位研究生的硕士学位申请。申请人包括447位毕业研究生、268位专业学位研究生、20位同等学力人员和9位高校教师在职硕士人员。会议依据《中华人民共和国学位条例》、学校学位工作条例及相关细则，决定授予相应硕士学位。

授予学位的类别及人数如下：

| 学位类别 | 人数 |
| --- | ---: |
| 艺术学硕士 | 51 |
| 教育学硕士 | 13 |
| 法学硕士 | 4 |
| 管理学硕士 | 60 |
| 经济学硕士 | 9 |
| 理学硕士 | 101 |
| 工学硕士 | 93 |
| 医学硕士 | 145 |
| 工商管理硕士专业学位 | 13 |
| 工程专业硕士学位 | 25 |
| 工程硕士专业学位 | 18 |
| 临床医学硕士专业学位 | 212 |

因授予对象为学生，本文不公开个人姓名。

> 来源：汕头大学 OA 通知（汕头大学学位评定委员会）
