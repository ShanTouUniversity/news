据悉，汕头大学图书馆近日发布电子资源动态通报（2012年第5期，总第5期），通报内容包括五项数据库服务调整：

| 资源 | 事项 |
|------|------|
| 读秀数据库 | 开通暑期漫游：新用户须在学校IP内注册"我的图书馆"账号并点击验证链接，已有账号的用户在校内IP登录后点验证链接即可绑定，暑期可在校外通过"暑期账号登录"使用 |
| 北大法意（教育频道） | 开通"国家司法考试在线模考系统"试用，涵盖模拟考试、考试大纲、必备法规、司法文书四大模块，试用期至2012年9月30日 |
| 锐思（RESSET）金融研究数据库 | 延长试用期：数据覆盖股票、固定收益、基金、宏观、行业、经济与法律信息、港股、外汇、期货、黄金等，试用期至2012年9月30日 |
| 库客（KUKE）数字音乐图书馆 | 音质全面提升：码率由64K、128K升至192K，格式由WMA改为MP3；读者在校内IP范围内注册个人用户后，7至8月可凭账户在校外免费访问（校外不提供下载） |
| "知识视界"视频图书馆 | 延长试用期：收录理、工、农、医、历史、文学等学科上万小时科教视频资源，试用期至2013年1月31日 |

各数据库的访问链接可通过图书馆网站相关数据库详情页面获取。

> 来源：汕头大学 OA 通知（图书馆）
