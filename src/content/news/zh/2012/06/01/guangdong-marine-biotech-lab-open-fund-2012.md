据悉，依托汕头大学建设的广东省海洋生物技术重点实验室于6月1日发布2012年开放课题基金申请指南，面向国内外高校、科研机构研究人员特别是中青年学者开放申请。

该实验室于1993年4月获批建设，1995年12月通过验收，由校内2000余平方米实验室与南澳临海实验站130余亩陆地及约10公顷试验海域组成，仪器设备总值近3000万元，聚焦粤东特色海洋生物资源开展系统研究。

## 主要研究方向

| 方向 | 重点内容 |
| --- | --- |
| 海洋经济动物生物学及应用 | 经济鱼贝虾蟹类生物学特性、良种培育、营养饲料、种苗繁育、流行病防治及免疫学 |
| 海藻生物学及资源利用 | 大型海藻分类与多样性、经济海藻养殖工程、海藻生理生态、生物入侵及潮间带植被修复 |
| 海洋生态环境与健康养殖 | 近岸生态系统健康评估、生物修复、保护管理示范、水产病害防治、浮游植物生态及生物多样性保护 |

## 申请办法

| 事项 | 要求 |
| --- | --- |
| 申请材料 | 认真填写《开放课题基金申请书》，目标明确、内容具体、具创新性，课题组需含1至2位本室成员 |
| 申请人条件 | 为正式职工且具中级及以上职称或博士学位，能保证研究时间 |
| 鼓励方向 | 优先使用本室仪器设备设施开展工作 |
| 受理时间 | 2012年6月1日至30日，7月底前评审完成 |
| 资助强度 | 每项2至3万元，资助4至5项，执行期1至2年 |
| 提交方式 | 纸质版3份（加盖单位公章）及电子版 |
