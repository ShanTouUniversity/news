据悉，在广东省教育厅与中国移动通信集团广东有限公司联合组织的"万名大学生勤工助学、资助十万名贫困中小学生"活动框架下，汕头大学学生处日前面向全校学生发布招聘信息，将招募30名学生赴移动实体渠道参加社会实践。家庭经济困难的学生将被优先考虑。

## 岗位与待遇

此次实践的工作期限为2012年4月至2013年3月，采用社会实践方式参与，服务津贴按每小时9.3元的标准计付，并在学生实践次月30日前支付给学生本人。

工作班表将根据学生的课余时间弹性安排：学生可在每月月初结合自身课程提交当月工作时间计划，每天工作不超过4小时、每周累计不超过24小时，以不影响正常学业为前提。班次分为早班（8:00–12:00）和午班（14:00–18:00），实践场所包括服务厅、体验店、品牌店等实体渠道。

## 六类岗位设置

| 岗位 | 主要职责 |
| --- | --- |
| 迎宾岗 | 在服务厅门口迎送客户，引导使用排队设备 |
| 咨询岗 | 在大堂解答业务咨询，引导使用自助服务设备 |
| 新业务体验推广岗 | 协助客户体验并推荐新业务 |
| 定制终端销售岗 | 介绍推荐机型、指导填写协议、介绍数据业务营销包 |
| 促销现场、营销推广岗 | 介绍促销活动内容，推荐促销产品 |
| 校园、社会、直销岗 | 面向校园及社会潜在客户推销产品 |

## 报名方式

有意者须登录活动网站 dxsx.st10086.com，点击"2012年带薪实习计划报名"，在网上报名系统提交成功后下载并填写纸质版报名表，面试时携带至现场（不接受现场报名）。报名截止时间为6月8日中午12:00；具体面试时间与地点将于6月11日在网站上公布。
