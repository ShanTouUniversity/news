据悉，法学院于6月14日发布通知，组织选拔优秀学生代表参加第11届 Jessup 国际法模拟法庭辩论赛（中国赛区）和第10届“贸仲杯”国际商事仲裁模拟仲裁庭辩论赛。

两项赛事分别将于今年11月（贸仲杯）和明年2月（Jessup）举行，现已开放报名。

## 选拔安排

| 事项 | 内容 |
| --- | --- |
| 参赛赛事 | Jessup 国际法模拟法庭（5—8人，5人为正式队员，另招4名研究助理，主要面向下学期二年级本科生）；贸仲杯（6—8人，另招2—6人研究团队） |
| 选拔范围 | 法学院全体本科生、研究生 |
| 参赛要求 | 法律基础扎实，对比赛有浓厚兴趣并能投入大量课余时间，具备英文听说读写能力及法律逻辑思辨能力 |
| 选拔方式 | 书面小论文（500词内，英文，占50%）+英文口头面试（英语口语、参赛意愿及法律基础，拟于9月中下旬举行，占50%） |
| 报名方式 | 报名表于6月18日前发送至指定邮箱；英文论文于9月15日前提交 |
| 比赛官网 | Jessup: http://www.ilsa.org/jessuphome；贸仲杯: http://www.cisg.law.pace.edu/vis.html |
| 发布单位 | 法学院 |

有意参赛的同学请按通知要求提交材料。报名邮箱及题目等详情见 OA 附件。

> ⚠️ 报名表格及题目请前往 OA 系统查看原文附件。
