据悉，根据上级关于加强学校周边环境整治工作的相关文件精神，金平区政府及汕头市相关职能部门近日将采取联合行动，对汕头大学及周边区域进行全面清理，整治对象包括校内外临时摊档、违章搭建物等。

## 公交线路调整

随着整治行动推进，校门口的 39 路公交车终点站也将同步迁移至原精卫中心大门口。此次调整后，全校师生乘坐 39 路车时，需统一在大学路两旁的公交站候车。

| 事项 | 调整情况 |
| ---- | -------- |
| 整治范围 | 汕头大学及周边区域 |
| 清理对象 | 临时摊档、违章搭建物等 |
| 39路终点站 | 由校门口迁至原精卫中心大门口 |
| 候车地点 | 大学路两旁公交站 |

学校方面呼吁全校师生积极配合，支持政府主管部门的整治行动，共同维护整洁、安全的校园环境。

> 来源：汕头大学 OA 通知（资源管理处）
