据悉，汕头大学商学院团委于4月11日发布通知，将于4月14日举办第二期“生命教育”体验式活动及交流分享会。

活动旨在通过体验式系列活动与理论学习，帮助学生理解生命意义，引导学生认识并珍爱生命、尊重他人生命，进而思索自身价值与定位，提升生命质量。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 对象 | 商学院2010、2011级本科生 |
| 名额 | 96人（超额抽签） |
| 时间 | 2012年4月14日全天 |
| 日程 | 上午9:00—12:00校园体验项目（生命组合、know me、生命之梯、生命电网、心灵游戏等）；下午14:30—17:30生命挑战营；晚上19:30—22:00生命教育学习与交流会 |
| 地点 | 体育馆门前集中，校园内及教室 |
| 主办单位 | 商学院团委 |

## 注意事项与报名

| 事项 | 内容 |
| --- | --- |
| 要求 | 严格遵守纪律，不得请假（特殊情况需说明）；具备良好身体素质，能全程参加中等强度训练；自备运动服、运动鞋；结束后提交书面心得体会 |
| 报名截止 | 2012年4月11日前 |
| 报名方式 | 自愿报名，到所在区区长（班长）处报名，仅需提供姓名、性别、班级和手机联系方式 |
