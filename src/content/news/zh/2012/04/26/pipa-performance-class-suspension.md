据悉，汕头大学教务处近日发布课程调整信息：因艺术教育中心任课教师杨青请假，原定于第9周周五（4月27日）第8、9节在 STU213 教室开设的《琵琶演奏》课程停课一次。

据教务部门通报，本次停课涉及开课班号为 52904 的教学班，补课时间目前尚未确定，待确定后将另行通知。修读该课程的同学们需留意后续安排。

| 项目 | 信息 |
| --- | --- |
| 课程名称 | 琵琶演奏 |
| 开课班号 | 52904 |
| 停课时间 | 第9周周五（4月27日）第8、9节 |
| 上课地点 | STU213 教室 |
| 任课教师 | 杨青（艺术教育中心） |
| 补课安排 | 待定 |

> 来源：汕头大学 OA 通知（教务处）
