据悉，教务处于4月16日发布通知，2012年（第三期）汕头大学公益课程师资培训班将于4月18日开班。

## 培训安排

| 事项 | 内容 |
| --- | --- |
| 开班时间 | 2012年4月18日起 |
| 规模 | 共6个时段，约13学时 |
| 考勤 | 实行考勤登记，缺席超过两个时段视为培训不通过；因教学冲突建议调课，无法参加需提前向教务处请假 |
| 取证条件 | 通过培训并承担一次公益服务项目、经评估合格后方可取得“公益课程任课资格证书” |
| 联系人 | 教务处刘祥玲老师 |
| 办公电话 | 82902416 |
| 邮箱 | lxl0726@stu.edu.cn |
| 主办单位 | 教务处 |

培训日程安排及学员名单见 OA 附件。
