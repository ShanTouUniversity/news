据悉，李嘉诚基金会与长江艺术与设计学院于5月17日联合发布通知，举办LAP“领袖才能冒险项目”LOGO征集比赛。

## 征集安排

| 事项 | 内容 |
| --- | --- |
| 征集对象 | 汕头大学全体研究生、本科生 |
| 投稿要求 | 提交A4幅面、300dpi、CMYK、JPG格式设计方案电子文件，并附设计说明及电话、邮箱等联系方式 |
| 投稿方式 | 发送至 11rdai1@stu.edu.cn |
| 截稿时间 | 2012年5月31日17:00前 |
| 评选方式 | 主办方组织专家评审团进行评选，评选标准为创意、符合主题、表现技巧 |
| 奖项 | 优选奖1名，奖金1000元 |
| 主办单位 | 李嘉诚基金会 |
| 协办单位 | 长江艺术与设计学院 |

投稿作品必须为原创，抄袭或涉及知识产权纠纷的将取消参评资格并由参赛者承担后果。如有疑问，可发邮件至 ckad@stu.edu.cn 咨询。详情见 OA 附件。

> ⚠️ 征集要求详情请前往 OA 系统查看原文附件。
>
> 来源：汕头大学 OA 通知（长江艺术与设计学院）
