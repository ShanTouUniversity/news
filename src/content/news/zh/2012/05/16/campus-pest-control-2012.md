据悉，为改善校园环境卫生，汕头大学将于5月19日至23日在校区、龙泉园和成教学院开展校园除“四害”行动，主要进行灭蚊蝇作业。资源管理处提醒师生员工在相关区域活动时注意安全。

| 日期 | 作业区域 |
| --- | --- |
| 5月19日 | 学术交流中心周边、P楼、学生宿舍区、食堂和行政楼周边 |
| 5月20日 | 附中、附小至精神卫生中心沿线、A-B座教工宿舍区、789号楼 |
| 5月21日 | 医科楼、新教学楼，以及G、H、I、J座学生宿舍 |
| 5月22日 | 校卫队办公场地周边、校门口、各校道和新图书馆外围 |
| 5月23日 | 龙泉园、成教学院 |

> 来源：汕头大学 OA 通知（资源管理处）
