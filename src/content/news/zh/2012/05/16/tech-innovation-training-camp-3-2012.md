据悉，工学院团委与学生科技发展中心将于5月20日至27日举办第三期“大学生科技创新训练营”，以贯彻落实 EIP-CDIO 工程教育改革目标、提升学生自主创新能力并营造实学创新风气。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 走近科技，创造奇迹 |
| 时间 | 2012年5月20日至27日 |
| 主办单位 | 工学院团委 |
| 承办单位 | 工学院学生科技发展中心 |
| 面向对象 | 有意参与2012年学院科技立项项目的大一、大二学生 |
| 方案 | 详见附件一 |

## 报名方式

| 事项 | 内容 |
| --- | --- |
| 报名截止 | 2012年5月18日17:00前 |
| 报名方式 | 下载并填写《科技创新训练营报名表》，以“年级+专业+姓名”命名后发送至指定邮箱 |
| 注意事项 | 需严格遵守安排、着装整洁（男生着长裤，不得穿拖鞋），无故缺席将影响后续立项 |

具体方案及报名表请前往 OA 系统查看原文附件，报名邮箱等信息已作隐私保护不在此转载。
