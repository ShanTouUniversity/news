据悉，汕头大学商学院在秋季本科开课计划中安排17门课程面向全校学生开放，非商学院学生可作为通识课程选读。课程包括经济学、创业管理、证券与投资银行、市场营销、人力资源管理和风险管理等方向。

| 课程代码 | 课程名称 |
| --- | --- |
| BUS3623 | 中级微观经济学 |
| BUS3250 | 创业管理 |
| BUS3723 | 计算经济学 |
| BUS1261 | 计量经济学 |
| BUS3188 | 企业经营决策 |
| BUS3722 | 证券发行与投资银行监管 |
| BUS2723 | 证券交易与证券市场监管 |
| BUS3640 | 世界经济 |
| BUS3186 | 企业经营案例分析 |
| BUS3214 | 绿色营销 |
| BUS3215 | 创新营销管理 |
| BUS3209 | 品牌管理 |
| BUS3213 | 非营利组织营销管理 |
| BUS3212 | 营销渠道管理 |
| BUS3217 | 跨文化消费者行为 |
| BUS1070 | 人力资源管理（周五AB节） |
| BUS3781 | 风险管理 |

课程选读详情可咨询商学院教务办公室，电话：`82902277`。

> 来源：汕头大学 OA 通知（商学院）
