据悉，香港中文大学校长沈祖尧演讲预约工作已于近日结束，共有1081名师生预约成功。

## 活动安排

| 事项 | 安排 |
| --- | --- |
| 演讲嘉宾 | 香港中文大学校长沈祖尧 |
| 预约结果 | 1081名师生预约成功，名单见附件 |
| 举办时间 | 5月30日（星期三）晚7:30 |
| 举办地点 | 大礼堂 |
| 发布单位 | 国际交流合作处 |
| 发布时间 | 2012年5月28日 |

国际交流合作处表示，欢迎全校师生积极参加。
