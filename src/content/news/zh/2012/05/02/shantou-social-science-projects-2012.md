据悉，汕头市社科规划领导小组办公室启动2012年社会科学规划课题申报工作，汕头大学科研处近日转发相关信息。课题研究应围绕汕头发展和“汕潮揭”一体化等近期重点任务，也可从下列方向拟定选题：

| 方向 | 方向 | 方向 |
| --- | --- | --- |
| 汕头城市发展趋势与发展战略 | 培育新兴战略性产业 | 传统优势产业转型升级 |
| 蓝色海洋综合开发与海洋经济 | “汕潮揭”一体化牵头市作用 | “汕潮揭”区域资源整合与联动 |
| 改善民生与区域合作 | 交通体系与“汕潮揭”交通一体化 | 海洋旅游综合开发 |
| 国家电子商务示范城市建设 | 社会组织发展 | 社会管理与公共服务创新 |
| 教育事业均衡发展 | 城乡一体化社会保障 | 文化强市与文化软实力提升 |
| 文化体制改革与文化产业 | 潮汕文化传承与创新 | 旧城改造及历史建筑保护 |
| 潮人与中国近现代化进程 |  |  |

项目负责人应具有高级专业技术职务；不具备该条件的，须由两名正高级专业技术职务同行专家书面推荐。每位负责人限报一个课题，且不得作为其他课题组成员；课题组人数须达到3人以上。项目立项后应尽快开展调研和撰写工作，并于9月10日前提交不少于1万字的论文或调研报告。

申报人须于5月22日前将申请书提交科研处进行形式审查；通过审查的材料须于5月28日前以A4纸双面打印、一式5份交科研处，并发送电子版至 `ljwang@stu.edu.cn`。联系人为黄玉梅、王丽菊，联系电话：82902563。

> ⚠️ 课题申请书及相关申报材料请前往 OA 系统查看原文附件。
