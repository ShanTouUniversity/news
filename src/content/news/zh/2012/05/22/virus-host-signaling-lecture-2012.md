据悉，汕头大学理学院将于5月25日举办“科学沙龙”系列学术报告会，邀请香港大学医学院微生物学系陈鸿霖博士作专题报告，介绍病毒与宿主相互作用中的细胞信号传导通路。

## 报告安排

| 事项 | 内容 |
| --- | --- |
| 报告题目 | 《Cellular Signaling Pathways in Virus–Host Interaction》（病毒与宿主相互作用中的细胞信号传导通路） |
| 报告人 | 陈鸿霖博士，香港大学医学院微生物学系 |
| 时间 | 2012年5月25日15:00 |
| 地点 | 理学院报告厅（理-352） |
| 主办单位 | 理学院 |

## 研究方向

据报告人简介，陈鸿霖博士主要研究流感和EB病毒致病机理、宿主与病毒相互作用及跨种传播的分子基础、流感病毒抗原性变异，以及新型流感病毒疫苗等方向。他已在 *Nature*、*PNAS* 等国际知名期刊发表论文100余篇。

报告面向有兴趣的师生开放。陈鸿霖博士的详细个人简介见 OA 附件。
