据悉，汕头大学与揭东县东海宾馆有限公司就订房、用餐和会议接待等事项达成优惠协议，协议适用于学校师生员工及各单位，有效期为2012年5月21日至2013年5月21日。酒店位于揭东县，距机场约5公里。

餐饮和会议服务优惠如下：中餐厅、西餐厅按九折结算，西餐厅自助餐按8.8折结算，咖啡厅按九折结算；特价菜、海鲜及烟酒等项目不参与相关折扣。会议室按七折结算，投影仪、横幅和水牌另行计费。

住房优惠以预订时段的实际优惠价为准：

| 房型 | 全价 | 优惠价 |
| --- | ---: | ---: |
| 东楼标准双人房 | 599元 | 238元 |
| 东楼标准单人房 | 636元 | 258元 |
| 东楼标准套房 | 1000元 | 400元 |
| 东楼部长套房 | 1800元 | 728元 |
| 南楼商务双人房 | 699元 | 278元 |
| 南楼商务单人房 | 736元 | 298元 |
| 南楼行政房（单、双） | 900元 | 360元 |
| 南楼商务套房 | 1500元 | 600元 |
| 南楼皇家套房 | 14600元 | 5880元 |

协议房价不能与其他优惠卡叠加使用，住客可按酒店标准获赠早餐。节假日价格以酒店当时公布价格为准；预订通常保留至每日18时，退房时间为次日13时。如需变更或取消预订，应提前通知酒店。

预订及咨询电话：`3905888-3188`、`3905888-8188`；传真：`0663-3219999`。
