据悉，汕头大学学生社团联合会于5月5日至20日在校园内开展第二届学生社团孵化行动，面向全校师生，为新社团成立提供报名、培训、展示和答辩平台。

活动安排包括：

| 环节 | 时间 |
| --- | --- |
| 报名表提交 | 5月5日至11日 |
| 报名表初审 | 5月11日 |
| 培训工作坊 | 5月12日至16日 |
| 完整资料提交 | 5月5日至18日 |
| 网络投票 | 5月13日至19日 |
| 新社团人气展示 | 5月19日 |
| 社团孵化答辩会 | 5月20日 |

报名截止时间为5月11日24时。申请人需下载并填写电子报名表，发送至 `11zyxue@stu.edu.cn`。通过孵化行动新成立的学生社团有机会获得最高600元的前期活动经费。

> ⚠️ 报名表及活动相关附件请前往 OA 系统查看原文。个人咨询联系方式不在本文转载。
>
> 来源：汕头大学 OA 通知（共青团汕头大学委员会、汕头大学学生社团联合会）
