据悉，汕头大学长江新闻与传播学院将于5月19日（星期六）在E307课室举办"新闻纪录片制作：求真！求新！"工作坊，主讲嘉宾为香港电台电视部公共事务组副总监蔡贞停。工作坊面向新闻学院师生开放报名，名额有限，有兴趣者需在填妥报名表后于5月16日前提交，主办方将根据报名情况进行遴选。

## 活动信息

| 项目 | 内容 |
| ---- | ---- |
| 时间 | 2012年5月19日（星期六），上午9时至12时、下午2时至5时 |
| 地点 | E307 课室 |
| 主办 | 汕头大学长江新闻与传播学院 |
| 主讲嘉宾 | 蔡贞停（香港电台电视部公共事务组副总监） |
| 参加要求 | 新闻学院学生；须修读过电视新闻采编或纪录片制作课程 |

## 工作坊内容

据介绍，本次工作坊旨在介绍拍摄新闻纪录片的理念与方法，通过案例分析和互动交流，让参与者理解并基本掌握新闻纪录片全过程——包括前期制作、制作期和后期制作——所需的态度、技术和知识，以提升学生拍摄纪录片的专业能力和水平。

## 关于主讲嘉宾

蔡贞停毕业于香港中文大学新闻传播系。除1988至1990年被派往伦敦英国广播电台海外部（BBC World Services）从事电台主持及编导工作外，其职业生涯大部分时间在香港电台电视部度过，现任该台公共事务组副总监，主要负责纪录片及电视外判计划。

2005年和2006年，她应亚太广播联盟邀请，两度担任"海啸过后"及"禽流感爆发"合拍纪录片系列监制。其亲自执导的纪录片多次在国际影展获奖：描写柬埔寨战后情况的《铿锵集—战后余生》获芝加哥电视节新闻纪录片金奖；人物传记《杰出华人系列—季羡林》获芝加哥电视节金奖（摄影类别）及银奖（人物传记类别）；《杰出华人系列—白雪仙》则于2005年全港电视节目欣赏指数调查中夺得评审团大奖。
