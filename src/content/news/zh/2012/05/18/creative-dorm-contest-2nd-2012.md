据悉，学生处于5月18日发布通知，将举办“创意宿舍大比拼”活动，以培养创造性思维、提升动手能力并促进宿舍区同学感情。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 创意思维之社区新风尚 |
| 时间 | 2012年5月18日至6月4日 |
| 地点 | 学生宿舍区、金三角 |
| 对象 | 全校学生（以宿舍为单位或宿舍联合组队，不接受个人报名） |
| 主办单位 | 学生处 |
| 承办单位 | 学生处学生宿舍区辅导员办公室、学生宿舍自我管理委员会 |

## 报名与参赛

| 事项 | 内容 |
| --- | --- |
| 报名截止 | 2012年5月26日24:00 |
| 报名方式 | 在金三角及各宿舍区宣传点领取表格投入回收点（AB座A208、CD座C126、EF座E108、G座G119）；或在 OA 下载电子表发送至指定邮箱 |
| 参赛类别 | 电子类（原创视频、相册、微电影、游戏、配音、舍歌等）；手工类（宿舍模型、小发明、十字绣、剪纸、DIY等）；才艺类（水果拼盘、音乐会、表演等）；省钱秘笈图文类（旅行、生活节约策划等） |
| 作品要求 | 符合主题及类别，按时完成，拍成照片或视频并附文字说明提交 |

## 奖项设置

| 奖项 | 名额 | 奖金 |
| --- | --- | --- |
| 最佳作品奖 | 4名（每类1名） | 300元 |
| 最佳人气奖 | 4名（每类1名） | 100元 |
| 最佳创意奖 | 2名 | 100元 |
| 优秀奖 | 5名 | 50元 |
| 幸运观众奖 | 10名 | 精美礼品 |
