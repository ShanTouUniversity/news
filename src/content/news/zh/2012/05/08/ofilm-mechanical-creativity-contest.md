据悉，为鼓励学生树立创新意识、营造创新氛围，"工学院－欧菲光企业创新俱乐部"将举办首届机械创意大赛，活动分为机械创意大赛和CAD机械制图大赛两大模块，面向全校学生开放。

## 机械创意大赛

参赛者需构思一个创意构想，并进行可行性分析、原理分析（图文并茂），说明所需技术、加工难度、经费预算等，最后制作PPT在汇报当天展示，每个小组答辩时间不超过5分钟。

**报名截止**：2012年5月27日

| 奖项 | 名额 | 奖金 |
| ---- | ---- | ---- |
| 一等奖 | 1名 | 200元 |
| 二等奖 | 2名 | 100元 |
| 三等奖 | 3名 | 50元 |

获奖者还将获得精美证书。

## CAD机械制图大赛

比赛分计时赛和难度挑战赛两部分：

| 赛项 | 形式 | 时限 | 评分构成 |
| ---- | ---- | ---- | -------- |
| 计时赛 | 仅限个人 | 30分钟现场绘制统一零件图 | 准确性70% + 用时30% |
| 难度挑战赛 | 可组队（不超过2人） | 60分钟内完成A/B/C三档装配图选一绘制 | 难度40%（A类≤40分、B类≤35分、C类≤30分）+ 准确性60% |

由于设备资源和场地限制，计时赛仅有30个参赛资格，难度挑战赛有15个（组），均按报名表接收顺序以"先到先得"方式分配。

**报名截止**：2012年5月13日

奖项方面，计时赛前三名奖金分别为100元、80元、50元；难度挑战赛前三名奖金分别为200元、150元、100元，获奖者均可获得证书。

有意参赛的学生可从办公自动化系统下载报名表填写后发送至指定校内邮箱。
