据悉，汕头大学理学院将于2014年6月4日上午10时举办“走向现代数学”系列学术报告，汕头大学数学系史永杰将围绕“一类卷积型积分方程的快速求解方法”作专题报告。

## 报告安排

| 事项 | 内容 |
| --- | --- |
| 报告题目 | 一类卷积型积分方程的快速求解方法 |
| 报告人 | 史永杰（汕头大学数学系） |
| 报告时间 | 2014年6月4日（周三）上午10:00 |
| 报告地点 | 数学实验室（工北412） |
| 主办单位 | 理学院 |

> 来源：汕头大学 OA 通知（理学院）
