据悉，2014年下半年全国计算机等级考试报名工作已启动。考试将于2014年9月20日9:00起分批进行，开考科目涵盖一级至四级，包括计算机基础、程序设计、网络技术、数据库技术、软件测试、信息安全和嵌入式系统开发等方向。

## 报名安排

| 事项 | 内容 |
| --- | --- |
| 报名时间 | 2014年6月23日至27日，周末不安排报名 |
| 报名地点 | 新行政中心三楼教务处学生事务窗口 |
| 报名材料 | 身份证原件，现场电子摄像并核对报名登记表 |
| 考试时间 | 2014年9月20日9:00起分批进行 |
| 报名费 | 一级至四级均为137元 |
| 咨询电话 | 86502402、86502411 |

考生须由本人签字确认报名信息。具体科目表及相关说明请查看 OA 附件。
