据悉，学生处于6月18日发布通知，2014届毕业典礼家长门票预约工作启动。

学校定于6月27日在体育馆举办2014届毕业典礼，将预留部分座位邀请毕业生家长出席。

## 预约安排

| 事项 | 内容 |
| --- | --- |
| 活动 | 汕头大学2014届毕业典礼，6月27日于体育馆举行 |
| 预约时间 | 2014年6月19日9:00至6月20日16:00 |
| 预约系统 | 汕头大学预约中心 http://activity.stu.edu.cn（需用个人校园网账号登录） |
| 预约规则 | 每位毕业生原则上最多可邀请两位家长，具体获票数视总体预约情况而定；非毕业生账号不得预约 |
| 门票数量 | 约450张 |
| 抽选方式 | 报名截止后统计并通过随机抽取决定获票名单及票数，结果将在办公自动化公布 |
| 发布单位 | 学生处 |

有意愿邀请家长观礼的毕业生请按时登录系统填写信息，逾期不再安排。

> 来源：汕头大学 OA 通知（学生处）
