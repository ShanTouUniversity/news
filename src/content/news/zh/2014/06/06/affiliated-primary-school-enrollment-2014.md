据悉，汕大附小于6月6日发布通知，将为2014年秋季小学一年级新生办理入学登记。

根据汕头市教育局文件，凡年满6周岁（2008年8月31日及以前出生）的校本部教职工子女为适龄儿童，请家长于2014年6月11日15:00—17:00到附小校长办公室办理登记手续。因特殊情况未能及时报名的，请提前联系，以免耽误教科书预订。

| 事项 | 内容 |
| --- | --- |
| 登记时间 | 2014年6月11日15:00—17:00 |
| 登记地点 | 汕大附小校长办公室 |
| 登记对象 | 校本部教职工子女中年满6周岁的适龄儿童 |
| 所需材料 | 户口本及家长工作证原件和复印件 |
| 联系电话 | 86502262 |
| 联系人 | 翁老师 |

根据汕市教〔2014〕29号文件，任何学校不得招收未满6周岁的儿童。适龄儿童因身体状况或特殊情况需延缓入学的，须由父母或其他法定监护人提出书面申请并提供相关证明。

> 来源：汕头大学 OA 通知（资源管理处、汕大附小）
