据悉，经有关部门批准，学校基建办公室将于第二、三食堂南侧空地建设砖砌隔油池，工程已委托汕头市东华建筑有限公司承建。

| 项目 | 信息 |
|------|------|
| 工程名称 | 第二、三食堂砖砌隔油池工程 |
| 施工地点 | 第二、三食堂南侧空地 |
| 施工单位 | 汕头市东华建筑有限公司 |
| 计划工期 | 2014年7月12日开工，8月10日前完工 |
| 项目负责人 | 陆春雄 |
| 现场管理员 | 陈锦武 |

基建办公室提醒，施工期间会产生一定噪音、振动和尘土，请过往行人和车辆注意安全，尽量避免在施工现场附近停留。

> 来源：汕头大学 OA 通知（资源管理处）
