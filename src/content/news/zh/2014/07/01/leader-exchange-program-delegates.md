据悉，为培养和提升学生的领袖才能，汕头大学将与宁波诺丁汉大学合作开展领袖生交换计划（第4期）。自6月17日启动选拔以来，经各单位推荐共有25位学生入围面试，最终经过两轮面试，确定任XX等10位同学入选本次交换计划。

## 入选名单

| 推荐单位 | 入选学生 |
| --- | --- |
| 校学生会 | 任XX（12法学）、蔡RH（12汉语言） |
| 校青协 | 李YQ（12英语） |
| 至诚书院 | 郑S（11数学） |
| 工学院 | 陈YS（12电子）、汤YL（12通信） |
| 法学院 | 林W（12法学）、邝HJ（12法学） |
| 文学院 | 毛YY（11英语） |
| FLY培训项目 | 张JH（12新闻） |

主办方表示，若上述同学因故无法参加此次交换计划，将根据第二轮面试结果排名依次递补，如有变动会及时通知相关同学。

据悉，入选学生需做好相关准备工作，并在8月25日小学期开始前返回学校参加相关培训。
