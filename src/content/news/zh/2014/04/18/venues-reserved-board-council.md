据悉，汕头大学第九届校董会第二次会议定于6月26日至27日举行。会议期间，学校还将同步举办毕业典礼等多项重大活动，并邀请重要嘉宾开展多种形式的交流活动。

为确保各项活动顺利举行，学校已对相关场馆做出统一安排。根据党政办公室发布的消息，以下场所在校董会活动期间将预留为专门用途：

| 场所 | 安排 |
| ---- | ---- |
| 大礼堂 | 预留为校董会活动专用 |
| 科学报告厅 | 预留为校董会活动专用 |
| 图书馆报告厅 | 预留为校董会活动专用 |
| 体育馆 | 预留为校董会活动专用 |
| 学术交流服务中心 | 预留为校董会活动专用 |

上述场所及设施在校董会期间不再承接其他活动安排。学校提醒各单位留意这一安排，如在此期间有活动计划，应另行选择场地或调整时间。

> 来源：汕头大学 OA 通知（党政办公室）
