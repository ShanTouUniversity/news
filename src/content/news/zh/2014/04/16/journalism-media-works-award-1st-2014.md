据悉，汕头大学长江新闻与传播学院将于4月15日至5月24日举办首届长江传媒作品奖活动，旨在奖励怀揣新闻理想、秉持专业精神、积极参与传媒实践的在校大学生。

## 参赛安排

| 事项 | 内容 |
| --- | --- |
| 参赛对象 | 长江新闻与传播学院在读学生 |
| 活动时间 | 2014年4月15日至5月24日 |
| 报名截止 | 2014年4月30日前 |
| 报名方式 | 下载报名表以“学生姓名+参赛类别”命名，发送至 jsprize@163.com；作品单独刻录光盘提交至秘书组联系人白帆（短号 69112） |
| 主办单位 | 长江新闻与传播学院 |

## 作品类别

| 类别 | 要求 |
| --- | --- |
| 新闻专题报道类 | 深度报道，题材不限，不少于2500字，可个人或小组参赛 |
| 摄影类 | 新闻摄影和专题摄影，专题不超过6张，附图片说明，可裁剪、调整对比度，不得 PS，须为个人作品 |
| 平面装帧设计类 | 书刊、海报设计等，书刊可个人或小组，海报仅限个人 |
| 互动视觉设计类 | 网站、App、动画制作等，可个人或小组参赛 |
| 视频类 | 纪实或非纪实视频，不超过30分钟，可个人或小组参赛 |
| 广告类 | 平面、摄影、视频、创意或策划广告等，可个人或小组参赛 |

## 奖项设置

每个类别设3个奖项，由评委评定，获奖作品将获奖金及荣誉证书，另设入围奖若干。作品不予退还，请妥善保管。

更多详情可关注官方微博“汕头大学新闻学院”或咨询相关联系人。报名表见 OA 附件，已作隐私保护不在此转载。
