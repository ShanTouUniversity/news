据悉，汕头大学科研处4月3日转发广东省委宣传部相关安排，面向省内高校思想政治理论课教师征集培育和践行社会主义核心价值观重大问题招标研究的建议选题。

征集工作旨在推动相关理论研究和成果建设，为培育和践行社会主义核心价值观提供学术支撑。校内有意参与的教师可结合教学科研实际提出选题，并在4月9日前将选题名称发送至 `yczhuo@stu.edu.cn`。

| 项目 | 详情 |
| --- | --- |
| 征集主题 | 培育和践行社会主义核心价值观重大问题 |
| 面向对象 | 省内高校思想政治理论课教师 |
| 提交内容 | 建议研究选题名称 |
| 截止时间 | 2014年4月9日 |
| 联系人 | 黄玉梅、卓燕淳 |
