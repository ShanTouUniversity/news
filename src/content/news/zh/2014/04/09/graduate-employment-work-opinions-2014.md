汕头大学近日发布汕大发〔2014〕32号文件，就2014年毕业生就业工作作出部署。文件显示，学校2013年毕业生初次就业率为97.15%，总体就业率为99.43%；面对广东高校毕业生规模和供需结构性矛盾，学校提出进一步提升就业质量和服务水平，推动毕业生充分就业。

## 工作重点

学校将通过校园招聘会、供需见面会和宣讲会拓展就业市场，并加强与人力资源部门、行业协会、商会及用人单位的合作。各单位还将建设就业实习基地，利用校友和专业机构等社会资源开展职业讲坛、就业工作坊等活动，同时支持学生参与创新创业竞赛、创业训练和项目孵化。

就业教育将重点引导毕业生到基层、农村学校及西藏、新疆等国家需要的地区就业，宣传基层就业、自主创业和应征入伍等政策。学校还将完善就业信息平台，提供网络招聘和视频面试等服务，通过就业信息网、电子邮件及就业资讯短信等渠道更新岗位信息。

针对就业困难学生，学校计划建立动态数据库，提供就业咨询、心理辅导和岗位推荐等帮扶，并加强对离校未就业毕业生的实名衔接和持续服务。学校将以职业生涯发展为目标，完善通识课程、职业测评和个性化咨询相结合的指导体系，推进就业指导队伍专业化。

文件同时提出建立毕业生就业质量跟踪调查和年度报告制度，将毕业生职业发展状况与社会需求反馈到专业设置和人才培养模式改革中。

## 2014年主要安排

| 时间 | 重点工作 |
| --- | --- |
| 1—6月 | 开展日常就业指导，为家庭经济困难本科毕业生提供求职补助，举办校友企业招聘会和就业服务月，收集并上报就业数据 |
| 4—5月 | 签订就业工作目标责任书，开展就业指导活动，关注尚未落实就业意向的学生，编制并上报2014届毕业生就业计划及2015届毕业生生源信息 |
| 6月 | 发放符合政策的就业奖励金，办理报到证，完成毕业教育、档案整理和离校前就业情况统计 |
| 7—9月 | 处理毕业生遗留问题，跟踪未就业毕业生去向，整理发送档案，汇总并公布各专业初次就业率 |
| 8—12月 | 为档案托管毕业生办理报到证，接收2014级新生档案，开展2015届毕业生招聘和就业指导活动 |
| 11月 | 汇总并上报6月以后落实工作单位的毕业生情况 |
| 10—12月 | 举办长江实业集团专场招聘会和2015届毕业生供需见面会，协助完成2015届毕业生资格审查 |
| 12月 | 按教育主管部门要求统计毕业生就业情况 |
