据悉，法学院于4月1日发布通知，启动与加拿大麦吉尔大学（McGill University）交换生项目，计划于2014年秋季学期选派本科生赴对方学习一学期。

## 项目安排

| 事项 | 内容 |
| --- | --- |
| 派出规模 | 法律系3名、公共管理系3名，共6名 |
| 交换院校 | 麦吉尔大学法学院及文学院政治系 |
| 交换学期 | 2014年秋季学期，为期一学期 |
| 费用 | 李嘉诚基金会提供学期交流奖学金（法学最高30,837加元、公管最高22,189加元），覆盖学费、生活费、住宿及机票；保险、护照、签证等自理 |
| 主办单位 | 法学院 |

## 选拔标准

1. 法律系二、三年级（2011、2012级）及公管系二年级（2011、2012级）在读本科生；
2. 英语听说读写能力良好，雅思6.5（单项不低于6.0）或托福90（单项不低于21）；
3. 专业扎实、成绩优秀，总GPA居专业前30%；
4. 具团队合作精神，积极参加公共服务，沟通表达能力强；
5. 性格开朗，适应新学习环境与境外学习问题能力强；
6. 同等条件下未参加过境外交流项目或比赛者优先。

## 报名方式与时间

| 事项 | 内容 |
| --- | --- |
| 网上报名 | 4月2日至4月7日通过汕头大学学生事务系统（sao.stu.edu.cn） |
| 报名材料 | 网上申请表打印件、在校成绩单、雅思/托福成绩单、英语作文（从3题中任选1题，不超过400字） |
| 题目示例 | A. 普通法传统中最感兴趣的方面；B. 中国政府如何改进环境保护；C. 加拿大议会体系源自威斯敏斯特传统的含义 |
| 面试 | 4月10日组织面试（材料初审通过者参加） |
| 材料提交 | 电子版打包发至 jjyao@stu.edu.cn（主题“学生姓名--麦吉尔学期交流项目”），纸质版送至法学院院长办公室（文北211）；截止4月7日，工作时间8:30—12:00、14:30—17:30 |
| 联系人 | 姚津津老师，电话 86503906，邮箱 jjyao@stu.edu.cn |

已参加香港大学、贝尔法斯特女王大学、延世大学面试且符合条件者亦可申请，但最终只能选择一个交换项目。
