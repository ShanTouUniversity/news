汕头大学粤语文化协会承办的“舌尖上的粤菜”微电影比赛将面向全校学生开放报名，鼓励参赛者以影像呈现粤菜烹饪、粤菜与其他菜系的比较或相关故事。作品时长须为3至10分钟，并附300字以内说明，语言不限。

比赛报名时间为4月23日至29日，作品提交时间为4月29日至5月6日，网上投票将于5月7日至14日进行，评比及颁奖安排在5月15日。评分由评委意见、微博点赞和团队互评构成，权重分别为50%、20%和30%。前三名将按累计成绩产生。

参赛者可个人或组队报名，每支队伍须有一名母语非粤语的本地队员。主办方将于4月23日在金三角设置现场报名点，也接受通过报名表提交申请。

| 事项 | 内容 |
| --- | --- |
| 报名 | 4月23日至29日 |
| 作品提交 | 4月29日至5月6日 |
| 网络投票 | 5月7日至14日 |
| 评比及颁奖 | 5月15日 |
| 承办单位 | 汕头大学粤语文化协会 |
