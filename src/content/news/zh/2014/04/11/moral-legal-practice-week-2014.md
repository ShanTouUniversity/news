据悉，社科部发布通知，将组织开展“道德与法律实践周”活动，以深化《思想道德修养与法律基础》课程教学改革，增强学生理论联系实际能力。

## 活动安排

| 板块 | 事项 | 内容 |
| --- | --- | --- |
| 道德实践周 | 参与对象 | 本学期选修《思想道德修养与法律基础》及《思想道德修养与法律基础》（道德）的学生 |
|  | 时间地点 | 第9周，校内 |
|  | 内容 | 开展“五个一”：做一件好事、纠一次违规、抄一句箴言、写一篇体会、参加一次讨论 |
|  | 具体安排 | 第8周教师布置安排；第9周走出课堂开展实践并撰写不少于800字体会，于第10周上交；任课老师推选优异者表彰发证 |
| 法律实践周 | 参与对象 | 选修《思想道德修养与法律基础》（法律）的学生 |
|  | 时间地点 | 第9周，校内 |
|  | 内容 | 每人寻找生活中涉及法律问题的案例并整理成文字，于第10周上交；任课老师推选优异者表彰 |

> 来源：汕头大学 OA 通知（社科部）
