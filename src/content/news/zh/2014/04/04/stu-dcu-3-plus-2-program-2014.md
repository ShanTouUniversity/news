汕头大学文学院面向相关学生启动与都柏林城市大学（DCU）SALIS 的“3+2本硕连读”项目报名。申请者可选择应用语言与翻译研究、国际交流语言—英语研究或当代文化与社会等专业方向。

申请者须在2014年4月30日17时30分前，将项目申请表、成绩单、英语考试成绩（如有）及一篇400字以内的英文作文，以邮件附件形式发送至 `myzheng@stu.edu.cn`。成绩单最迟可于5月21日前补交，邮件主题须按通知要求注明项目报名信息。

项目要求申请者达到相应英语成绩：托福 CBT 总分不低于237、iBT 不低于92或 PBT 不低于580；雅思总分不低于6.5且单项不低于6.0，申请应用语言与翻译研究专业者写作单项须达到6.5。

| 项目 | 详情 |
| --- | --- |
| 合作项目 | 汕大—都柏林城市大学3+2本硕连读项目 |
| 可选方向 | 应用语言与翻译研究、国际交流语言—英语研究、当代文化与社会 |
| 材料提交截止 | 2014年4月30日17时30分 |
| 成绩单补交截止 | 2014年5月21日 |
| 提交邮箱 | `myzheng@stu.edu.cn` |
| 费用说明 | 汕大本科四年级学费免缴；海外学费、住宿、交通、保险等由学生承担 |

都柏林城市大学对非欧盟学生学费给予汕大文学院学生15%的减免。减免后，所列本科专业年学费分别约为11,300欧元和12,100欧元，研究生年学费约13,300欧元，其他支出每年约10万元人民币。

> ⚠️ 项目申请表及专业详情请前往 OA 系统查看原文；申请邮件中的个人材料请勿公开发布。
>
