据悉，共青团汕头大学委员会于10月21日发布通知，将于10月22日下午2时在G4024教室举办2013—2014春季学期学生社团立项活动展示会，共有八个学生社团参展。

## 参展社团

| 社团名称 | 活动内容 |
| --- | --- |
| 灯谜爱好者协会 | 猜灯谜等传统民俗活动 |
| 吉他协会 | 吉他演奏与交流 |
| 兴潮社 | 潮汕文化与艺术展示 |
| 知识产权协会 | 知识产权知识普及 |
| 轮滑协会 | 轮滑表演与体验 |
| 毽球协会 | 毽球运动展示 |
| 手语俱乐部 | 手语交流与表演 |
| 科幻协会 | 科幻作品分享与创意展示 |

展示会面向全校师生开放，欢迎感兴趣的师生到场观摩交流。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
