据悉，网络与信息中心 MYSTUdio 将于10月23日晚举办 Movie Night 电影之夜。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 爆米花之夜，纯观影+影评 |
| 影片 | 《机器人总动员》（Wall·E） |
| 时间 | 2014年10月23日19:30—21:00 |
| 地点 | MYSTUdio（图书馆一楼） |
| 名额 | 70人，成功报名者将收到邮件通知 |
| 福利 | 每人提供饮料及小零食 |
| 主办单位 | MYSTUdio |

影片讲述公元2700年人类离开被垃圾覆盖的地球后，清理机器人瓦力与搜索机器人夏娃的奇幻旅程。

## 报名方式

| 事项 | 内容 |
| --- | --- |
| 报名时间 | 2014年10月21日起 |
| 报名方式 | 登录 MYSTU 活动页面进入“MYSTUdio—Movie Night 电影之夜20141023”点击“我要参加” |
| 报到 | 已收到邮件的报名者请于10月23日19:15到 MYSTUdio 报到 |
| 咨询 | 可在 MYSTU 活动讨论区留言，MYSTUdio 团队将回复 |

> ⚠️ 报名链接及活动详情请前往 OA 系统查看原文。
>
