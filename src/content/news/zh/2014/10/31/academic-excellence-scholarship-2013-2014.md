据悉，学生处于10月31日发布通知，公示2013—2014学年学业优秀奖学金入围名单，校本部各学院共有1199名学生入围，其中一等学业优秀奖学金167名、二等学业优秀奖学金427名、三等学业优秀奖学金605名。

学校设立学业优秀奖学金，以鼓励学生勤奋学习、刻苦钻研，在专业学术上取得优异成绩。该奖学金设一等奖1500元/人·年、二等奖1000元/人·年、三等奖500元/人·年。根据《汕头大学本科生奖学金管理办法》（汕大发〔2014〕83号）的规定，评选以GPA百分比在同年级同专业中的排名为依据：前5%可获一等，前15%可获二等，前30%可获三等。

## 公示信息

| 事项 | 内容 |
| --- | --- |
| 公示名单 | 一等167名、二等427名、三等605名，共1199名（名单见 OA 附件，已作隐私保护不在此转载） |
| 奖金标准 | 一等1500元/人·年，二等1000元/人·年，三等500元/人·年 |
| 评选依据 | 汕大发〔2014〕83号，GPA百分比居同年级同专业排名 |
| 评选程序 | 学生本人提交申请，经学校审核 |
| 异议截止 | 2014年11月3日（周一）17:00前 |
| 受理地点 | 行政中心106学生处助学工作管理中心（单位反映须加盖公章，个人反映须签署真实姓名） |
| 发布单位 | 学生处 |
