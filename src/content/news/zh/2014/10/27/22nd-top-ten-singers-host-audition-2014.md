据悉，汕头大学校团委于2014年10月27日宣布正式启动第二十二届"校园十大歌手"大赛新生主持人选拔工作，面向2014级全体新生招募优秀主持人。

## 选拔要求

主持人候选人需满足以下条件：

| 条件 | 说明 |
| --- | --- |
| 年级要求 | 2014级新生 |
| 表达能力 | 具有较强的语言组织及表达能力 |
| 普通话 | 标准流利 |
| 形象气质 | 五官清秀端正，主持大方得体、自信热情 |
| 应变能力 | 思维敏捷，处事灵活 |

## 报名方式

有意参与者可在校园内办公信息网下载报名表，发送至邮箱 `13smzhan@stu.edu.cn`。

报名截止时间为**2014年10月29日24:00**，请有意向的同学抓紧时间报名。

> 来源：汕头大学 OA 通知（校团委）
