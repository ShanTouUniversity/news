据悉，经各学院（书院）考核推荐，学生处和校友工作办公室复核，拟向35位高年级学生颁发2014年校友助学金，资助金额为2500元/人，现予公示。

## 公示安排

| 事项 | 安排 |
| --- | --- |
| 资助对象 | 高年级学生35人（例：谢XY等） |
| 资助标准 | 2500元/人 |
| 公示时间 | 2014年10月24日起至10月27日12:00 |
| 复核单位 | 学生处、校友工作办公室 |
| 推荐方式 | 各学院（书院）考核推荐 |

## 异议反馈

| 事项 | 要求 |
| --- | --- |
| 截止时间 | 10月27日（周一）上午12:00前 |
| 反馈形式 | 书面形式 |
| 受理地点 | 助学工作管理中心（行政中心106办公室） |
| 单位反馈 | 需加盖公章 |
| 个人反馈 | 需签署真实姓名 |

公示期间，如单位或个人有不同意见，可按上述要求反映。

> ⚠️ 受助学生完整名单请前往 OA 系统查看原文附件。
>
> 来源：汕头大学 OA 通知（学生处）
