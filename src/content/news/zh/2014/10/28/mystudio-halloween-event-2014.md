据悉，网络与信息中心 MYSTUdio 将于10月31日（周五）晚7:30至9:00在 MYSTUdio 举办万圣节活动，欢迎同学们积极参与。

## 活动详情

| 事项 | 内容 |
| --- | --- |
| 时间 | 2014年10月31日（周五）19:30—21:00 |
| 地点 | MYSTUdio |
| 参与名额 | 前50名成功报名者 |
| 着装要求 | 乔装出席（契合万圣节主题） |
| 活动环节 | 游戏互动、奖品发放、最佳服装奖评选 |
| 主办单位 | MYSTUdio |
| 报名截止 | 2014年10月30日 |

据悉，本次活动设有多个游戏环节，参与游戏即可获得奖品。另设最佳服装奖1名，鼓励同学们发挥创意、精心装扮。由于当日正值西方万圣节，所有参赛者均需乔装出席方可入场。

> 来源：汕头大学 OA 通知（网络与信息中心）
