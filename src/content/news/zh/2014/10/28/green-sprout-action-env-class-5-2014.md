据悉，汕头大学青年志愿者协会"绿丝带"服务学习环保义工队正式启动"绿芽行动"第五期环保课堂志愿者招募工作，主题为"与小学共行环保，与绿色重建和谐"。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 项目名称 | 绿芽行动第五期环保课堂 |
| 主办单位 | 青年志愿者协会"绿丝带"服务学习环保义工队 |
| 活动主题 | 与小学共行环保，与绿色重建和谐 |
| 志愿者培训 | 11月5日、12日 |
| 小学服务实践 | 11月19日、26日下午 |
| 服务地点 | 汕头市培苗小学 |
| 招募人数 | 20名志愿者 |

据悉，志愿者将在培训后前往汕头市培苗小学开展环保教育实践活动，通过寓教于乐的方式向小学生传播环保理念，共同守护绿色家园。

> 来源：汕头大学 OA 通知（校团委）
