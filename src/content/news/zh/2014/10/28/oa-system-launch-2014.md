据悉，汕头大学党政办公室与网络与信息中心于10月28日发布联合通知，宣布学校协同办公系统（OA系统）将于2014年11月1日正式启用。

原有办公信息系统自2001年投入使用以来已运行13年，随着学校信息化建设的不断推进，系统老化问题日益凸显，难以满足当前数字化办公需求。为进一步提升学校行政管理效率和信息公开水平，学校决定启动新版协同办公系统。

## 新OA系统功能

| 功能模块 | 说明 |
| --- | --- |
| 学校发文 | 实现学校层面各类公文的线上发布与管理 |
| 工作通知 | 各部门工作通知的在线发布与查询 |
| 通讯录 | 全校师生员工通讯录的在线查询与维护 |
| 文档管理 | 学校文档资料的在线归档与检索 |
| 公告浏览 | 全校师生可浏览和查询各类公告及通知信息 |

## 访问方式

| 项目 | 详情 |
| --- | --- |
| 启用时间 | 2014年11月1日 |
| 访问地址 | http://oa.stu.edu.cn |
| 覆盖范围 | 全校师生 |
| 发布单位 | 党政办公室、网络与信息中心 |

新OA系统的启用将有力推动学校办公自动化和信息公开的规范化建设，为师生提供更加便捷高效的信息服务。

> 来源：汕头大学 OA 通知（党政办公室、网络与信息中心）
