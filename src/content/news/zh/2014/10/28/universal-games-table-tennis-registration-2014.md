据悉，汕头大学体育部于10月28日发布通知，正式启动2015年大学生运动会乒乓球项目注册运动员的选拔工作，面向校本部研究生和本科生开展选拔。

## 选拔安排

| 项目 | 详情 |
| --- | --- |
| 选拔项目 | 乒乓球 |
| 赛事 | 2015年大学生运动会 |
| 选拔对象 | 校本部研究生、本科生 |
| 选拔时间 | 2014年11月9日 |
| 选拔地点 | 体育馆 |
| 报名截止时间 | 2014年11月5日前 |
| 报名方式 | 发送邮件至体育部邮箱 o_tyb@stu.edu.cn |
| 邮件标题 | 请注明"大运会乒乓球注册运动员报名" |

有意向参加选拔的同学请在报名截止前通过邮件方式向体育部报名，邮件标题需注明"大运会乒乓球注册运动员报名"字样。

> 来源：汕头大学 OA 通知（体育部）
