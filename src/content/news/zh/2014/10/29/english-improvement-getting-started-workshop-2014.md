据悉，英语语言中心将于11月3日举办英语入门工作坊，为校外及校内语言学习者提供学习规划指导。

## 工作坊安排

| 事项 | 内容 |
| --- | --- |
| 主题 | How Do I Improve My English: Getting Started Workshop |
| 时间 | 2014年11月3日（周一）16:00—18:00 |
| 地点 | CILL |
| 主讲人 | Nana Wei 女士、周茜 |
| 内容 | 为语言学习旅程提供指导建议，帮助学习者规划课外英语学习路径 |
| 预约方式 | http://fa14gettingstarted.eventbrite.com，名额有限 |
| 注意事项 | 请携带入场券参加；不确定能否参加者请勿报名，报名后务必出席 |
| 发布单位 | 英语语言中心 |

> 来源：汕头大学 OA 通知（英语语言中心）
