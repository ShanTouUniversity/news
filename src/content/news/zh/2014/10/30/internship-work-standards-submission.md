据悉，为落实《汕头大学本科学生实习管理条例》（汕大发〔2014〕80号）的要求，汕头大学正在推进各单位实习工作标准的制订与审核工作。实习工作标准是各教学单位组织开展实习工作的重要依据和指引。

教务处此前已于2014年6月18日将实习新条例及相关模板资料通过电子邮件发送至各教学单位领导，并要求做好标准的制订和提交。为进一步加快审核进度、便于实习工作的开展和检查督促，教务处现要求各教学单位于**2014年11月7日前**将本单位实习工作标准的纸质文档（须经系领导签名）报送教务处。随后，教务处将组织专家对各单位上报的标准进行审核，审核通过后予以公布。

关键信息一览：

| 项目 | 内容 |
| ---- | ---- |
| 制订依据 | 《汕头大学本科学生实习管理条例》（汕大发〔2014〕80号） |
| 报送截止 | 2014年11月7日前 |
| 报送要求 | 纸质文档，系领导签名 |
| 审核方式 | 教务处组织专家审核后公布 |
| 联系人 | 周梦依（86503202） |
