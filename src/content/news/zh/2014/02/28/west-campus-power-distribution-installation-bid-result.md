汕头大学基建办公室2月28日公示校园西区供配电设施安装工程施工单位的投标结果。根据学校招投标领导小组的评审推荐，广东润民建安工程有限公司汕头分公司确定为中标单位，中标金额为人民币534,229.50元，该金额已扣除103,635元的备选项目费用。

## 中标信息

| 项目 | 内容 |
| ---- | ---- |
| 工程名称 | 汕头大学校园西区供配电设施安装工程 |
| 中标单位 | 广东润民建安工程有限公司汕头分公司 |
| 中标金额 | ￥534,229.50元（已扣除备选项目￥103,635.00元） |
| 公示时间 | 2014年2月28日至3月3日 |
