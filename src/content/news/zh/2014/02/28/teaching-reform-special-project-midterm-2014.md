据悉，汕头大学教务处于2月28日发布通知，将对2013年度汕头大学教改专项立项建设项目进行中期检查。

## 检查安排

| 事项 | 内容 |
| --- | --- |
| 检查对象 | 2013年度汕头大学教改专项立项建设项目（详见附件） |
| 检查形式 | 1. 子项目提交中期检查表至单位总负责人及学校质量工程项目管理网站（3月14日前）；2. 单位自查并填写汇总表提交至教务处（3月24日前）；3. 教务处组织检查并于4月初公布结果 |
| 检查内容 | 项目进展、首批经费使用情况、阶段性成果、存在问题及改进措施、下一阶段计划；阶段性成果包括课程讲义、课件、论文及其他成果 |
| 结果运用 | 公布通过名单及反馈意见，下拨第二批研究经费 |

## 时间与材料提交

| 事项 | 内容 |
| --- | --- |
| 项目提交 | 3月14日前提交电子版至单位总负责人及学校质量工程项目管理网站 http://project.stu.edu.cn（用项目负责人校园网账户登录） |
| 单位提交 | 3月24日前完成自查并将《汕头大学教学改革专项自查情况汇总表》提交至教务处，联系邮箱 liz@stu.edu.cn |
| 发布单位 | 教务处 |

检查详情及附件请前往 OA 系统查看原文。
