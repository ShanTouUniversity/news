据悉，根据国务院学位委员会相关文件精神和教育部要求，汕头大学研究生学院已就2014年同等学力人员申请硕士学位工作作出安排。申请人需在规定时间内完成网上注册、信息填报、电子照片上传，并到校进行现场确认、采集图像及指纹、签署《诚信承诺书》。

## 资格审查材料

申请人需到研究生学院办理报名手续，提交学士学位证书、最后学历证书、身份证的原件及复印件（原件查验后退回），加盖原毕业学校或单位人事部门公章的本科阶段成绩单复印件，以及所在单位出具的简历、思想政治表现、工作成绩、科研成果、业务能力、外语程度等方面材料的密封件一式两份，同时填写相关表格并缴纳资格审查费150元。

## 时间安排

| 事项 | 时间/地点 |
| ---- | --------- |
| 网上信息填报 | 即日起至2014年3月20日（全国同等学力人员申请学位管理工作信息平台） |
| 现场确认 | 2014年3月6日 9:00-12:00、14:30-17:00 |
| 现场确认地点 | 汕头大学新行政中心426会议室 |
| 咨询电话 | 0754-86504745 |

## 现场确认流程

据安排，去年已完成现场确认的申请人今年无需重复办理。现场确认当天，申请人须出示有效证件，提交本科毕业证书、学士学位证书（或硕士学位证件）、二代身份证的原件及复印件、《申请学位资格审查申请表》一式两份以及信息平台注册ID等材料，所有复印件均须本人签字保证真实性；申请表"本人承诺"处须本人签名，并经院所审核盖章方为有效。

随后，学校将采集申请人图像信息，并采集左右手拇指、食指和中指指纹——至少六个手指，每个手指采集四次——最后生成资格审核表，由申请人确认签字。

校方特别提醒：申请人务必按上述时间完成现场确认，否则无法按时参加全国同等学力人员申请硕士学位水平考试的后果自负。
