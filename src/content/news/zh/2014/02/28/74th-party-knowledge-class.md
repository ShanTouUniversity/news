据悉，汕头大学党委组织统战部于2月28日发出安排，第七十四期党的基本知识学习班拟于今年3月份开学。各党总支、直属党支部现已启动学员的推荐初审和上报工作。

## 学员条件与推荐要求

根据安排，各单位报送的学员须同时满足两项条件：递交入党申请书满一年以上，且已被列为重点培养对象；同时要确保能在学习期间正常参加课程。

各总支、直属支部需在《报名表》上签署意见并加盖公章后，于2014年3月13日前统一报送至党校办公室（行政中心315），并将"学员名单汇总表"通过电子邮件发送至 o_dxb@stu.edu.cn。经党校办公室复查后，最终确定学员名单。

## 关键信息一览

| 项目 | 安排 |
| ---- | ---- |
| 开班时间 | 2014年3月 |
| 报名截止 | 2014年3月13日前 |
| 报送地点 | 党校办公室（行政中心315） |
| 名额分配及报名表 | 见 OA 原文附件 |

另据预告，第七十五期学习班预计于5月中下旬开班。
