汕头大学教务处近日启动2014年上半年学生普通话测试报名工作。报名学生须同时通过汕大学分制系统和广东省普通话水平测试考务管理系统完成网上预报名，考试时间将在报名数据报省审核后另行通知。

## 报名与确认安排

| 环节 | 时间或要求 |
| --- | --- |
| 网上预报名 | 登录汕大学分制系统“我要选课→资格考试报名”，并登录广东省普通话水平测试考务管理系统报名 |
| 打印报名表 | 3月1日至7日，自行打印《广东省普通话水平测试报名表》 |
| 缴费 | 3月10日由财务委托一卡通中心扣取，每人85元培训、测试费 |
| 现场确认 | 3月12日14:30—17:30，携报名表到行政中心三楼教务处事务窗口 |
| 考试地点 | 汕头职业技术学院普通话培训测试站 |

网上报名时，考区应选择“汕头市”，测试站选择“汕头职业技术学院普通话培训测试站”，考试场次选择“2014年上半年汕头大学测试”。报名信息提交后无法自行修改，也不允许重复报名；如信息有误，须在纸质报名表上修改后统一报送测试站管理员。

本次网上报名不要求上传电子相片，考生将在考试前半小时由测试站统一拍照。未成功扣费或未完成报名信息确认的，报名将不成功。

> 来源：汕头大学 OA 通知（教务处）
