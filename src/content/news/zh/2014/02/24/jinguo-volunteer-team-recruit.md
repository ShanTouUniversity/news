据悉，为深入贯彻党的十八大和中国妇女十一大精神，进一步弘扬"奉献、友爱、互助、进步"的志愿精神，引导广大妇女积极参与志愿服务，汕头市妇女联合会决定在全市组建首批20支巾帼志愿者队伍（汕妇通〔2014〕4号）。校工会已向全校女教职工发出号召。

## 报名信息

| 项目 | 详情 |
| ---- | ---- |
| 面向对象 | 有爱心的女教职工 |
| 报名材料 | 《汕头市巾帼志愿者报名登记表》 |
| 截止时间 | 2月28日 |
| 提交邮箱 | o_xgh@stu.edu.cn |
| 咨询电话 | 86502983 |

报道称，有意愿参加的女教职工可填写报名登记表，在2月28日前提交报名。登记表等材料详见相关附件。
