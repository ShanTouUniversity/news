据悉，商学院将于5月5日至10日开设《以价值为基础的创新》（Value Based Innovation）课程，由以色列理工学院 Shlomo Maital 教授主讲，并由梁强博士协助教学。

Shlomo Maital 为世界知名创业创新学者、Neaman 研究所高级研究员，曾任以色列理工学院学术主任并长期担任麻省理工学院访问教授，著有《The Technion Nation》等多部著作。该课程是其在麻省理工学院讲授20年、深受欢迎的创新课程，采用授课、互动、项目实习与实战演练等多种方式，旨在培养学生创新能力与商业技能。

## 课程安排

| 事项 | 内容 |
| --- | --- |
| 课程名称 | 以价值为基础的创新（Value Based Innovation） |
| 授课教师 | Shlomo Maital 教授（以色列理工学院），协助：梁强博士 |
| 教学语言 | 英语 |
| 授课时间 | 2014年5月5日至10日 |
| 修读人数 | 70名 |
| 学分 | 2学分；与已选课程冲突的，商学院可提供证明办理请假 |
| 承办单位 | 商学院 |
