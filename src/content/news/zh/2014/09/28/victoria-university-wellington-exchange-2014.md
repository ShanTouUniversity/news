据悉，汕头大学文学院于9月28日发布公示，根据国家留学基金委《2014年优秀本科生国际交流项目选派办法》及相关资助项目函件，学校“汕头大学与新西兰惠灵顿维多利亚大学交流项目”获批资助，将选派优秀本科生于2014—2015学年春季学期赴新西兰惠灵顿维多利亚大学交流学习。

## 选拔与公示

经学生自愿报名、选拔、学院审核与复议及学校审核等程序，本着“公平、公开、公正”及“自愿报名、择优选拔”原则，共有1名候选人符合推荐条件，现予以公示。为保护学生隐私，公示名单作匿名化处理。

| 事项 | 内容 |
| --- | --- |
| 交流院校 | 新西兰惠灵顿维多利亚大学 |
| 交流学期 | 2014—2015学年春季学期 |
| 资助项目 | 国家留学基金委优秀本科生国际交流项目 |
| 候选人数 | 1人 |
| 候选人 | 卢F，女，2012级英语专业 |
| 公示时间 | 2014年9月28日至9月30日 |

## 异议反馈

如对公示结果有异议，请于2014年9月30日前联系相关部门反映。
