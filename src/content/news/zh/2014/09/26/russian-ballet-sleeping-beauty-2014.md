据悉，俄罗斯国家芭蕾舞团将于2014年10月12日20:00在林百欣会展中心大会堂演出芭蕾舞剧《睡美人》。

## 演出及售票信息

| 项目 | 内容 |
| --- | --- |
| 演出时间 | 2014年10月12日20:00 |
| 演出地点 | 林百欣会展中心大会堂 |
| 票价 | 100、180、280、380、480、680及 VIP 880 元 |
| 售票时间 | 10月9日09:00—18:00 |
| 售票地点 | 工会一楼门前 |
| 校内优惠 | 汕大教职工或学生凭一卡通购票享8.5折 |

购票满280元及以上可获柴可夫斯基音乐车载 CD 一份，前10名购票者还可获价值30元抵用券，相关赠品送完即止。

> 来源：汕头大学 OA 通知（工会）
