据悉，汕头大学资源管理处将于2014年9月26日至30日在校区、龙泉园和成教学院开展防蚊灭蚊喷药作业，以配合省、市登革热防控工作。学校提醒师生员工配合作业并注意安全。

## 作业安排

| 日期 | 作业区域 |
| --- | --- |
| 9月26日 | 幼儿园、A—B型教工宿舍、排洪沟 |
| 9月27日 | 行政中心及周边、食堂、学术楼 |
| 9月28日 | 学生宿舍区域 |
| 9月29日 | 附中、附小至西区四合院 |
| 9月30日 | 龙泉园、成教学院 |

> 来源：汕头大学 OA 通知（资源管理处）
