据悉，人民网—中华慈善新闻网大学生记者团正在汕头大学开展招新。该记者团由中华慈善总会新闻界志愿者慈善促进工作委员会、人民网—中华慈善新闻网联合各高校发起成立，成员为热爱慈善公益事业、具备较强新闻创作和综合能力的在校大学生。

此次在汕大招新以"善聚青年的力量"为宗旨，旨在及时报道汕头大学的慈善公益活动以及汕头当地精神文明动态，为大学生提供实践机会和展示平台。

**成员权益**

- 统一核发工作证件，并在人民网—中华慈善新闻网正式注册为志愿者
- 有机会接受中央级媒体记者、编辑的培训
- 可在人民网—中华慈善新闻网发表署名新闻作品
- 可获得寒暑假实习及推荐就业机会，表现优秀者可赴总部实习并策划新闻选题
- 可参加网站举办的各大活动及年度优秀大学生记者评选，有机会获得优秀大学生记者助学金

**报名条件**

| 条件 | 要求 |
| ---- | ---- |
| 年级 | 本科二年级以上在校学生（含研究生），专业不限 |
| 素质 | 具有公益与新闻热情、责任心强、沟通协调能力强 |
| 技能 | 具备基本写作技能或其他特长 |
| 平衡 | 能兼顾专业学习与社会实践 |
| 加分项 | 有编辑采访经验或在报刊杂志发表文章者优先 |

有意向的同学须于10月10日前将电子报名表及作品提交至邮箱 dxsjzt2014@yeah.net，邮件主题注明"大学生记者团报名"。文字记者可提交不多于3篇的新闻或文学作品；摄影记者可提交3至5张图片（单张不超过1M）。材料审核通过者将收到笔试通知短信，之后统一参加笔试和面试。
