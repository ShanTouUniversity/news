据悉，科研处于9月24日发布通知，启动广东省教育科学“十二五”规划2014年度课题认定申报。

## 申报类别与要求

本次申报属于省级重大重点科研项目中的特色创新类（教育科学类），需符合以下要求：

| 事项 | 内容 |
| --- | --- |
| 归属规划 | 须属于学校2014—2016年度高等教育“创新强校工程”总体规划，未列入者原则上不得申报 |
| 负责人条件 | 申请和承担的省级财政支持项目不超过3项；须具良好政治素质及独立科研组织能力 |
| 申报对象 | 所有在岗教师 |
| 研究方向 | 围绕教育强省、教育现代化及南方教育高地目标，聚焦教育改革发展的重大现实与理论问题 |
| 学科领域 | 按11个学科组选择领域编号（jk001、jk002、jk004、jk006—jk013），不含教育信息技术与德育学科 |
| 成果形式 | 鼓励以论文和研究报告为最终成果（1—2年完成），专著 2—3年完成 |
| 限额 | 学校限报5项 |

## 程序与注意事项

申请人需填写《申报书》（附件1），于10月13日前将初稿发送至 yczhuo@stu.edu.cn 进行形式审核，由学校遴选择优推荐，获推荐者的后续流程由科研处邮件通知，逾期不受理。领域编号超出范围者按不合格处理。
