据悉，学生处于9月9日转发省教育厅通知，开展“我是您永远的学生——2014年教师节最温暖的问候大放送”祝福语征集活动。

今年9月10日将迎来我国第30个教师节。为弘扬尊师重教传统，“广东教育”微信邀请广大师生参与祝福语投稿，让学子向老师表达问候与祝福。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 我是您永远的学生——2014年教师节最温暖的问候大放送 |
| 截止时间 | 2014年9月10日 |
| 投稿方式 | “广东教育”微信后台直接留言；或投稿至邮箱 gdjytwx@163.com |
| 征集对象 | 所有现在和曾经做过学生的广大网友 |
| 内容要求 | 祝福语需有创意、有活力、有温度、有激情，字数约100字 |
| 加分条件 | 配图更佳，如当年与老师的合影或20年后成长照片 |
| 发布单位 | 学生处（转发省教育厅通知） |

格式范例及投稿说明见 OA 原文。欢迎广大师生踊跃参与，向喜爱的老师送上节日祝福。

> 来源：汕头大学 OA 通知（学生处）
