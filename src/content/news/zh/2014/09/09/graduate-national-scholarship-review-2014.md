据悉，研究生学院于9月9日发布通知，启动2014年度研究生国家奖学金评审工作。

## 评审安排

| 事项 | 内容 |
| --- | --- |
| 评审对象 | 具有我国国籍、取得汕头大学学籍的全日制在读研究生，当年毕业者除外 |
| 奖励标准 | 博士3万元/人·年，硕士2万元/人·年，由中央财政出资 |
| 申请时间 | 2014年9月6日至18日17:30 |
| 申请方式 | 登录学生事务系统提交申请并双面打印《研究生国家奖学金申请审批表》，经导师签字后连同证明材料于9月18日前提交至学院评审委员会 |
| 评审程序 | 学生自主申报→学院评审委员会初评公示（不少于5个工作日）→学校评审领导小组审定公示（不少于5个工作日）→上报省厅 |
| 提交材料 | 博士/硕士获奖学生汇总表、科研及获奖情况汇总表、申请审批表、评审细则及评审情况报告等 |
| 联系人 | 王风奇、黄美萍，电话 86504000（短号 884000），邮箱 mphuang@stu.edu.cn |
| 发布单位 | 研究生学院 |

参评条件包括热爱祖国、拥护党的领导、遵纪守法、诚实守信、学习成绩优异、科研能力显著等。评审将充分尊重导师推荐意见，必要时组织答辩。

> ⚠️ 申请表及相关表格请前往 OA 系统查看原文附件。
>
> 来源：汕头大学 OA 通知（研究生学院）
