据悉，汕头大学工会将在李嘉诚基金会支持下，于10月12日举办2014年8月至10月教职工生日聚会，活动面向符合月份条件的教职工及其家属。

聚会将于当天11:30至13:00在庄氏祥记国瑞店举行。教职工可于9月24日8:00至30日15:00通过预约系统报名，缴费安排为10月8日至9日，入场券领取时间为10月11日9:30至12:00。活动不安排交通车，参加者需自行前往并注意安全。

## 活动信息

| 项目 | 内容 |
| --- | --- |
| 活动 | 2014年8月至10月教职工生日聚会 |
| 时间 | 2014年10月12日11:30—13:00 |
| 地点 | 庄氏祥记国瑞店（国瑞店） |
| 预约时间 | 2014年9月24日8:00至9月30日15:00 |
| 预约方式 | 通过工会预约系统报名 |
| 咨询电话 | 86503545（网络中心） |

工会提醒，报名缴费后不能退票；教职工家属凭票参加，儿童须由至少一名家长陪同。活动方案及预约操作细则以 OA 附件为准。
