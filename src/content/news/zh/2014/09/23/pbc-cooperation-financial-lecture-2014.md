据悉，共青团汕头大学委员会与商学院将于9月24日在科学报告厅举办中国人民银行汕头支行与汕头大学合作签订仪式暨金融知识专题讲座。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 中国人民银行汕头支行与汕头大学合作签订仪式暨金融知识专题讲座 |
| 时间 | 2014年9月24日14:00 |
| 地点 | 科学报告厅 |
| 讲座内容 | 《人民币真伪辨别知识》《银行卡交易与风险防范》《信用伴我成长 启航青春人生》等 |
| 形式 | 各银行专业人士现场咨询及专题讲座 |
| 主办单位 | 共青团汕头大学委员会、商学院 |

本次讲座内容贴近师生日常的信用卡使用、贷款及网上银行等业务，有助于提升银行交易风险防范意识，欢迎全校师生参加。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会、商学院）
