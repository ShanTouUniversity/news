据悉，汕头大学财务处近日依据原国家计委、财政部、教育部印发的《教育收费公示制度》（计价格〔2002〕792 号）以及《汕头大学校务公开实施细则》（汕大党字〔2009〕第 27 号）的有关规定，将学校 2014 年的教育收费项目和收费标准向社会公示。

## 咨询与投诉渠道

| 渠道 | 联系方式 |
| ---- | -------- |
| 市民服务热线 | 12345 |
| 广东省价格服务热线 | 020-12358 |
| 汕头大学财务处电话 | 86502101 |

根据公示安排，具体的收费项目明细以附件表格形式发布，涵盖学校各项教育收费内容。若师生或社会人士对收费项目、收费标准有异议，可通过上述市民服务热线、省价格服务热线或学校财务处电话进行投诉及查询。

教育收费公示制度旨在提高高校收费的透明度，保障学生和家长的知情权与监督权。
