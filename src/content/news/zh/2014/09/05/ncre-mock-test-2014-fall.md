据悉，教务处于9月5日发布通知，2014年下半年全国计算机等级考试模拟测试安排公布。

2014年下半年全国计算机等级考试将于9月20日分批进行。为测试考试软件与系统环境运行状况、保障考试顺利进行，学校定于9月10日16:00—17:00在E102机房组织模拟测试。测试按先到先安排的原则，请已报名考生按期参加。

| 事项 | 内容 |
| --- | --- |
| 考试 | 2014年下半年全国计算机等级考试，9月20日分批进行 |
| 模拟测试时间 | 2014年9月10日16:00—17:00 |
| 模拟测试地点 | E102机房 |
| 原则 | 先到先安排 |
| 发布单位 | 教务处 |

请同学们相互告知。

> 来源：汕头大学 OA 通知（教务处）
