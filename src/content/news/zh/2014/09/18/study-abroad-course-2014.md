据悉，汕头大学英语语言中心2014年秋季学期开设《Study Abroad》选修课，欢迎符合条件的学生通过学分制系统选课。

## 课程信息

| 项目 | 内容 |
| --- | --- |
| 课程名称 | Study Abroad |
| 主讲教师 | Myra Anne Ingmanson |
| 上课周期 | 第1至第16周，每周一次 |
| 上课时段 | 周二第8、9节或周四第6、7节 |
| 上课地点 | CILL |
| 选课要求 | 已修完 ELC4 课程 |
| 选课方式 | 登录学分制系统选课 |

课程介绍及具体教学内容以英语语言中心随通知发布的课程说明为准。
