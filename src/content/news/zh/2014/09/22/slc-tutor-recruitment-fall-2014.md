据悉，学生处互助学习中心（SLC）于9月22日发布通知，因学业问询课程设置需要，面向校内招募2014年秋季学期导生。

## 招募要求

| 事项 | 内容 |
| --- | --- |
| 对象 | 汕头大学本部本科生（二年级及以上） |
| 条件 | 责任心强、态度友好、沟通能力较强；学习成绩优良，所服务课程成绩需排在前20%以内（特殊情况需提供任课教师证明） |

## 导生职责

带动自主学习风气，分享学习方法与经验，耐心解答疑问，组织专业课程交流讨论，了解服务对象进度并主动提供适合的服务。工作时间一般为每学期第3至16周。

## 待遇与报名

按学校勤工俭学岗位导生标准发放报酬。

| 事项 | 内容 |
| --- | --- |
| 报名截止 | 2014年9月28日前 |
| 报名方式 | 登录“学生勤工助学申请系统”（http://qgjx.stu.edu.cn）提交申请表，需详细填写联系方式 |
| 咨询 | 向各院系 SLC 学生联络员垂询，招募课程及联系方式见 OA 附件 |
| SLC 联系方式 | 电话 86502250、邮箱 slc@stu.edu.cn、网页 http://slc.stu.edu.cn |
| 发布单位 | 学生处、互助学习中心 |

> ⚠️ 招募课程列表及联络员联系方式请前往 OA 系统查看原文附件。
>
