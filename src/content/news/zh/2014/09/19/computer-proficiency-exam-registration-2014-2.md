据悉，教务处于9月19日发布通知，2014年第二次全国高等学校计算机水平考试报名工作启动。

## 考试安排

| 事项 | 内容 |
| --- | --- |
| 考试时间 | 2015年1月3日8:00起，分批进行，每批次考试时间105分钟 |
| 考试方式 | 计算机网络考试 |
| 考试科目 | 一级：计算机应用（2010）；二级：Visual Basic 程序设计、Visual FoxPro 程序设计、C++ 程序设计、Access 数据库（2003）、Photoshop 图像处理与制作、网页制作基础、Flash 动漫制作、Office 2010 高级应用、Java 程序设计、电子商务（每人每次限报两个科目，可跨级别） |
| 报名时间 | 2014年9月19日至10月7日 |
| 报名方式 | 登录学分制系统：我要选课 → 资格考试报名 |
| 报名费 | 38元/人·科 |
| 缴费方式 | 10月8日由财务处委托网络中心从一卡通账户统一扣取，余额不足则报名失败 |
| 发布单位 | 教务处 |

> 来源：汕头大学 OA 通知（教务处）
