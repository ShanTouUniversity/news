据悉，汕头市定于9月25日下午举办“汕头市知识产权专家高级培训班”，以配合全国知识产权执法维权“护航”专项行动，提升专家库专家及合作单位专业人员的业务水平。

## 培训安排

| 事项 | 内容 |
| --- | --- |
| 时间 | 2014年9月25日下午 |
| 主办单位 | 汕头市知识产权局 |
| 承办单位 | 广东省知识产权培训（汕头大学）基地 |
| 协办单位 | 中国（汕头）知识产权维权援助中心、汕头市专利保护协会 |
| 主讲嘉宾 | 国家知识产权局专利复审委员会外观诉讼处樊晓东副处长等专家 |
| 内容 | 专利侵权判定、专利奖评审事项等 |
| 报名截止 | 2014年9月22日下班前，将报名回执发至 chenjs@stu.edu.cn，以便派车接送 |
| 发布单位 | 科研处 |

培训面向我校汕头市知识产权专家库专家及有兴趣参加的老师。

> ⚠️ 报名回执等附件请前往 OA 系统查看原文。
