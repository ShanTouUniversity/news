国家社科基金2014年度中华学术外译项目启动申报。汕头大学科研处转发申报信息，项目支持优秀中国学术成果翻译，并由国外权威出版机构出版发行。支持语种包括英文、法文、西班牙文、俄文、德文、日文、韩文和阿拉伯文。成果须不少于10万字，通常不超过30万字；资助标准约为每10万汉字10万元，单项资助不超过50万元。

申报成果须在申报前与国外权威出版机构签订出版合同；翻译项目还须取得相关版权授权。科研人员、科研机构和国内出版机构可按规定申请。申请材料须于2014年2月24日前提交形式审查，并于2月28日前将合格材料交科研处。

| 项目 | 要求 |
| --- | --- |
| 支持语种 | 英、法、西、俄、德、日、韩、阿拉伯语 |
| 资助标准 | 每10万汉字约10万元，单项不超过50万元 |
| 成果篇幅 | 不少于10万字；一般不超过30万字 |
| 形式审查 | 2014年2月24日前发送至 yczhuo@stu.edu.cn |
| 校内材料截止 | 2014年2月28日 |
| 联系人 | 黄玉梅、卓燕淳；86502563 |
