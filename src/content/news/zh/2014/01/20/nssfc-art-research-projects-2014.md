据悉，2014 年度国家社会科学基金艺术学项目的申报工作已正式启动。汕头大学科研处近日向校内各有关单位转发申报安排，申请人须在规定时间前通过申报系统完成材料提交。

## 项目类别与申请门槛

| 类别 | 申请条件 |
| ---- | -------- |
| 重点项目 | 副高级以上职称或博士学位，且须为完成过省部级以上同专业研究课题的负责人 |
| 一般项目 | 副高级以上职称或博士学位，且须在相关研究领域核心期刊发表相关论文 3 篇 |
| 青年项目 | 申请人及课题组成员年龄不超过 35 周岁（1979 年 3 月 31 日之后出生）；无副高以上职称或博士学位者须由两名正高级同行专家推荐 |
| 文化部文化艺术科学研究项目 | 原则上面向文化系统人员申报的课题，以及紧密围绕国家和地方文化艺术建设实际、亟需开展的研究课题 |

## 校内申报时间节点

| 节点 | 时间 |
| ---- | ---- |
| 提交申报材料做形式审查 | 3 月 17 日前 |
| 提交终稿审核 | 3 月 25 日前 |

据通知内容，课题负责人同年度只能申报一个国家社科基金艺术学项目，在研国家级项目负责人不得再申请新项目；全日制研究生不能申请。选题方面，申请人既可依据《2014 年度国家社会科学基金艺术学项目课题指南》拟定题目，也可根据研究兴趣申报自选课题，两者在评审程序和资助强度等方面同等对待。

申报人需登录指定系统以身份证号注册账号并填写申报书，其中"活页"论证字数不得超过四千字，且不得出现申请人及成员姓名、单位名称等信息。科研处提醒，凡弄虚作假经查实将取消 3 年申报资格；评审期间走访或行贿评审专家的，一经查实公开通报批评并撤项。
