据悉，文学院于1月16日发布通知，启动与爱尔兰都柏林城市大学人文与社会科学学院交换生项目选拔工作，以便拟申报2014—2015学年秋季学期项目的同学提前与家人沟通并准备材料。

## 选拔安排

| 事项 | 内容 |
| --- | --- |
| 选拔名额 | 5名 |
| 选拔范围 | 文学院2012级和2013级全日制本科生（2014年9月秋季学期为二年级或三年级） |
| 合作院校 | 爱尔兰都柏林城市大学人文与社会科学学院（Faculty of Humanities and Social Sciences, Dublin City University） |
| 交换形式 | 一学期或两学期，申请时可选“Both”服从调剂 |
| 费用说明 | 向汕大正常缴纳学费，DCU 免收交换生学费；国际旅费、生活费、住宿等每月约700—900欧元（约6000—8000元人民币）需自理 |

## 选拔标准

1. 学业成绩优异；
2. 具备一定经济条件；
3. 英语听、说、读、写能力较强，自行参加雅思考试6.0分以上（用于签证）；
4. 心智成熟、具独立性与团队精神；
5. 认可并善于对外宣传汕头大学办学特色。

## 报名方式

| 事项 | 内容 |
| --- | --- |
| 报名材料 | 申请表、GPA及排名证明、英文水平证书复印件（如有） |
| 提交时间 | 2014年4月4日上午下班前 |
| 提交地点 | 文学院团委办公室（文科楼南201），纸质与电子文档并交 |
| 电子邮箱 | twwxy@stu.edu.cn |
| 选拔流程 | 书面初审 → 笔试（阅读与英文写作）→ 面试（语言能力）→ 确定5人推荐至 DCU |

学校网址 http://www.dcu.ie/schools.shtml 供参考。申请表见 OA 附件。
