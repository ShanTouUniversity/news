汕头大学科研处发布申报信息，组织学校出版社、哲学社会科学期刊编辑部的相关工作人员申报2014年度教育部人文社会科学研究一般项目。教育部将通过课题指南引导高校出版工作者围绕高校出版管理与发展等理论和实践问题开展研究。

申报对象须为出版社或哲学社会科学期刊的在编在岗人员。规划基金项目申请者须具有编审或副编审职称；青年基金项目申请者须具有编辑及以上职称，且出生日期为1974年1月1日以后。申请题目须严格按照课题指南确定，不得擅自更改。申报办法和评审事项按照教育部人文社会科学研究一般项目相关要求执行。

| 项目 | 要求 |
| --- | --- |
| 申报对象 | 学校出版社、哲学社会科学期刊在编在岗人员 |
| 规划基金 | 具有编审（含副编审）职称 |
| 青年基金 | 具有编辑及以上职称，1974年1月1日以后出生 |
| 申报依据 | 教育部课题指南及一般项目申报要求 |
| 校内联系人 | 黄玉梅、卓燕淳 |
