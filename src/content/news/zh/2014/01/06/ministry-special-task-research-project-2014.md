汕头大学科研处发布通知，启动2014年度教育部人文社会科学研究专项任务项目（高校思想政治工作）申报。项目分为一类课题、二类课题和辅导员骨干专项课题，资助额度原则上分别为每项5至6万元、2万元和1万元，研究期限分别为2年、1年和1年。

申报实行限项管理，每类课题学校最多申报2项。申请人每人限报1项，且须实际承担项目研究和实施工作；辅导员骨干专项面向高校专职辅导员。正在承担相关教育部、国家社科基金或国家自然科学基金项目的负责人等，不符合本次申报条件。项目申请须通过中国高校人文社会科学信息网项目申报系统完成，并按要求提交电子版和纸质材料。

| 节点 | 要求 |
| --- | --- |
| 电子版形式审查 | 2014年2月21日前发送至 yczhuo@stu.edu.cn |
| 纸质材料及确认电子文档 | 2014年2月27日前交科研处 |
| 学校限额 | 每类课题最多申报2项 |
| 联系人 | 黄玉梅、卓燕淳 |
| 联系电话 | 86502563 |

通知还要求申请人遵守匿名评审、材料真实性和知识产权等规定。课题指南及申请材料模板请以原通知附件为准。

> 来源：汕头大学 OA 通知（科研处）
> ⚠️ 课题指南、申请书模板及申报附件请前往 OA 系统查看原文。
