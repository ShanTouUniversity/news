据悉，汕头大学科研处于1月17日启动2014年度国家自然科学基金项目申报工作，并公布校内审核、修改和报送时间安排。

## 校内时间节点

| 时间 | 工作安排 |
| --- | --- |
| 1月17日起 | 申请人开始填写2014年版申请书；面上项目采用离线方式，其他类型项目采用在线方式 |
| 2月25日前 | 学院完成形式审查、组织专家评审并返回修改意见 |
| 2月27日 | 各学院向科研处报送申请书初稿 |
| 2月27日至3月8日 | 科研处集中进行形式审查、检查限项并反馈意见 |
| 3月8日至12日 | 申请人根据意见修改申请书 |
| 3月13日 | 各学院报送终稿一式两份及相关电子材料 |
| 3月13日至15日 | 科研处复查、盖章并上传数据 |
| 3月16日 | 学校统一向国家自然科学基金委员会报送申请书 |

## 申报提醒

通知同时提醒申请人关注项目类型调整、限项申请和项目总数限制等资助政策。申请材料应按要求提交纸质原件和电子版，相关附件包括博士后承诺书、专家推荐信、导师同意函、伦理审查证明等材料。

除面上项目外，其他集中接收项目原则上通过ISIS系统在线填写。项目组成员在2月27日提交申请书后原则上不得更换，如确需调整，应于3月4日前向科研处提交书面报告。

联系人为胡云翔、朱长盛，联系电话86502813。具体项目指南和表格以 OA 附件为准。
