汕头大学工学院课程组将举办2013年秋季学期App Inventor移动编程大赛，参赛对象为校本部参加《移动编程导论》课程的学生。参赛者自愿报名，课程教师将根据学生提交的课程创新报告，每个教学班遴选不超过5件优秀作品参赛。

报名截止时间为2014年1月12日23:59。比赛计划于2014年3月中旬公布获奖名单并颁发奖品。一等奖1名，奖品为10英寸三星平板电脑；二等奖7名，奖品为7英寸三星平板电脑。获奖学生需同意作品作为教学案例使用，并按课程需要参与相关网站管理、服务或助教工作。

| 项目 | 安排 |
| --- | --- |
| 报名对象 | 参加《移动编程导论》的校本部学生 |
| 报名截止 | 2014年1月12日23:59 |
| 作品遴选 | 每个教学班不超过5件 |
| 获奖公布 | 2014年3月中旬 |
| 奖项 | 一等奖1名；二等奖7名 |
