据悉，理学院招生与就业工作委员会于5月20日发布通知，面向全校招募湛江、茂名两市高考招生咨询志愿者。

为加强对外宣传，吸引优秀生源报考汕头大学，理学院负责组织两地高考填报志愿咨询活动。

## 招募安排

| 事项 | 内容 |
| --- | --- |
| 招募对象 | 生源地为湛江市或茂名市的在校本科生、研究生 |
| 服务内容 | 6月底回到生源地参加高考填报志愿咨询活动，介绍学校情况和招生信息 |
| 报名条件 | 对学校认同感强、乐于参与招生宣传；具备良好沟通能力；接受理学院选拔培训并服从调派 |
| 政策支持 | 志愿服务与社会实践相结合，提供交通、误餐等经费补助 |
| 报名截止 | 2014年5月31日前 |
| 报名方式 | 下载报名表据实填写，发送至 ltzhang@stu.edu.cn，邮件标题注明“招生咨询志愿者报名”，文件命名为“学院+高中+姓名”（例：文学院+湛江第一中学+张三） |
| 联系人 | 理学院团委张老师，电话 86502779 |
| 组织单位 | 理学院招生与就业工作委员会 |

活动安排等详情见 OA 附件。
