汕头大学商学院与中国银行汕头分行面向商学院全日制本科生和研究生招聘第八批人才储备类实习生，共10人。实习期为2014年7月1日至8月31日，工作地点为中国银行汕头分行本部及辖属机构。

## 实习信息

| 项目 | 内容 |
| --- | --- |
| 工作内容 | 非涉密资料整理、录入和维护 |
| 工作时间 | 工作日8:30—12:00、14:00—17:30 |
| 实习补贴 | 40元/日，按规定代扣个人所得税 |
| 其他待遇 | 提供午餐，并统一购买团体人身意外伤害商业保险 |
| 报名截止 | 6月10日17:00 |
| 报名邮箱 | btsu@stu.edu.cn |
| 联系电话 | 82902725 |
| 岗前培训 | 6月12日15:00，商学院研讨室 |

实习生须遵守中国银行的管理、劳动纪律及保密要求，并参加岗前和在岗培训及考评。表现良好者可进入中国银行汕头分行校园招聘备选人才库。报名登记表及相关附件请前往 OA 系统查看原文。
