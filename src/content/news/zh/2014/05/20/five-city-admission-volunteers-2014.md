据悉，为做好汕头大学2014年本科生招录工作，让考生及家长进一步了解学校办学理念和特色，工学院现面向全校学生招募揭阳、惠州、东莞、汕尾、深圳等5市的高考招生咨询志愿者，为考生和家长提供填报志愿等方面的咨询服务。

## 招募概况

| 项目 | 详情 |
| ---- | ---- |
| 面向对象 | 生源地为揭阳（含普宁市、揭东县、揭西县、惠来县）、惠州（含惠东县、惠阳区、博罗县、龙门县）、东莞、汕尾（含海丰县、陆丰市、陆河县）、深圳5市的在读本科生、研究生 |
| 服务时间 | 初定6月26日至28日，以各中学高三毕业生回校时间为准 |
| 报名截止 | 2014年6月4日 |
| 培训安排 | 6月中旬集中培训 |

## 工作内容与保障

报道称，志愿者将协助工学院派出的老师开展高考志愿填报咨询活动，向考生和家长介绍学校招生政策并解答疑问。报名者须为正式注册的在读学生，认同汕大办学理念，熟悉本校及所在学院情况，具备良好的沟通表达与团队协作能力。

学校将为报名参加的同学提供集中培训，并为志愿者回母校宣传提供一定的交通误餐补助，对表现突出的先进个人予以表彰奖励。

报名可以个人或团队形式进行（团队须注明负责人）。报名表须于6月4日前发送至 ydshen@stu.edu.cn，邮件标题注明"高考招生咨询志愿者报名"，附件按"学院+高中学校+姓名"格式命名。联系人沈老师，办公电话86502986。
