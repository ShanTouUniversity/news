据悉，2013-2014学年度春季学期汕头大学学生社团立项活动之一——第一届潮汕校园灯谜大会已于近日圆满结束。共青团汕头大学委员会、汕头大学学生社团联合会和汕头大学灯谜爱好者协会于5月30日联合公布获奖名单。

本届大会设个人笔猜和学校竞猜两个组别，吸引了潮汕地区多所学校的学生参与，最终获奖者来自潮汕地区四所学校。

## 获奖名单

### 个人笔猜

| 奖项 | 获奖者 | 所在学校 |
| ---- | ------ | -------- |
| 一等奖 | 陈DB | 汕头私立广厦学校 |
| 二等奖 | 黄LQ | 韩山师范学院 |
| 三等奖 | 王WJ | 达濠华侨中学 |

### 学校竞猜

| 奖项 | 获奖队伍 |
| ---- | -------- |
| 一等奖 | 韩山师范学院"他们猜得队" |
| 二等奖 | 达濠华侨中学"濠江小队" |
| 三等奖 | 汕头私立广厦学校队、汕头大学"朝夕相队" |

其中，汕头大学"朝夕相队"作为东道主代表队之一，与汕头私立广厦学校队并列获得学校竞猜三等奖。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
