为改善校园环境卫生，汕头大学资源管理处将于 6 月 2 日至 8 日在校区、龙泉园和成教学院开展灭蚊蝇工作。学校提醒师生员工在相关区域活动时注意安全。

| 日期 | 作业区域 |
| --- | --- |
| 6月2日 | 学术交流中心周围、P楼、学生宿舍区 |
| 6月3日 | 医科楼、新教学楼、G、H、I、J座学生宿舍 |
| 6月4日 | 校卫队办公场地周边、校门口、各校道、新图书馆外围 |
| 6月5日 | 第二、三食堂及老行政楼周围 |
| 6月6日 | 水库坝、A—B教工宿舍区、789号楼 |
| 6月7日 | 龙泉园、成教学院 |
| 6月8日 | 附中、附小至西区四合院 |

> 来源：汕头大学 OA 通知（资源管理处）
