据悉，至诚书院于5月7日发布通知，将于5月17日举办第三期“礼仪文化学习营”。

本次学习营旨在促进宿生对中西礼仪的了解，提升礼仪文化素养和个人气质，养成遵守公共道德的自觉性。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 时间 | 2014年5月17日8:00—18:00 |
| 学习内容 | 《常礼举要》、中华礼仪文化、礼仪学习关键、礼与个人家庭社会关系、社交细节及身边礼仪（交往艺术、形象塑造、餐桌礼仪）等 |
| 学习形式 | 讲座、专家视频、小组研讨，个人研习与集中学习相结合 |
| 面向对象 | 至诚书院宿生及学校其他住宿区同学（自愿报名） |
| 招收名额 | 32名（至诚书院26名，其他住宿区6名，按报名先后录取） |
| 报名要求 | 谦虚好学、能静心学习、具团队协作精神、服从安排、活动期间无其他课程安排等 |
| 报名截止 | 2014年5月13日17:00前 |
| 报名方式 | 登录预约系统 http://booking.stu.edu.cn 填写报名材料 |
| 发布单位 | 至诚书院 |

> 来源：汕头大学 OA 通知（至诚书院）
