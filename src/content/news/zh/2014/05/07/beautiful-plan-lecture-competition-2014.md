据悉，共青团汕头大学委员会与学生处于5月7日发布通知，将举办学生社区X计划之“社团之声——美丽计划”系列讲座与美丽计划大比拼活动。

活动旨在丰富宿舍生活、活跃社区氛围、提升艺术修养，为师生提供美容信息交流平台，助力和谐、活力社区建设。

## 活动安排

### 一、美丽计划讲座

| 事项 | 内容 |
| --- | --- |
| 主题 | 传递美丽，分享美丽 |
| 时间 | 2014年5月10日19:00 |
| 地点 | E座301室 |
| 主讲人 | 《今日视线》主播陈维斯 |
| 内容 | 化妆（淡妆/彩妆/化妆品介绍）、礼仪、护肤、减肥瘦身、正式场合着装、发型等 |
| 报名方式 | 通过短信向指定联系人报名，信息包括宿舍号、姓名及联系方式（详见OA通知与附件） |

### 二、美丽计划大比拼

| 事项 | 内容 |
| --- | --- |
| 主题 | 清心玉映，携手美丽 |
| 时间 | 2014年5月18日 |
| 地点 | 金三角 |
| 比赛方式 | 第一场画职业妆；第二场抽签决定妆容主题；内容可能结合讲座情况调整 |
| 评分规则 | 评委评分70% + 现场观众投票30%，总分前三名分获一、二、三等奖 |
| 报名截止 | 2014年5月17日24:00前 |
| 报名方式 | 通过短信或填写报名表以邮件方式向指定联系人/邮箱报名（详见OA附件） |

如有疑问可向指定联系人咨询。报名表等详情请前往OA系统查看原文附件。
