据悉，共青团汕头大学委员会联合《汕大青年》报编辑部将举办“学霸也疯狂”知识竞赛，面向全校学生开放。初赛将于2014年5月10日15:00至17:00在 E 阶201举行，决赛定于5月18日14:30至16:00举行，具体地点另行通知。

参赛者可自由组队，每队最多3人。初赛通过必答和抢答环节决出前五名队伍，决赛再通过多轮比赛产生一至五等奖各1名，并给予相应奖励。报名截止时间为5月9日18:00。

## 活动信息

| 事项 | 内容 |
| --- | --- |
| 初赛 | 5月10日15:00–17:00，E阶201 |
| 决赛 | 5月18日14:30–16:00，地点待定 |
| 参赛对象 | 全校学生，自由组队，每队最多3人 |
| 报名截止 | 5月9日18:00 |
| 报名方式 | 短信报名、提交纸质报名表，或通过 OA 附件报名 |
| 奖项 | 一至五等奖各1名，并给予相应奖励 |

报名表和具体赛制请前往 OA 系统查看原文附件。
