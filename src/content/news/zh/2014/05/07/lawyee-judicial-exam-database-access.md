据悉，汕头大学图书馆已为校内用户开通“北大法意—国家司法考试在线模考系统”。该平台面向司法考试备考人员，提供模拟考试、考试大纲、必备法规和司法文书四类内容，并支持不同模块之间切换使用。

学校获得500个在线账号，账号和密码范围为 stu001 至 stu500，访问地址为 http://sk.lawyee.org/Default.aspx。校内用户可按通知所示登录使用。

| 事项 | 内容 |
| --- | --- |

| 服务内容 | 模拟考试、考试大纲、必备法规、司法文书 |
| 账号数量 | 500个 |
| 账号范围 | stu001–stu500 |
| 访问地址 | http://sk.lawyee.org/Default.aspx |
| 开通单位 | 汕头大学图书馆 |
