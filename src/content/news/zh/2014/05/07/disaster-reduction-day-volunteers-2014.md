据悉，汕头市将于2014年5月12日围绕“城镇化与海洋减灾”开展应急管理与防灾减灾宣传活动，汕头大学理学院面向全校招募25至30名志愿者参加。活动时间为当天9:00至12:00，地点为汕头市人民广场。

有意参加者须在5月9日12:00前按通知要求向 dolphinmbi@sina.com 报名。活动旨在提升大学生防灾减灾意识，相关背景资料和报名要求以原通知为准。

## 活动信息

| 事项 | 内容 |
| --- | --- |
| 活动主题 | 城镇化与海洋减灾 |
| 活动时间 | 2014年5月12日9:00–12:00 |
| 活动地点 | 汕头市人民广场 |
| 招募人数 | 25至30名志愿者 |
| 报名截止 | 5月9日12:00 |
| 报名邮箱 | dolphinmbi@sina.com |

原通知中包含个人联系方式及报名所需身份信息，本文不转载；请前往 OA 系统查看原文。
