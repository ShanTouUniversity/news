据悉，汕头大学公布4月份学生宿舍水电费核对及缴费安排，本次抄表时间为4月30日，上次抄表时间为3月31日。学生可登录汕头大学水电费管理系统查询费用，如有疑问，应于5月7日至13日工作时间向水电中心提交核查申请。

核对期结束后，网络中心将于5月14日起通过一卡通扣缴本次费用，正常缴费时间为5月14日至19日；逾期未缴费的，将于5月20日按学校相关规定处理。学生应及时充值，避免一卡通余额不足。

## 时间安排

| 事项 | 时间 |
| --- | --- |
| 费用查询 | 登录 http://power.stu.edu.cn/ |
| 提交核查 | 5月7日至13日工作时间 |
| 一卡通扣缴开始 | 5月14日 |
| 正常缴费期 | 5月14日至19日 |
| 逾期处理 | 5月20日 |
| 水电中心 | 科技楼旁，电话86502489 |
| 网络中心 | 电话86503545 |

涉及宿舍信息核对的事项请联系辅导员办公室；具体费用数据和核查表请前往 OA 系统查看原文附件。
