至诚书院将于2014年7月中旬在潮州市铁铺西陇村开展暑期乡村“服务学习”公益课程，计划招募40名全校学生。项目已纳入学校公益课程管理，完成学习和考核后可获1学分；活动还将与来自香港科技大学、香港教育学院的近10名学生开展交流合作。

## 服务安排

| 项目 | 内容 |
| --- | --- |
| 服务时间 | 7月中旬，课程共7天，具体安排结合13级学生军训结束时间确定 |
| 服务地点 | 潮州市铁铺西陇村 |
| 招募人数 | 40名，通过面试择优录取 |
| 服务内容 | 为当地中小学生开展夏令营、社会调查及联欢活动 |
| 报名截止 | 5月30日17:00 |
| 报名邮箱 | ATP@stu.edu.cn |
| 面试时间 | 拟定6月4日下午 |

报名者须遵守公益课程规定，具备合作、沟通和服务意识，并按要求提交报名表。报名表附件请前往 OA 系统查看原文。
