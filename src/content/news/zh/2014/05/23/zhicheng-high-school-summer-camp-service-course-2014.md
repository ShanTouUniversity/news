至诚书院与法学院将联合开展“走进大学 启航人生”中学生夏令营公益课程，为潮汕地区高中生提供大学体验和成长培训。课程已纳入学校公益课程管理，学生完成学习和考核后可获1学分。

## 课程安排

| 项目 | 内容 |
| --- | --- |
| 招募人数 | 44名，分为24人和20人两个班 |
| 理论培训 | 6月29日至7月9日期间安排五个晚上 |
| 公益实践 | 第一班7月13日至16日；第二班7月17日至20日 |
| 服务对象 | 潮汕地区高中学生 |
| 报名截止 | 6月1日17:00 |
| 报名邮箱 | o_zhicheng@stu.edu.cn |

课程内容包括大学精神分享、团队拓展、研究性学习方法、项目策划执行、中国文化学习和领导力实践。报名者须下载并填写报名表，按要求在文件名中注明年级、专业和姓名后提交。报名表附件请前往 OA 系统查看原文。
