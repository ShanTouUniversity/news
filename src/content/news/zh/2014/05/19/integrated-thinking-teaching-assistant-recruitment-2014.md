据悉，汕头大学文学院整合思维项目面向下学年招聘小班导修课助教，欢迎对整合思维学习和教学有兴趣的汕大学生及毕业生应聘。

《汕大整合思维》自2011年秋季学期起面向本科一年级学生开设，采用大班讲授与小班导修相结合的教学方式。助教将参与小班讨论和活动，帮助学生训练思维技巧并培养良好思考习惯。

## 应聘信息

| 项目 | 内容 |
| --- | --- |
| 招聘对象 | 2014年秋季学期开始为本科三年级及以上的在读生或毕业生 |
| 基本要求 | 对课程有兴趣，善于表达、沟通和推理，能够适应团队协作 |
| 优先条件 | 学业成绩优秀、曾修读该课程并取得良好成绩，或有带领小班研讨课经验 |
| 报名截止 | 2014年5月28日 |
| 报名材料 | 个人简历、学业成绩资料及其他相关材料 |
| 联系邮箱 | `zhenghesiwei@126.com`，邮件主题注明“应聘汕大整合思维助教” |

项目团队将对报名材料进行初选，合格者另行通知面试。

> 来源：汕头大学 OA 通知（人事处）
