据悉，学生处学生创业中心于5月27日转发《关于组织申报全国大学生创业基金的通知》（教毕指〔2014〕29号），组织开展申报工作。

有意向的同学请于2014年6月30日前登录“全国大学生创业服务网”（cy.ncss.org.cn）提交申请，申请后请与学生处学生创业中心联系。

| 事项 | 内容 |
| --- | --- |
| 申报项目 | 全国大学生创业基金 |
| 申报平台 | 全国大学生创业服务网 cy.ncss.org.cn |
| 申报截止 | 2014年6月30日前 |
| 联系人 | 罗列 |
| 联系电话 | 86502255 |
| 联系邮箱 | luolie@stu.edu.cn |
| 发布单位 | 学生处学生创业中心、学生创业园管理办公室 |

申报详情见 OA 附件。
