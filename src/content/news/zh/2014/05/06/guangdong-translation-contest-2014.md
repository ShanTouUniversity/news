据悉，共青团汕头大学委员会于5月6日转发团省委通知，第八届广东大中专学生科技学术节之第五届广东大学生翻译大赛将举行。

为促进翻译教育与翻译水平提升，培养具有良好翻译基础的青年人才，团省委、省教育厅、省科技厅、省科协、省学联将联合举办本届大赛。

## 赛事安排

| 事项 | 内容 |
| --- | --- |
| 赛事名称 | 第八届广东大中专学生科技学术节之第五届广东大学生翻译大赛 |
| 语种 | 英语、日语（每人限报一种） |
| 形式 | 口译、笔译 |
| 校内报名截止 | 2014年5月15日 |
| 报名方式 | 填写《报名表》（见 OA 附件）发送至校团委邮箱 o_tw@stu.edu.cn |
| 选拔方式 | 校团委择优推荐参赛 |
| 发布单位 | 共青团汕头大学委员会 |

详情及报名表见 OA 附件。

> ⚠️ 报名表及赛事通知请前往 OA 系统查看原文附件。
>
> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
