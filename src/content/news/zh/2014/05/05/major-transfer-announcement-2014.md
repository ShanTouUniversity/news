据悉，教务处于5月5日发布公示，根据《汕头大学本科学生学籍管理规定》（汕大发〔2013〕67号），各专业已对申请转专业的学生完成考核并提出初步名单，经教务处审核，现将拟批准转专业的学生名单予以公示。

## 公示安排

| 事项 | 内容 |
| --- | --- |
| 公示依据 | 《汕头大学本科学生学籍管理规定》（汕大发〔2013〕67号） |
| 公示内容 | 拟批准转专业的学生名单（名单见 OA 原文，已作隐私保护不在此转载） |
| 公示期 | 至2014年5月12日 |
| 受理方式 | 书面形式或来人、来电向教务处反映，需签署真实姓名 |
| 联系电话 | 86502402 |
| 联系邮箱 | o_jwc@stu.edu.cn |
| 发布单位 | 教务处 |
