汕头大学艺术教育中心《小号演奏》（班号67044）和《圆号演奏》（班号67049）课程调整安排显示，两门课原定 **5月6日** 的课程停课，改于 **5月10日** 在艺术教育中心STU204室补课。

| 课程 | 停课时间 | 补课时间 |
| ---- | ---- | ---- |
| 小号演奏（67044） | 5月6日第6至7节 | 5月10日第6至7节 |
| 圆号演奏（67049） | 5月6日第8至9节 | 5月10日第8至9节 |

> 来源：汕头大学 OA 通知（教务处）
