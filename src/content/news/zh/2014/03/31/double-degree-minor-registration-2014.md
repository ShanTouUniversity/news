据悉，为培养复合型人才、给在校本科生提供跨学科跨专业学习机会，汕头大学教务处已启动2013—2014学年本科生修读双学位和辅修专业的报名登记工作。此次报名依据《汕头大学关于本科生修读双学位和辅修专业的实施办法》（汕大发[2007]78号）执行。

## 报名要点

| 事项 | 说明 |
| ---- | ---- |
| 报读资格 | 校本部有学籍的在读本科生 |
| 免费政策 | 2013级学生修读英语、工商管理专业双学位和辅修专业免费，按《汕头大学本科生免费修读双学位和辅修专业的实施细则》（汕大教字〔2013〕11号）执行，单独开班，可能在周末、假期或晚上上课 |
| 其他专业 | 接收人数及报名条件见《各专业可以接收的双学位、辅修学生数及报名条件》，跟主修专业学生一起上课、不单独开班，需注意与主修课程时间是否冲突 |
| 课程计划 | 见《学业指南》（商学院课程计划另见附件），疑问可咨询开设学院教务员 |

## 流程安排

有意报读的学生需填写《汕头大学本科生双学位和辅修专业登记表》，先到主修专业学院请教务员核实学业情况，再于4月11日前将登记表送至双学位或辅修专业所在学院的教务员处。各接收学院教务员须在4月18日前将最终确定接收的学生名单汇总报教务处备案。
