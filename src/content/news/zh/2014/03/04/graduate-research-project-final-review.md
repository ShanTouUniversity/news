据悉，根据学校关于研究生开展课外学术科技立项的通知和立项研发控制进度表的要求，汕头大学研究生学院将于近期对2013年立项的项目组织终期评审。

## 提交要求

| 事项 | 说明 |
| ---- | ---- |
| 提交对象 | 所有获得立项的项目负责人 |
| 截止时间 | 2014年3月7日前 |
| 提交材料 | 书面结项报告书（含指导教师评价和签名）及立项作品 |
| 作品形式 | 已发表的研究论文、创业计划、专利、已建立的模型、调查报告、建议书等项目成果或即将取得的成果 |
| 提交地点 | 新行政中心401室研究生学院王风奇老师处，并发送电子版至 fengqiwang@stu.edu.cn |

值得注意的是，未按规定提交结项报告书的项目将被视为自动放弃，相关项目追加经费需予以收回。
