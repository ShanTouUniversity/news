据悉，文学院于3月28日发布通知，启动汕头大学—加拿大麦吉尔大学学期交流项目，将选拔2名文学院本科生于2014年秋季学期赴加进行为期一学期的学习交流，相关费用由李嘉诚基金会提供奖学金支持。

## 项目概况

| 事项 | 内容 |
| --- | --- |
| 项目 | 汕头大学—麦吉尔大学学期交流项目 |
| 选拔人数 | 2名 |
| 派出学期 | 2014年秋季学期，为期一学期 |
| 奖学金 | 最高22189加元（含学费8929、生活费5410、住宿费4750、机票3100加元） |
| 自理费用 | 出国保险等其他费用 |
| 主办单位 | 文学院 |

## 选拔标准

面向文学院2011、2012、2013级本科生，要求英语听、说、读、写能力较强，雅思6.5（单项不低于6.0）或托福90（单项不低于21），总GPA班级排名前30%，品学兼优、性格成熟开朗、善于沟通，同等条件下未参加过校院国际交流项目的同学优先，并需善于对外宣传汕头大学。

## 报名安排

| 事项 | 内容 |
| --- | --- |
| 报名平台 | 汕头大学学生事务系统 https://sao.stu.edu.cn，2014年4月8日至11日开放 |
| 报名材料 | 网上申请表打印件、在校成绩单、雅思/托福成绩单、英语作文，电子版与纸质版各一份 |
| 报名截止 | 2014年4月11日12:00前 |
| 提交方式 | 电子版打包发送至 myzheng@stu.edu.cn（主题为“学生姓名--麦吉尔学期交流项目”），纸质版送至文南212文学院办公室 |
| 选拔方式 | 材料初审后于4月18日前组织面试 |
| 联系人 | 郑漫瑶老师，文南212，电话 86503343/652023，邮箱 myzheng@stu.edu.cn |
