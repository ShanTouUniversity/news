据悉，2013年度民政部社会工作与志愿服务课题的申报工作已经启动，汕头大学科研处日前向学校各有关单位转发了申报要求，并组织校内研究人员参与申报。本批课题面向直接从事相关工作的研究者，要求申请人具备承担重大课题研究的相应基础。

## 申报条件

根据申报安排，申请人需依据《民政部2013年度社会工作与志愿服务课题研究指南》所列的研究任务选择课题；往年承担过民政部社会工作和志愿服务方面课题但尚未结题的专家，此次不能作为课题主要负责人申报。此外，高校、研究机构与地方民政部门、实务机构联合申报将受到鼓励。

## 研究期限与成果要求

| 事项 | 要求 |
| --- | --- |
| 完成时间 | 2013年8月20日前完成并提交成果报告 |
| 成果归属 | 由民政部社会工作司和作者共同所有，未经同意不得公开发表 |
| 研究方法 | 定量与定性方法综合运用 |
| 报告篇幅 | 一般不少于3万字（不含附件或辅助研究资料） |
| 政策建议 | 占全文1/5以上 |
| 经费支持 | 一般不超过3万元 |

中标课题将由民政部社会工作司与中标单位签订《民政部科研任务书》，并给予一定研究经费支持；未完成研究任务或成果验收不合格的课题，将不予结题。

## 校内时间安排

按照科研处的要求，申请人须先填写《民政部招标课题申请书》和《研究论证活页》，并于3月15日前将初稿交至科研处进行形式审查，3月20日前再提交一式4份的合格材料及电子版。校内联系人黄玉梅可通过电话 86502563 或 82902563 咨询相关事宜。
