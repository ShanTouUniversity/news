据悉，英语语言中心于11月18日发布通知，2013年度英语节辩论赛初选将于11月23日在 CILL（语言自习中心，图书馆一层）举行。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 活动名称 | 2013年度英语节辩论赛初选 |
| 报名截止 | 2013年11月19日24:00 |
| 初选时间 | 2013年11月23日（星期六） |
| 初选地点 | CILL（语言自习中心，图书馆一层） |
| 参赛对象 | 全校本科生，可两人组队报名（推荐）或单独报名 |
| 赛制 | 英国议会赛制（British Parliamentary Format），每场4支队伍同台竞技，每队2名辩手 |
| 赛前准备 | 赛前20分钟抽签定辩位，赛前15分钟公布辩题，每位辩手发言7分钟 |
| 评选 | 评委对每场8名辩手分别打分，决出最佳辩手与获胜队伍 |
| 后续安排 | 入选选手将参加决赛积分赛，并有机会参与 English Debate Society 系列赛前工作坊 |
| 报名方式 | 下载附件报名表填妥后发送至指定邮箱 |
| 主办单位 | 英语语言中心 |

比赛为英国议会赛制，正反双方分为 Opening Government、Closing Government、Opening Opposition、Closing Opposition 四方。详细规则见 OA 附件。入选选手将与其他学校选手竞技。报名及咨询邮箱见 OA 附件，已作隐私保护不在此转载。
