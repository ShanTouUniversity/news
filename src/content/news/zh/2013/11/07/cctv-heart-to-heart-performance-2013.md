据悉，中央电视台“心连心”艺术团慰问演出的预约活动已经截止，汕头大学学生处于11月7日公布预约成功名单，共50名同学入选。演出将于11月8日（星期五）下午3:00在汕头市华侨公园举行。

## 预约结果

| 事项 | 安排 |
| --- | --- |
| 演出名称 | 中央电视台“心连心”艺术团慰问演出 |
| 预约结果 | 50名同学预约成功，名单见附件 |
| 演出时间 | 2013年11月8日（星期五）15:00 |
| 演出地点 | 汕头市华侨公园 |
| 发布单位 | 学生处 |
| 发布时间 | 2013年11月7日 |

## 集合与入场注意事项

| 事项 | 安排 |
| --- | --- |
| 上车时间 | 11月8日（星期五）13:45 |
| 上车地点 | 校训碑前空地 |
| 着装要求 | 着装整洁，准时上车 |
| 随身物品 | 尽可能不要随身携带公文包、挂包、金属类物品，确保快捷进场 |
| 禁止携带 | 雨伞、饮料、食物及宣传品等 |

学生处提醒，预约成功的同学请按要求准时集合、有序入场。

> ⚠️ 预约成功50人名单请前往 OA 系统查看附件原文。
>
> 来源：汕头大学 OA 通知（学生处）
