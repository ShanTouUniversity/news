据悉，汕头大学国际交流合作处已启动美国惠特曼学院（Whitman College）2014年秋季学期交换生项目选拔工作，本次选拔名额为1名，将于2014年秋季赴惠特曼学院进行为期半年的交换生学习。

选拔范围为本校本部2011级全日制本科生，要求2012-2013学年GPA排名前5%，英语水平达到Level 4。选拔标准包括积极参加校内外活动、具有领导能力、较强的分析理解能力、良好的英语听读写能力等。

申请者需提交申请表及一篇300-500字的英语文章（题目二选一）。欢迎符合条件有意向的同学积极报名。

## 项目信息

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 美国惠特曼学院交换生项目 |
| 选拔名额 | 1名 |
| 学习时间 | 2014年秋季学期（半年） |
| 选拔范围 | 校本部2011级全日制本科生 |
| GPA要求 | 2012-2013学年排名前5% |
| 英语水平 | Level 4 |
| 申请材料 | 申请表 + 300-500字英语文章（题目二选一） |
| 主办单位 | 国际交流合作处 |

> 来源：汕头大学 OA 通知（国际交流合作处）
