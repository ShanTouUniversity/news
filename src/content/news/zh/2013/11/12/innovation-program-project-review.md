据悉，汕头大学教务处将对**2012年度立项、项目开展时间为一年半**的大学生创新创业训练计划项目组织检查，检查采取提交书面材料与公开答辩相结合的方式进行。

按照安排，各项目组须于**2013年12月6日**前将书面材料（一式三份）交至新行政中心三楼教务处事务窗口，同时将与纸质版一致的电子版发送至 yjguo@stu.edu.cn。电子版材料命名格式为“院系名称-项目编号-负责人姓名”，例如“文学院-1056011001-张三”。

公开答辩定于**2013年12月18日**举行，具体时间、地点及分组名单将另行通知。

关键安排一览：

| 事项 | 安排 |
| ---- | ---- |
| 检查范围 | 2012年度立项、开展期一年半的大创项目 |
| 材料形式 | 书面材料 + 公开答辩 |
| 材料提交 | 2013年12月6日前，一式三份 |
| 提交地点 | 新行政中心三楼教务处事务窗口 |
| 电子版 | 发送指定邮箱，按“院系-编号-负责人”命名 |
| 公开答辩 | 2013年12月18日 |

> 来源：汕头大学 OA 通知（教务处）
> ⚠️ 项目检查相关表格及附件请前往 OA 系统查看原文。
