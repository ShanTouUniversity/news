据悉，汕头大学青年志愿者协会"绿丝带"服务学习环保义工队与科学技术协会科普团联合举办第五期"绿芽行动"环保课堂，面向全校招募志愿者。

## 活动背景

"绿芽行动"环保课堂旨在让小学生从小树立正确的环保理念，并在日常生活中注重环保细节，传承"奉献、友爱、互助、进步"的志愿者精神。

## 招募信息

| 事项 | 内容 |
| --- | --- |
| 活动名称 | 第五期"绿芽行动"环保课堂 |
| 主办单位 | "绿丝带"服务学习环保义工队、科协科普团 |
| 招募对象 | 全校学生 |
| 招募人数 | 若干志愿者 |
| 精神理念 | 奉献、友爱、互助、进步 |

有意参加的同学可向所在学院青年志愿者协会或相关组织报名。

> 来源：汕头大学 OA 通知（校团委）
