据悉，校工会于11月28日发布通知，汕头大学第五届教职工代表大会暨第七届工会会员代表大会第三次会议定于12月4日召开。

## 会议安排

| 事项 | 内容 |
| --- | --- |
| 时间 | 2013年12月4日14:30—17:30，请代表提前15分钟签到 |
| 地点 | 科学院报告厅 |
| 内容 | 会议内容及日程安排详见 OA 附件 |
| 代表团名单 | 详见 OA 附件 |
| 座位安排 | 第一排中间为校领导及特邀代表，第二排中间为列席代表，第三至十一排中间为正式代表 |
| 参会要求 | 代表所在单位不得安排代表在会议期间出差或参加冲突活动，特殊情况需向团长或工会主席请假；各代表团需于12月2日12:00前统计出席及列席人数报校工会 |
| 联系方式 | 校工会，电话 82902983、86502983，邮箱 o_xgh@stu.edu.cn |
| 发布单位 | 工会 |

> ⚠️ 会议日程及代表团名单请前往 OA 系统查看原文附件。
>
> 来源：汕头大学 OA 通知（工会）
