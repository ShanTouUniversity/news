据悉，汕头大学工会定于11月22日下午组织校教工足球队与驻汕某部队足球队进行友谊赛，以促进校军交流、增进双方情谊。

## 比赛安排

| 事项 | 内容 |
|------|------|
| 比赛性质 | 友谊赛 |
| 对阵双方 | 汕头大学教工足球队 vs 驻汕某部队足球队 |
| 比赛时间 | 2013年11月22日下午 |
| 比赛地点 | 驻汕某部队足球场 |
| 上车时间 | 11月22日下午4:00 |
| 上车地点 | 校训碑前 |
| 联系人 | 罗英光 |
| 联系电话 | 86503271、693448（短号） |

请参加比赛的教职工足球队员于11月22日下午4:00在校训碑前集合乘车前往赛场。欢迎全校师生到场观战，为校教工足球队加油助威。

> 来源：汕头大学 OA 通知（工会）
