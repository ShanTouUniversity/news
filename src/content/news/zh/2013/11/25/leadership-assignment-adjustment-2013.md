据悉，汕头大学及中共汕头大学委员会于11月25日联合发布文件（汕大发〔2013〕135号），因工作需要调整部分校领导、校长助理工作分工。

## 调整后分工

| 领导 | 分工 |
| --- | --- |
| 徐小虎 校长 | 主持学校全面工作 |
| 宋*臻 书记（原通知一字显示异常） | 主持党委全面工作，协助管理学校全面工作，分管宣传、统战 |
| 顾佩华 执行校长 | 协助校长管理行政全面工作，分管人事、财务及广东以色列理工学院筹建 |
| 罗念潮 副书记 | 分管组织、思想政治教育、学生就业、工会、纪检、监察及审计，分管社科部思政教育 |
| 温小波 副校长 | 分管科研、教学、招生、艺术教育、社科部教学及通识教育、中心实验室、学报及校办产业 |
| 李丹 副校长 | 分管学生培养、住宿学院、体育部、篮球队 |
| 林丹明 副校长 | 协助日常行政及以色列理工学院筹建，分管党政办、外事、资源、保卫、网络与信息 |
| 乌兰哈斯 副校长 | 分管学科建设、“211工程”、研究生、继续教育、图书馆 |
| 黄东阳 校长助理 | 协助联系医学院工作，负责医学院迁入校本部整合协调 |
| 徐宗玲 校长助理 | 分管校友工作 |
| 陈少刚 校长助理 | 协助开展资源管理 |

> 来源：汕头大学 OA 通知（汕头大学、中共汕头大学委员会）
