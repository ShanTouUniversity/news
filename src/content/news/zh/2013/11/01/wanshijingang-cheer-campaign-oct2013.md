据悉，汕头大学体育部于11月1日发布助威号召，提醒即将于11月2日晚7:30在汕头大学体育馆举行的"万变金刚"队与湖南师范大学男篮友谊赛，到场观赛的师生请注意着装。

体育部表示，橙色与黑色是万变金刚队标志的主色调，号召观众身着带有这两种颜色元素的服饰到场，共同营造热烈的主场氛围。本次助威活动与10月30日已发布的赛事预告相呼应。

## 比赛与助威信息

| 事项 | 内容 |
| --- | --- |
| 对阵双方 | 汕头大学万变金刚队 vs 湖南师范大学男篮 |
| 比赛时间 | 2013年11月2日（周六）19:30 |
| 比赛地点 | 汕头大学体育馆 |
| 入场费 | 免费 |
| 入场时间 | 19:00开始有序进场 |
| 助威主题 | 身着橙色或黑色元素服饰，营造主场氛围 |
| 啦啦队席 | 40人临时席位，先到先得 |
| 提前就坐 | 有意参与近距离助威的观众请于18:45前到席 |
| 中场表演 | 排舞俱乐部献技 |
| 发布单位 | 体育部 |
| 发布日期 | 2013年11月1日 |

啦啦队席数量有限，有意近距离体验比赛氛围的观众需提前就坐，工作人员将就座前进行简单培训，确保助威效果。

> 来源：汕头大学 OA 通知（体育部）
