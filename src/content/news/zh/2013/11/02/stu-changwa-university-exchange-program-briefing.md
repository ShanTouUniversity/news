据悉，汕头大学国际交流合作处将举办赴台湾中国文化大学交换生项目介绍会，为学生了解该交流项目提供咨询渠道。

该项目安排学生于2014年2月至6月赴台湾中国文化大学进行为期一学期的研习交流。报名面向在校二、三年级学生（医学专业除外），要求成绩良好、一年内无不及格科目，热爱祖国、遵纪守法，且未受过学校通报及以上处分。

学生在学习期间所修课程，学校予以承认，返校后可进行学分转换。学习相关费用，包括学费、住宿费、生活费及往返旅费等，均由学生自行承担。

有意申请的同学请于11月15日前向所在学院教务室递交申请材料，逾期不予受理。

| 项目 | 内容 |
|------|------|
| 合作院校 | 台湾中国文化大学 |
| 研习时间 | 2014年2月至6月 |
| 报名范围 | 在校二、三年级学生（医学专业除外） |
| 申请条件 | 成绩良好，一年内无不及格科目，无通报及以上处分 |
| 费用承担 | 学费、住宿、生活及旅费由学生自理 |
| 申请截止 | 2013年11月15日前 |
| 学分认定 | 返校后办理学分转换 |

> 来源：汕头大学 OA 通知（国际交流合作处）
