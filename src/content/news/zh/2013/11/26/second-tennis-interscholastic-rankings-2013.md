据悉，汕头大学体育部于11月26日宣布，第二届网球积分赛将于12月11日至15日在校园网球场举行。比赛设有男子单打和女子单打两个项目，以个人名义报名参加。

本次比赛采用单盘淘汰制，比赛日程安排为每周三、周六、周日。有意向的师生须在12月10日前完成报名。

## 比赛信息

| 事项 | 内容 |
| --- | --- |
| 赛事名称 | 汕头大学第二届网球积分赛 |
| 比赛时间 | 2013年12月11日—15日（每周三、六、日） |
| 比赛地点 | 汕头大学网球场 |
| 比赛项目 | 男子单打、女子单打 |
| 赛制 | 单盘淘汰制 |
| 报名方式 | 以个人名义报名 |
| 报名截止 | 2013年12月10日 |
| 主办单位 | 汕头大学体育部 |
| 发布日期 | 2013年11月26日 |

> 来源：汕头大学 OA 通知（体育部）
