据悉，共青团汕头大学委员会于11月26日公布"加强学风建设，更好成长成才"特色团日活动立项结果。本次活动旨在加强校园学风建设，促进大学生更好地成长成才。经过评审，共13个项目获得立项批准，其中10个项目获得经费资助。

## 立项结果

| 类别 | 数量 |
| --- | ---: |
| 获准立项项目 | 13个 |
| 获得经费资助项目 | 10个 |

## 活动信息

| 事项 | 内容 |
| --- | --- |
| 活动主题 | 加强学风建设，更好成长成才 |
| 活动类型 | 特色团日活动 |
| 立项项目数 | 13个 |
| 经费资助项目数 | 10个 |
| 发布单位 | 共青团汕头大学委员会 |
| 发布日期 | 2013年11月26日 |

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
