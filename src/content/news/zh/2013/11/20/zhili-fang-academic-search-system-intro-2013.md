据悉，汕头大学图书馆近日向全校师生推介智立方系统，旨在帮助师生更高效地获取和利用学术资源。

智立方系统整合了多种类型的文献资源，提供一站式检索和全文保障服务。具体资源类型包括：

| 资源类型 | 说明 |
| --- | --- |
| 中外文期刊 | 涵盖国内外学术期刊全文及索引 |
| 学位论文 | 国内外硕博士学位论文全文 |
| 会议论文 | 重要学术会议论文汇编 |
| 专利 | 国内外专利信息检索 |
| 专著 | 中外文学术专著 |
| 标准 | 国内外技术标准与规范 |
| 科技成果 | 科技报告与成果转化信息 |
| 产品样本 | 工业产品样本与技术资料 |
| 科技报告 | 各国科技研究报告 |
| 政策法规 | 相关法律法规与政策文件 |

图书馆提醒，师生可通过校园网访问智立方系统，利用其强大的检索功能快速定位所需文献资源，提升科研效率。

> 来源：汕头大学 OA 通知（图书馆）
