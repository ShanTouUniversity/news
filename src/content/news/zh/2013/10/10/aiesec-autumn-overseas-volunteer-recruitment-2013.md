据悉，汕头大学AIESEC（埃塞克）于10月10日发布通知，面向全校学生启动2013年秋季海外志愿者项目招新，报名截止时间为2013年10月23日。

## 关于 AIESEC

AIESEC（埃塞克）是一个由高校或更高学术机构的在校学生和新近毕业生运营的全球性、非政治性、独立、非盈利组织，目前遍布全球5大洲、124个国家和地区，是世界上最大的学生团体，拥有80000名以上成员，分布超过2400所大学。其全球总部设在荷兰鹿特丹，在各大区分别设有总会。

海外志愿者计划是AIESEC主要运营的项目之一，围绕文化传播、HIV防治、社区或乡村发展、环境保护、语言教育、小额信贷、妇女权益等众多社会议题进行。志愿者在参与项目的同时，可体验当地生活与文化，与当地AIESEC成员共同讨论项目的发展与运行，拓展社交圈并得到历练。

## 招新对象

本次招新面向全校学生，不限专业和年级。

## 招新系列活动

| 活动 | 时间与地点 | 内容 |
| ---- | ---------- | ---- |
| 活动一：Global Night | 10月13日（星期日）20:00—22:00，9号楼EAC | 介绍海外志愿者项目与AIESEC文化 |
| 活动二：金三角路演 | 10月16日11:30—14:00，金三角 | 海外志愿者招新咨询 |
| 活动三：招新面试 | 第二轮、第三轮的时间及地点在简历筛选通过之后以短信通知 | 第一轮简历筛选 → 第二轮小组面试 → 第三轮个人面试 |

## 报名方式

报名者可选择以下任一方式：

| 方式 | 说明 |
| ---- | ---- |
| 现场报名（Global Night） | 在Global Night大型活动中领取报名表现场报名 |
| 现场报名（金三角） | 10月16日11:30—14:00在金三角AIESEC摆摊处领取报名表现场报名 |
| 邮箱报名 | 发送中英文简历，或将填写好的报名表（见附件）发送至 aiesec.volunteer.stu@gmail.com |

此外，宿舍区及第二、第四食堂海报处设有报名表回收点，详情见 OA 原文。如有疑问，可联系 AIESEC 工作人员（联系方式见 OA 原文）。
