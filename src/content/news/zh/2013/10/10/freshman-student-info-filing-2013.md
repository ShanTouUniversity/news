据悉，为保证学生学籍信息的准确性，规范教学管理、学生奖助学金评定等工作，提供更加准确、快捷、高效的服务，汕头大学教务处、学生处于10月10日发布通知，将对2013级本科生的学籍信息进行审核。2013级本科生须于即日起至2013年11月10日登录学生事务系统完成信息填报。

## 填报安排

| 事项 | 内容 |
| ---- | ---- |
| 填报对象 | 2013级本科生 |
| 填报时间 | 即日起至2013年11月10日 |
| 填报系统 | 学生事务系统 http://sao.stu.edu.cn |
| 须填写内容 | 基本信息、学习经历、家庭主要成员、主要社会关系、奖惩情况等 |
| 关键信息核对 | 姓名、性别、出生日期、身份证号码（在"我的信息"菜单中核对） |
| 咨询渠道 | 教务处学务科 86502623；学生处教育管理科 86503398、lslin@stu.edu.cn |

## 填报流程

学生登录学生事务系统 http://sao.stu.edu.cn 后，进入"我的事务"菜单的"填写学籍信息"页面，按照提示填报基本信息、学习经历、家庭主要成员、主要社会关系、奖惩情况等内容，确认无误后提交并打印《汕头大学学生学籍卡》。由于打印需要安装组件，建议使用IE浏览器或浏览器的兼容模式。打印后须用黑色钢笔签名，由班干部收集后以专业班级为单位交到学院教务室存档。

## 关键信息核对

学生可在"我的信息"菜单中核对学籍关键信息中的姓名、性别、出生日期、身份证号码。如发现信息有误，请联系教务处学务科（行政中心三楼教务处学务科，联系电话86502623）咨询信息更改手续。关于学生政治面貌，到学生四年级时教务处将根据校团委、组织统战部等单位提供的数据统一修改，故政治面貌有误的无需致电教务处。

## 其他事项

按照上级教育管理部门规定，高等学校必须严格依照招生录取数据所包含的信息和注册程序要求，对在校学生进行注册和学籍管理，未经报批学校不得擅自更改招生考试录取时已经确定的学生基本信息（包括姓名、性别、出生年月等）；申请经报批未获批准者，维持原招生录取信息不变。

在信息核对、补登过程中若有问题，可致电或发邮件咨询学生处教育管理科（86503398，lslin@stu.edu.cn）。各学院（书院）辅导员可登录学生事务系统，进入"信息查询"中的"学生信息列表"，查看所在学院（书院）学生提交学籍信息的具体情况，督促未按时填报的学生及时完成填报工作。
