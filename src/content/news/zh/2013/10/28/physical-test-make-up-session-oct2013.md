据悉，汕头大学体育部于10月28日发布通知，将于10月30日下午进行体质测试补测。学校体质测试工作已于10月26日测试完毕，大部分同学已准时按要求完成测试，部分同学因各种原因未参加或漏测。为确保不影响个人前途及学校声誉，体育部安排了本次补测。

补测项目及地点如下：坐位体前屈位于田径场看台下体质测试室，50米跑在田径场内，立定跳远在田径场跑道终点处，男生引体向上在田径场外小足球场边，女生1分钟仰卧起坐在田径场主席台下，男生1000米及女生800米在田径场内。

| 项目 | 地点 |
|------|------|
| 坐位体前屈 | 田径场看台下体质测试室 |
| 50米跑 | 田径场内 |
| 立定跳远 | 田径场跑道终点处 |
| 男生引体向上 | 田径场外小足球场边 |
| 女生1分钟仰卧起坐 | 田径场主席台下 |
| 男生1000米 / 女生800米 | 田径场内 |

> 来源：汕头大学 OA 通知（体育部）
