据悉，粤嵌股份旗下的粤嵌教育将于10月19日（星期六）下午 14:30—17:00 在 E 座 303 举办嵌入式技术体验活动。本次活动由资深 Linux 开发技术专家、高级工程师邓人铭老师主讲，面向数学与应用数学、应用物理、计算机科学与技术、电子信息工程、通信工程等有 C 语言或电子相关基础的学生开放。

邓人铭老师拥有 8 年嵌入式开发经验，从事 Linux 开发技术研究与教学多年。活动内容涵盖粤嵌公司介绍、嵌入式系统概述、产品开发流程、基于 Cortex-A8 的 S5Pv210 平台 GAME BOX 案例分析、嵌入式行业现状及前景，以及互动交流等环节。

| 项目 | 内容 |
|------|------|
| 主题 | 嵌入式技术体验（基于 Cortex-A8 的 S5Pv210 平台 GAME BOX 案例分析） |
| 时间 | 10月19日（星期六）14:30—17:00 |
| 地点 | E座303 |
| 主讲人 | 邓人铭（高级工程师，资深Linux开发技术专家） |
| 参与对象 | 数学与应用数学、应用物理、计算机科学与技术、电子信息工程、通信工程等相关专业学生 |

主办方表示，欢迎同学们踊跃参加。

> 来源：汕头大学 OA 通知（理学院）
