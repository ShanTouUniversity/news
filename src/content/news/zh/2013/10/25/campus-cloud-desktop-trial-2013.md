据悉，汕头大学网络与信息中心已完成校园网云桌面应用系统一期部署，系统面向全校师生员工开放试用。该系统基于服务器虚拟化技术，提供虚拟云桌面、虚拟应用及个人数据存储服务，个人数据存储空间为50GB。

## 系统服务

用户可在申请时选择专用桌面、静态桌面或动态桌面三类服务，并从中文 Windows 7、英文 Windows 7、中文 Windows XP 和英文 Windows XP 四种桌面操作系统中选择一种。由于现阶段硬件资源有限，每位用户只能申请一个虚拟桌面。

## 申请与分配

| 事项 | 内容 |
| --- | --- |
| 试用对象 | 全校师生员工 |
| 申请方式 | 使用校园网账号和密码登录 [cloud.stu.edu.cn](http://cloud.stu.edu.cn) 自助在线申请 |
| 操作指南 | 访问 [cloud.stu.edu.cn/help.aspx](http://cloud.stu.edu.cn/help.aspx) |
| 系统建设单位 | 网络与信息中心 |

在审批和资源分配方面，系统优先满足教学科研一线教师用于课堂教学和备课的需求。多媒体教室授课的外籍教师列为第一优先，原则上分配静态桌面；在多媒体教室授课的校内教师列为第二优先，优先分配静态桌面，静态桌面不足时分配动态桌面。其他用户一般按照申请先后顺序审批并分配动态虚拟桌面。静态桌面和专用桌面的申请将依据上述分配原则进行审批。

> 来源：汕头大学 OA 通知（网络与信息中心）
