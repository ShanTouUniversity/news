据悉，汕头大学至诚书院于10月31日公布第六期"心理拓展训练营"录取名单。本期训练营共收到21份报名，全部予以录取，训练营定于11月2日上午8:30在至诚书院J-354举行。

本期训练营以"和谐心灵，健康你我"为主题，旨在通过拓展活动促进同学之间的交流与心理健康。获录取学员需穿着运动休闲装准时参加。

## 录取信息

| 项目 | 内容 |
| --- | --- |
| 训练营名称 | 至诚书院第六期心理拓展训练营 |
| 报名时间 | 截至10月30日14:00 |
| 报名人数 | 21人 |
| 录取人数 | 21人（全部录取） |
| 活动时间 | 2013年11月2日 8:30 |
| 活动地点 | 至诚书院 J-354 |
| 着装要求 | 运动休闲装 |
| 发布单位 | 至诚书院 |
| 发布日期 | 2013年10月31日 |

本期训练营共设24个名额，其中至诚书院宿生18名，其他宿区宿生6名。由于报名人数未超限额，所有报名者均获录取。此前招募通知已于10月25日发布。

> 来源：汕头大学 OA 通知（至诚书院）
