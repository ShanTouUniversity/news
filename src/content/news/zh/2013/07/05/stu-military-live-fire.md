据悉，经汕头大学与协训部队协商，学校定于7月6日组织本年度军训学生开展实弹射击活动。根据安排，凡参加军训的2012级学生原则上均须参加此次实弹射击——军训课为必修课程，实弹射击是其中重要环节。

## 分时段乘车安排

为保证活动安全有序，学校将统一安排车辆接送学生前往靶场。乘车地点设在校训碑前，各单位按以下时间依次出发：

| 出发时间 | 单位 |
| -------- | ---- |
| 7:30 | 工学院 |
| 8:10 | 文学院 |
| 8:40 | 理学院 |
| 9:10 | 法学院 |
| 9:40 | 商学院 |
| 14:30 | 新闻学院 |
| 15:00 | 至诚书院 |
| 15:30 | 艺术学院 |

学生按学院顺序上车，尚未轮到的单位在原地等候。

## 安全与纪律要求

报道称，参加实弹射击的学生须统一穿着军训服装进入靶场，并严格按照时间安排到指定地点集合候车。进入打靶场后，学生须服从教官指挥。此外，各学（书）院均安排辅导员随队协助组织工作，以保障训练安全。

> 来源：汕头大学 OA 通知（人民武装部）
