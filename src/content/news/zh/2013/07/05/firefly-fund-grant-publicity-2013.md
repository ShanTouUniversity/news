据悉，共青团汕头大学委员会、青年志愿者协会与“萤火虫”爱心基金会于7月5日联合发布消息，对“学海萤光”助学金拟资助名单进行公示。

“学海萤光”助学金由青年志愿者“萤火虫”爱心基金会设立。本次评选共收到20份申请，经理事会审核，拟资助其中17名同学，具体拟资助对象见公示名单。

| 公示事项 | 内容 |
| --- | --- |
| 资助项目 | “学海萤光”助学金 |
| 设立单位 | 青年志愿者“萤火虫”爱心基金会 |
| 申请数量 | 20份 |
| 拟资助人数 | 17人 |
| 异议截止 | 7月10日17时 |
| 反映方式 | 书面或来电反映；单位材料需加盖公章，个人材料需签署真实姓名 |
| 基金会邮箱 | fireflyfundofstu@163.com |
| 发布单位 | 共青团汕头大学委员会、青年志愿者协会、“萤火虫”爱心基金会 |
| 落款日期 | 2013年7月5日 |

公示期间，对拟资助结果有异议者，可在7月10日17时前以书面或来电方式反映。受助名单等详细信息以 OA 原文附件为准，本文不转载具体名单。
