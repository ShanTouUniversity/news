据悉，为培养和提升学生的领袖才能，汕头大学与宁波诺丁汉大学合作开展的第三期领袖生交换计划选拔结果于2013年7月揭晓。自6月21日发布选拔通知后，经各单位推荐共有19位学生入围面试，最终黄PS、陈ST等10位同学脱颖而出，入选本次交换计划。

## 入选名单

| 推荐单位 | 入选学生（年级·专业） |
| --- | --- |
| 校学生会 | 黄PS（11级行政管理）、陈ST（11级会计学） |
| 汕大青年 | 杨ZY（12级新闻学） |
| 学生社团联合会（含社团） | 郑YN（11级英语） |
| 至诚书院 | 钟JT（11级法学） |
| 商学院 | 容ZH（11级会计学）、肖HM（11级会计学） |
| 工学院 | 张Y（10级土木工程） |
| 法学院 | 郭Y（11级法学） |
| FLY培训项目 | 俞SQ（11级计算机） |

据主办方介绍，入选同学需做好相关准备工作，并与项目工作人员保持联系，为赴宁波诺丁汉大学的交流做好准备。

该计划是汕大与宁波诺丁汉大学在学生领袖培养方面的合作项目，旨在通过两校学生的双向交流，提升学生的组织能力与国际视野。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会、学生处）
