据悉，人事处于7月9日发布公示，公布学校拟向汕头市推荐的2013年优秀教师和优秀教育工作者候选人名单。

此次推荐依据汕市教[2013]42号文件开展。此前，学校已于7月2日启动校内推荐工作。本轮人选经各单位推荐、职能部门审核，并由学校评定小组评选产生。

拟推荐人选共4人，具体如下：

| 奖项类别 | 拟推荐人选 |
| --- | --- |
| 汕头市优秀教师 | 陈志民 |
| 汕头市优秀教师 | 吴凡 |
| 汕头市优秀教师 | 于津 |
| 汕头市优秀教育工作者 | 黄玉梅 |

公示期间，如对以上人选有异议，可于7月15日前以书面形式向人事处反映。相关安排如下：

| 事项 | 内容 |
| --- | --- |
| 异议截止时间 | 7月15日前 |
| 受理地点 | 新行政中心315（人事处） |
| 受理方式 | 书面反映；单位材料需加盖公章，个人材料需签署真实姓名 |
| 联系电话 | 86502340 |
| 邮箱 | rscgs@stu.edu.cn |
