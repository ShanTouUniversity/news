据悉，研究生学院于1月7日发布通知，组织2012年秋季学期研究生“三助”岗位考核工作。

2012年秋季学期，学校共设置133个三助岗位，其中助教84个、助管49个。根据《汕头大学研究生“三助”岗位的实施办法》，考核安排如下：

| 事项 | 内容 |
| --- | --- |
| 考核对象 | 133个三助岗位（助教84个、助管49个） |
| 助教考核 | 由授课教师对助教进行考核并填写《研究生助教岗位考核表》 |
| 助管考核 | 由设岗单位对研究生进行考核并填写《研究生助管岗位考核表》，附津贴报账证明 |
| 提交截止 | 2013年1月11日下班前 |
| 提交地点 | 研究生学院（新行政楼401） |
| 后续影响 | 不考核或无法提供津贴证明的岗位，将不受理2013年春季学期三助申请 |
| 发布单位 | 研究生学院 |

考核表等见 OA 附件。

> ⚠️ 考核表及相关附件请前往 OA 系统查看原文。
>
> 来源：汕头大学 OA 通知（研究生学院）
