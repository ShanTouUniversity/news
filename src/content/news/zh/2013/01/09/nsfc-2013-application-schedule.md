据悉，为组织好2013年度国家自然科学基金项目申报，汕头大学科研处已就申报时间安排、限项规定、提交方式等事项作出统一部署。学校将于3月16日将申请书统一寄送国家自然科学基金委员会。

## 申报时间安排

| 时间 | 事项 |
| --- | --- |
| 1月8日起 | 离线申请下载2013年版申报书填写；在线申请使用已有帐号网上填写（未开通者联系科研处） |
| 2月25日前 | 学院形式审查、组织专家评审，并返回申请人修改 |
| 2月27日 | 各学院汇总《申请书》初稿（纸质和电子版）上报科研处 |
| 2月27日—3月8日 | 科研处集中形式审查、检查超项并反馈意见 |
| 3月8日—3月12日 | 返回项目申请书修改 |
| 3月13日 | 学院汇总申请书终稿1式2份（含原件1份）及电子版报送科研处（不受理个人报送） |
| 3月13日—3月15日 | 科研处复查、盖章、上传数据 |
| 3月16日 | 学校统一将申请书送国家基金委 |

## 限项规定

据通知内容，2013年起的主要限项规则包括：

- 自2013年开始，上一年度（即2012年）已获科学基金资助（不含一年期资助项目）的项目负责人，当年不得申请同类型项目；
- 申请人同年只能申请1项同类型项目（不含主要参与者）；
- 具有高级专业技术职务的人员，申请和正在承担的相关类型项目总数合计限为3项，涵盖面上项目、重点项目、重大项目、重大研究计划项目、联合基金项目、青年科学基金项目等；
- 青年科学基金、优秀青年科学基金、国家杰出青年科学基金均为负责人限获得1次资助的项目类型；
- 不具有高级专业技术职务的人员，作为申请人申请和作为负责人正在承担的项目合计限为1项；
- 创新研究群体、国家基础科学人才培养基金、海外及港澳学者合作研究基金、数学天元基金、国际（地区）合作交流等项目不受总数3项限制。

此外，2月27日提交申报书后项目组成员原则上不得更换；确需更换的，须于3月4日前向科研处提交书面报告并经审核通过。

## 提交方式与定稿要求

本次集中接收申请中，面上项目（不含青年—面上连续资助项目）和青年科学基金项目采用离线撰写方式，申请人须在2013年1月1日后下载最新版本模板并删除旧版模板文件；重点项目、重大项目、优秀青年科学基金项目、国家杰出青年科学基金项目等其余类型均采用在线撰写方式。

定稿材料要求为：与电子版版本号一致的纸质原件（亲笔签名）一式2份及电子版1份，博士后承诺书、专家推荐信、导师同意函、伦理审查证明等附件须按要求提供原件。

## 特别提示

科研处特别提醒两点：一是自2014年起，连续2年（2012年度和2013年度）申请面上项目未获资助的申请人将被暂停1年面上项目申请资格；二是基金委今年继续加强对申请书内容的比对检查，以防范学术不端行为、避免重复资助。
