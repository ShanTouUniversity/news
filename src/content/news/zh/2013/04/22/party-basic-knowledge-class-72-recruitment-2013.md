汕头大学第 72 期党的基本知识学习班拟于 **2013年5月** 开班，党委组织统战部通知各党总支、直属党支部开展学员推荐、初审和报送工作。推荐对象须已递交入党申请书一年以上，并已被列为重点培养对象；党校办公室复查后确定最终学员名单。

### 推荐名额

附件显示本期计划推荐学员 **160 人左右**，名额分配如下：

| 推荐单位 | 名额 |
| --- | ---: |
| 文学院总支 | 8人 |
| 理学院总支 | 20人 |
| 工学院总支 | 24人 |
| 法学院总支 | 25人 |
| 商学院总支 | 20人 |
| 长江艺术与设计学院总支 | 10人 |
| 长江新闻与传播学院总支 | 10人 |
| 研究生学院总支 | 16人 |
| 至诚书院总支 | 21人 |
| 机关、后勤、离退休党总支，以及继续教育学院、图书馆、社科部、科研、体育部、附中附小、学生宿舍区等直属支部 | 根据申请人员实际情况推荐 |
| **合计** | **160人左右** |

### 报送安排

各单位完成推荐和初审后，应由党总支或直属党支部在报名表上签署意见并加盖公章，于 **4月30日前** 统一报送党校办公室，地点为新行政中心 315 室；同时将学员名单汇总表电子版发送至 `o_dxb@stu.edu.cn`。党校办公室复查后确定学员名单。

报名表涉及姓名、出生年月、籍贯、所在院系、住址和联系电话等个人信息，学员名单汇总表也含姓名和电话，新闻页面仅发布推荐条件、名额和报送安排，不转载报名表或名单。

### 报到及课程安排

后续通知明确，第 72 期学习班于 **5月12日** 开学，附件名单共列 **121 名学员**，分为 9 个小组。学员须于 **5月9日至10日** 到各组组长处报到，提交一张一寸正面免冠照片并领取学习资料；各组组长于 5 月 9 日 13:00 在文北 206 开会。

课程安排如下：

| 日期 | 时间、地点 | 内容 |
| --- | --- | --- |
| 5月12日 | 8:55、10:40、14:55、19:30，讲堂三 | 党风建设；录像《锤炼》（上）；党员的义务和权利；中国共产党的性质和宗旨 |
| 5月19日 | 8:55、10:40，讲堂一；14:55、19:30，讲堂三 | 端正入党动机、争取早日入党；录像《锤炼》（下）；党的组织制度和纪律；深入贯彻落实科学发展观 |
| 5月26日 | 8:55、14:55，讲堂三；晚上，地点由各小组自定 | 党的指导思想与大学生；与关工委老同志交流；小组讨论 |
| 6月2日 | 自学；19:30—21:00，讲堂一、讲堂三 | 自学《中国共产党章程》等；理论考试 |

5 月 19 日须缴交书面作业，5 月 26 日须缴交学习小结和《学员登记表》。无正当理由未报到者视为自动放弃资格；学习期间无故缺课、缺考，或请假时间超过教学计划总时数三分之一以上者，不发结业证书。学员最终成绩综合理论考试、作业和学习小结、讨论情况、学习态度、党性作风及考勤情况评定。

学员名单、组长姓名及联系电话等附件内容涉及个人信息，本文不转载。
