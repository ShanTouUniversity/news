据悉，共青团汕头大学委员会与青年志愿者协会于4月23日发布通知，将组织汕大学生为四川雅安4·20地震开展募捐及祈福活动，以帮助灾区人民重振信心、渡过难关。

雅安市于4月20日发生7.0级地震，震中芦山县余震不断，灾区生命财产安全受到严重影响。校团委表示，“一方有难、八方支援”是中华民族传统美德，希望通过实际行动体现汕大学子的爱心。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 雅安，挺住 |
| 祈福时间 | 2013年4月26日19:30—20:00 |
| 祈福地点 | 大礼堂前 |
| 祈福内容 | 烛光合唱祈福，并在现场接受募捐；参与者需着装朴素、态度肃穆，听从工作人员指引，提前练唱附件合唱曲目 |
| 募捐时间 | 4月24日至25日11:00—13:00、17:00—19:00（二、四饭堂楼下）；4月26日祈福现场 |
| 募捐对象 | 全体学生 |
| 善款去向 | 汇至广东省青少年发展基金会“雅安青少年救灾基金”专项基金 |
| 主办单位 | 共青团汕头大学委员会、青年志愿者协会 |
