汕头大学第七届电子竞技大赛决赛暨第六届网络文化节颁奖仪式因天气和场地原因延期，活动时间调整为 **4月14日**，地点为新行政中心东侧正门。除电子竞技决赛外，现场还将设置面向全校师生的手机游戏挑战活动。

### 电子竞技赛程

| 时间 | CS 项目 |
| --- | --- |
| 9:00—10:00 | 犀飞利 VS 抱大腿 |
| 10:00—11:00 | 少先 VS EK |
| 11:00—12:00 | 季军战 |
| 17:00—18:00 | 冠军战 |

| 时间 | LOL 项目 |
| --- | --- |
| 14:00—15:00 | Orz VS 哆啦a梦 |
| 15:00—16:00 | 群主2B VS SD |
| 16:00—17:00 | 季军战 |
| 19:30—20:30 | 冠军战 |

### 手机游戏互动

| 时间 | 内容 |
| --- | --- |
| 9:00—12:00 | 《水果忍者》及趣味问答 |
| 14:00—17:00 | 《Temple Run 2》及趣味问答 |

网络文化节颁奖仪式将在活动期间举行，具体时间以现场安排为准。
