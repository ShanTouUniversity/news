汕头大学 2013 年度国家社会科学基金项目申请受理工作结束。本次学校共申请项目 **27 项**，不含国家社科基金艺术学与教育学项目。

| 申报单位 | 申请数量 | 备注 |
| --- | ---: | --- |
| 商学院 | 10 | 含粤台企业合作研究院 2 项 |
| 法学院 | 7 | 含地方政府发展研究所 3 项 |
| 文学院 | 4 | |
| 社科部 | 2 | 含地方政府发展研究所 1 项 |
| 新闻与传播学院 | 2 | |
| 高教所 | 1 | |
| 艺术与设计学院 | 1 | |
| 合计 | 27 | |

科研处感谢各单位教学科研人员的努力，并希望各单位继续鼓励教师申报科研项目，支持前期研究、课题设计和论证工作，提高国家社科基金项目立项资助率。

> 来源：汕头大学 OA 通知（科研处）
