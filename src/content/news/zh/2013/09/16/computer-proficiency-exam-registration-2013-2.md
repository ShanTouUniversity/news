据悉，教务处发布通知，本学期全国高等学校计算机水平考试报名工作已经启动，学生可于9月13日至10月7日通过学分制系统网上报名。

## 考试安排

| 事项 | 内容 |
| --- | --- |
| 考试时间 | 2013年12月28日8:00起分批进行，每批次各科目考试时间均为105分钟 |
| 考试方式 | 计算机网络考试 |
| 考试科目 | 一级：计算机应用；二级：Visual Basic 程序设计、Visual FoxPro 程序设计、C++ 程序设计、Access 数据库（2003）、Photoshop 图像处理与制作、网页制作基础、Flash 动漫制作、Java 程序设计 |
| 报考限制 | 每次考试每个考生最多可报考不同或相同级别的两个科目 |
| 报名时间 | 2013年9月13日至10月7日 |
| 报名方式 | 登录学分制系统网上报名（我要选课 → 资格考试报名） |
| 报名费 | 38元/人/科 |
| 缴费方式 | 财务处委托网络中心于10月8日从报名学生一卡通账户统一扣取，请报名学生提前存足余额，扣费不成功则报名失败 |

> 来源：汕头大学 OA 通知（教务处）
