据悉，国际交流合作处发布通知，新西兰惠灵顿维多利亚大学2014年寒假项目现已启动报名。该项目自2014年起对我校学生开放。

据介绍，该项目名为“跨文化领导力暑期课程”（Intercultural Leadership Summer Course），是惠灵顿维多利亚大学为中国伙伴大学本科生组织的短期寒假海外学习项目。项目通过讲座、讨论会和社会交流活动，帮助学生培养全球视角与领导力，增进对国际和地区问题的认识，提高跨文化交际能力，并在全英文环境中提升英语运用能力、了解中新文化交流。项目结束后，学生将获得项目证书。

## 项目要点

| 事项 | 内容 |
| --- | --- |
| 项目名称 | 跨文化领导力暑期课程（Intercultural Leadership Summer Course） |
| 项目时间 | 2014年1月14日—2月8日 |
| 学位数 | 30个（含为北京大学预留的学位），符合条件者先来先得 |
| 项目费用 | 3600新西兰元 |
| 申请对象 | 在籍本科二、三年级学生 |
| 申请时间 | 即日起，先来先得，早申请成功率较高 |

## 申请条件

- 在籍本科二、三年级学生；
- 学习成绩优秀；
- 具有较强的跨文化交际能力、独立生活能力和应变能力；
- 英语听说读写优秀，要求相当于 IELTS 6 / TOEFL 550；
- 家庭经济状况良好。

## 申请材料

| 材料 | 说明 |
| --- | --- |
| 《国际交流项目报名表》 | 按要求填写 |
| 中文成绩单 | 需教务盖章 |
| 英语能力证明 | 相当于 IELTS 6 / TOEFL 550 水平 |
| 英文写作 | 题目：Why would you like to participate in the programme and what do you hope to gain from this experience? |

## 费用构成

| 费用项目 | 金额 |
| --- | --- |
| 住宿餐饮费 | 1050新西兰元 |
| 参观考察费 | 700新西兰元 |
| 项目费用（含当地医疗和保险、机场往返学校交通费、教材费、活动费等） | 1850新西兰元 |
| 合计 | 3600新西兰元 |

项目费用不包括国际旅费、惠灵顿公共交通费（约25新西兰元/周）、娱乐花销（约40新西兰元/周）以及个人零食、话费等（约30新西兰元/周）。

## 报名与咨询

惠灵顿维多利亚大学采用先来先得原则，较早申请的成功率较高。录取并缴费后，如在项目开始前退出，需扣除部分费用。项目信息以附件为准，如有疑问，可发邮件至 rghuang@stu.edu.cn 咨询。

## 惠灵顿维多利亚大学简介

惠灵顿维多利亚大学创建于1899年，是新西兰最古老的大学之一，位于新西兰首都惠灵顿，由建筑学院、教育学院、人文社会学院、商业与管理学院、法学院及科学院六个学院组成，分布在4个校区。该校法学院在亚太地区享有盛名，研究水平居新西兰大学之首，在 QS 2013—2014 世界大学排行榜上位居第265位。学校现有学生20380名，其中3400名来自全球100多个国家的国际学生或交换学生。
