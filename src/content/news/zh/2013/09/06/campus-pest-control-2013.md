据悉，为改善校园环境卫生、加强植物病虫害防治，汕头大学资源管理处将于9月9日至15日在校区及成教学院的绿地花木、果树及水沟开展喷药作业，一并开展除"四害"工作。

资源管理处提醒，喷药期间请师生员工注意安全，避免在喷药区域长时间停留或接触花草树木。

| 日期 | 喷药区域 |
| --- | --- |
| 9月9日 | 学术交流中心周围、P楼、学生宿舍区、水库坝、789号楼、A-B教工宿舍 |
| 9月10日 | 食堂、行政楼周围、行政中心 |
| 9月11日 | 校卫队办公场地周边、校门口、各校道、新图书馆外围 |
| 9月12日 | 医科楼、新教学楼、G/H/I/J座学生宿舍 |
| 9月13日 | 人工湖区域、运动场 |
| 9月14日 | 成教学院 |
| 9月15日 | 附中、附小至精神卫生中心 |

> 来源：汕头大学 OA 通知（资源管理处）
