据悉，根据广东省自然科学基金管理委员会有关通知及基金项目管理办法，汕头大学科研处于9月30日发布通知，启动学校2013年广东省自然科学基金项目结题工作。本年度共有21个项目需办理结题，涉及工学、理学、管理学等多个学科领域。

## 关键信息

| 事项 | 内容 |
| --- | --- |
| 结题项目数 | 21项 |
| 验收形式 | 重点项目为会议验收；面上项目（自由申请、博士启动）为专家函评 |
| 专家要求 | 本校验收专家不超过1名；各专家所在单位不同，二级单位之间视为同一单位；具有副高以上职称的同行专家；面上项目3名，重点项目5名 |
| 网上结题时间 | 2013年10月9日至11月12日 |
| 材料提交 | 2013年11月24日至30日，纸质版一式两份交至科研处 |
| 延期申请截止 | 2013年10月15日前与科研处联系 |
| 联系电话 | 86502813 |

## 验收形式与专家要求

本次结题按项目类别分别组织验收：重点项目采用会议验收，项目负责人须将项目验收时间及专家初步名单于10月15日前报科研处，省基金办将进行抽查；面上项目（自由申请和博士启动）采用专家函评。项目结题的具体操作步骤详见《省基金项目网上结题操作流程》（附件1）。

| 事项 | 要求 |
| --- | --- |
| 重点项目验收形式 | 会议验收，验收时间及专家初步名单须于10月15日前报科研处，省基金办进行抽查 |
| 面上项目验收形式 | 专家函评 |
| 本校专家人数 | 不超过1名 |
| 专家所在单位 | 各专家所在单位不同，二级单位之间视为同一单位 |
| 专家职称 | 具有副高以上职称的同行专家 |
| 专家人数 | 面上项目3名，重点项目5名 |

## 时间安排

| 时间 | 工作安排 |
| --- | --- |
| 10月9日至11月12日 | 各项目负责人完成网上省基金项目结题书录入、提交工作 |
| 11月12日至18日 | 科研处形式审核 |
| 11月19日至23日 | 省基金委审核 |
| 11月24日至30日 | 各项目负责人将通过基金委审核的纸质版一式两份交至科研处 |

提交的纸质材料包括结题报告（附专家组意见原件）、合同书（复印件）、发表论文专著（论文需有省基金资助标识）、专利证书及其他结题证明材料。

## 延期申请与联系

需要延期结题的项目，项目负责人须在10月15日前与科研处联系。联系人：胡云翔、朱长盛；电话：86502813。
