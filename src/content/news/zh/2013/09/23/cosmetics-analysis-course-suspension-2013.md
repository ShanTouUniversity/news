据悉，教务处于9月23日发布通知，因化学系教师方奕文外出参加研究生招生宣传，其开设的课程《化妆品及分析》将停课一次，校方提醒修读该课程的同学相互转告。

## 停课安排

| 事项 | 内容 |
| --- | --- |
| 课程 | 化妆品及分析 |
| 班号 | 63749 |
| 停课时间 | 第2周星期四（9月26日）第1、2节 |
| 上课地点 | E207 |
| 停课原因 | 任课教师外出参加研究生招生宣传 |
| 补课安排 | 时间待定，另行通知 |

修读该课程的同学请相互告知，并留意教务处后续发布的补课通知。

> 来源：汕头大学 OA 通知（教务处）
