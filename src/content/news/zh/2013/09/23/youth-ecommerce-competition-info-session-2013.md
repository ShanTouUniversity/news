据悉，汕头大学商学院发布通知，广东青年电子商务创业大赛（第一季）校园宣讲会将于2013年9月25日15:00—17:00在E阶梯201举行。届时，演讲嘉宾胡瑛将向到场师生传达大赛精神并讲解赛制，大赛组委会还将与师生进行开放式交流，并接受现场报名。主办方欢迎全校师生参加。

## 大赛关键信息

| 项目 | 内容 |
| --- | --- |
| 宣讲会时间 | 2013年9月25日15:00—17:00 |
| 宣讲会地点 | E阶梯201 |
| 演讲嘉宾 | 胡瑛 |
| 大赛主题 | 创业导航，宇博飞翔 |
| 大赛时间 | 2013年9月至2014年1月 |
| 比赛地点 | 汕头、广州 |
| 比赛方式 | 提交电子商务营销案，并结合实训基地实操 |
| 报名对象 | 广州、深圳、汕头三地的广东籍大学生和社会青年 |
| 团队要求 | 以团队形式报名，各队自定团队名称，人数2—5人 |
| 招募方式 | 通过网络发布、媒体传播、学校定点招募等形式公开招募，报名者登录官方网站按指定方式上传团队成员简历、职能分工等资料 |
| 奖项 | 冠、亚、季军各1组，分获奖金与创业基金 |

## 奖项设置

| 奖项 | 奖金 | 创业基金 |
| --- | --- | --- |
| 冠军（1组） | 3万元 | 120万元 |
| 亚军（1组） | 2万元 | 80万元 |
| 季军（1组） | 1万元 | 50万元 |
