据悉，根据广东省教育考试院《关于做好2013年下半年广东省全国大学英语四、六级考试报名工作的通知》（粤考院〔2013〕279号），2013年下半年全国大学英语四、六级考试报名已经启动。本次考试定于12月14日举行，四级考试时间为9:00—11:20，六级考试时间为15:00—17:20。

## 关键信息

| 项目 | 内容 |
| --- | --- |
| 考试时间 | 2013年12月14日 |
| 四级时间 | 9:00—11:20 |
| 六级时间 | 15:00—17:20 |
| 报名方式 | 登录学分制专题网站，完成"我要选课→资格考试报名" |
| 网上报名 | 2013年9月4日—21日 |
| 报名费 | 38元 |
| 扣费安排 | 9月22日由网络中心统一从一卡通扣取；不成功则9月23日上午由中国银行从学费账户扣取 |
| 入场证件 | 身份证、学生证、准考证，缺一不可 |

## 报名条件

| 级别 | 条件 |
| --- | --- |
| 四级 | 除一年级新生外，本学期英语分级为 level 2 及以上的本科生；艺术类本科生须修完 ELC EA3 或通过英语应用能力考试；2012级英语专业学生 |
| 六级 | 已取得四级合格证书，或四级成绩达425分及以上；已取得英语专业四级合格证书 |

已获得六级合格证书或六级成绩达425分及以上者可以再次报名，但本科生须已修读完 ELC4，且再次报名次数不超过2次。

## 报名与缴费

本次报名全部在网上进行，学生须登录学分制专题网站，按"我要选课→资格考试报名"的流程完成报名，报名时间为9月4日至21日。

报名费为38元。研究生和本科生的报名费由财务处委托网络中心于9月22日统一从学生一卡通账户中扣取；若扣费不成功，则由财务处委托中国银行于9月23日上午从学费账户中扣取。学生须在此期间保证账户余额充足，扣费不成功即视为报名失败。

## 注意事项

- 本次考试不接受非在校生报名。
- 考生参加考试须携带身份证、学生证和准考证，三证缺一不可。

> 来源：汕头大学 OA 通知（教务处）
