据悉，学生处于9月18日发布通知，启动学生社区 X 计划 2013—2014 学年活动立项申报工作，以促进学生社区文化发展，构建人文、创新、活力与和谐社区。

该计划自2010年11月启动以来已开展两期，本学年立项申报面向全校教职员工（个人或团队）及各宿舍区本科学生团队（自由组合）。

## 项目要求

| 事项 | 内容 |
| --- | --- |
| 活动对象 | 全校各宿舍区本科学生 |
| 活动时间 | 2013年10月至2014年6月 |
| 项目类型 | （1）创新项目：围绕健康、规划、学习、时间、人际、情感等自主设计新颖、可行、学生喜闻乐见的活动；（2）承办已有项目：在主办方拟定名称基础上改进，不得修改原名称，具体见附件 |
| 后续材料 | 立项活动完成后1周内提交新闻稿和照片，2周内提交工作备忘录、电子相册或 DV 等至 G座238 辅导员办公室存档 |
| 主办单位 | 学生处 |

## 申报安排

| 事项 | 内容 |
| --- | --- |
| 申报时间 | 即日起至9月30日17:00前 |
| 申报材料 | 《学生社区X计划2013—2014学年活动项目申报书》及补充材料，指定一名负责人 |
| 提交地点 | 学生宿舍区辅导员办公室 G座238 |
| 电子版 | 发送至 ymfan@stu.edu.cn |
| 咨询电话 | 86503118 |

详细活动名称及申报书见 OA 附件。
