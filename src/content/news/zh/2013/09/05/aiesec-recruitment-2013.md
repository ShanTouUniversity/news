据悉，汕头大学 AIESEC 团队于9月5日发布招新通知，将开展系列招新活动，面向全校学生开放。

AIESEC 是由在校学生和新进毕业生运营的全球性、非政治性、独立非营利组织，目前拥有8万余名会员，分布于2400余所大学，遍布五大洲124个国家和地区，全球总部位于荷兰鹿特丹。汕头大学 AIESEC 成立于2012年6月18日，得到商学院大力支持，是中国大陆区总会重点关注和培养对象。

## 招新安排

| 事项 | 内容 |
| --- | --- |
| 对象 | 全校学生，不限专业、不限年级 |
| 宣讲会 | 9月8日20:00—22:00，学生活动厅（图书馆一楼），内容包括团队介绍、体验营及真人图书馆 |
| 摆摊报名 | 9月5日金三角摆摊，现场接受报名 |
| 面试 | 简历筛选、小组面试、个人面试，时间地点短信通知 |
| 报名截止 | 2013年9月11日23:30 |
| 报名方式 | 投递报名表至A331、D240、E264、G322、J316宿舍信封；在金三角或二、四饭楼下领取报名表现场报名；在9月8日宣讲会现场报名 |
| 主办单位 | 汕头大学 AIESEC 团队、商学院 |

更多招新信息可关注官方微博 @AIESEC汕大 或微信公众平台。欢迎有志成为国际志愿者、参与海外实习及拓展国际社交网络的同学报名。
