据悉，根据汕头大学与新西兰坎特伯雷大学签订的学生交流协议，自2013年起，学校可推荐优秀本科学生赴新西兰基督城的坎特伯雷大学参加海外学习项目（非学位项目）。国际交流合作处近日发布通知，启动2014年该项目的申请。

## 项目要点

| 事项 | 内容 |
| --- | --- |
| 项目名称 | 坎特伯雷大学海外学习项目（非学位项目） |
| 学年时间 | 第一学期：2014年2月—6月；第二学期：2014年7月—11月 |
| 申请截止 | 第一学期：2013年11月1日；第二学期：2014年5月1日 |
| 申请对象 | 在籍二年级以上本科生，GPA居本院本年级前30% |
| 语言要求 | 雅思总分不低于6.0且单科不低于6.0；托福iBT总分不低于80（听力、阅读和写作不低于19）；托福PBT总分不低于500且英语写作（TWE）不低于4.5 |
| 材料提交 | 10月25日前将纸质材料提交至国际交流合作处（新行政中心240室） |
| 费用 | 学费、国际旅费、境外生活费、办理签证手续费等由学生自行承担 |

## 报名条件

- 在籍二年级以上本科生；
- GPA居本院本年级前30%；
- 思想成熟、自律能力强，学术积极性较强；
- 雅思总分不低于6.0，且单科不低于6.0；托福iBT总分不低于80，其中听力、阅读和写作不低于19；托福PBT总分不低于500，且英语写作（TWE）不低于4.5；
- 其他条件见项目手册。

## 提交材料

| 材料 | 说明 |
| --- | --- |
| 申请表 | 按项目要求填写 |
| 护照复印件 | 按要求提供 |
| 已修成绩单原件 | 须加盖校教务处公章 |
| 英文水平证明 | 雅思、托福等成绩证明 |

## 费用

项目费用由学生自行承担，包括学费、国际旅费、境外生活费以及办理签证手续费等。

## 申请程序

有意申请者须于10月25日前将纸质材料提交至国际交流合作处（新行政中心240室）。该处将根据两校协议统一向坎特伯雷大学出具推荐名单并寄送申请材料；坎特伯雷大学根据申请材料决定录用名单，并直接向学生寄送发票和通知书。学生完成海外学年学习顺利归校后，由教务处根据所选课程及授课内容进行成绩认定。如有疑问，可发邮件至 rghuang@stu.edu.cn 咨询。

## 坎特伯雷大学简介

坎特伯雷大学建于1873年，是一所公立研究型大学，设商学与法律、文、教育、工程、理五个学院，下设30多个系部，共100多个专业。该校在QS 2013—2014世界大学排行榜上列第238位，其土木工程和结构工程学科列第21位，教育学、心理学、法学、地理、历史、哲学、语言学、会计和金融等学科列前100位。学校现有教师及研究人员约850人，在校生16000多人，其中来自80个国家和地区的留学生1200多名。学校位于新西兰南岛最大城市基督城西北部；基督城为新西兰第二大城市，环境优美，被誉为“花园城市”。
