据悉，为鼓励学生建言献策、参与学校建设，搭建校领导与学生之间的沟通桥梁，汕头大学于9月举办第2期校领导与学生晚餐会。本期活动为新生专场，定于 **9月14日18:00** 在 **鸿泰餐厅201室** 举行，计划邀请 **32名2013级学生** 参加。

## 关键信息

| 事项 | 内容 |
| --- | --- |
| 活动名称 | 第2期校领导与学生晚餐会 |
| 活动时间 | 2013年9月14日18:00 |
| 活动地点 | 鸿泰餐厅201室 |
| 邀请嘉宾 | 校领导及有关部处领导、教师代表4—5人 |
| 参加学生 | 2013级新生32名 |
| 报名截止 | 2013年9月12日 |
| 报名方式 | 登录学校预约系统填写 |
| 名单公布 | 校内办公信息网 |
| 餐费 | 由学校统一支付 |

## 活动形式

晚餐会由校领导主持，邀请嘉宾与参加学生围绕学校建设及学生关心的问题进行自由交流。学生处希望受邀同学在活动中发挥桥梁作用，实事求是地收集身边同学关注的问题并带到会上交流。

## 报名方式

有意参加的新生可于 **9月12日前** 登录[预约系统](http://booking.stu.edu.cn/index.htm)填写报名信息，并可一并提交事先收集的问题。名额报满后，预约系统将自动关闭；受邀学生名单将在校内办公信息网公布。

对本次活动有任何意见或建议，可发送邮件至学生处邮箱 `lslin@stu.edu.cn`。

> 来源：汕头大学 OA 通知（学生处）
