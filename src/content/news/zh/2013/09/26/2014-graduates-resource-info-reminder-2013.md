据悉，根据广东省教育厅有关通知，为做好2014届高校毕业生就业方案的编制及此后一系列推荐、派遣工作，汕头大学需报送2014届毕业生资源信息，报送范围包括校本部本科毕业生和全体研究生。

学生处近日提醒，各学院（书院）应通知尚未填写基本信息的毕业生，务必于2013年10月10日前登录 http://gdc.stu.edu.cn/ 填写个人信息。学生处指出，毕业生基本信息涉及日后派遣等一系列工作，请各位毕业生认真对待。具体操作说明可查看通知附件。

## 关键信息

| 事项 | 内容 |
| --- | --- |
| 报送对象 | 2014届毕业生（含校本部本科毕业生、全体研究生） |
| 截止时间 | 2013年10月10日前 |
| 填写平台 | http://gdc.stu.edu.cn/ |
| 重要性 | 毕业生基本信息涉及日后派遣等一系列工作，须认真对待 |
| 操作说明查看方式 | 见 OA 系统通知附件 |
| 责任单位 | 各学院（书院）负责通知尚未填写基本信息的毕业生 |

> ⚠️ 具体操作说明见 OA 系统通知附件，新闻页面不予转载。
