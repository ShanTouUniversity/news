据悉，汕头大学将于今年10月对全校2011级、2012级、2013级学生进行体质健康标准测试，测试分四个休息日进行。为保障测试现场组织与测试数据整理工作，体育部计划面向校本部本科生招聘12名学生工作人员，并参照学校勤工俭学标准给予工作补助。

## 关键信息

| 项目 | 内容 |
| ---- | ---- |
| 测试日期 | 10月13日（周日）、19日（周六）、20日（周日）、26日（周六） |
| 招聘人数 | 12名（女生人数不超过一半） |
| 工作补助 | 参照学校勤工俭学标准 |
| 报名截止 | 2013年9月27日下午下班前 |
| 报名邮箱 | o_tyb@stu.edu.cn |
| 后续安排 | 体育部汇总报名信息后通知面试和培训 |

## 工作内容

据了解，受聘学生的工作主要包括三个方面：一是协助值班教师完成器材搬运、发令、计时、计数、记录等现场事务；二是对测试数据进行监督，维持测试秩序，及时纠正不规范的测试行为；三是协助教师完成数据的整理和录入。

## 任职要求

体育部对报名者提出三项要求：身体健康，能够在室外环境下工作，并具备较强的组织管理工作能力；确保在上述测试日期没有其他工作或学习安排；课余时间充足，能够协助教师整理和录入数据。

## 报名方式

有意应聘的同学需在9月27日下午下班前，将本人的学号、姓名、年级专业和手机号码通过电子邮件发送至体育部邮箱 o_tyb@stu.edu.cn，并在邮件标题中注明“体质测试工作人员”字样。体育部表示，将在汇总报名信息后另行通知面试与培训安排。

> 来源：汕头大学 OA 通知（体育部）
