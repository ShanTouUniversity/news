据悉，汕头大学资源管理处已公布2013年暑期学生宿舍水电费账目，学生即日起可登录系统查询，9月9日至13日为核对期；核对期内无异议的费用，将自9月16日起通过一卡通扣缴。

根据学校暑假安排（汕大党政办〔2013〕4号），在校学生的暑假时间为2013年6月30日至8月17日。结合2012级学生军训以及部分医学院学生搬迁带来的住宿变动，水电中心在暑期分四次进行抄表，以分段核算各阶段的用水用电量。

## 暑期抄表安排

| 抄表次序 | 时间 | 说明 |
| --- | --- | --- |
| 第一次 | 7月2日 | 毕业生离校后 |
| 第二次 | 7月16日 | 2012级学生军训结束后 |
| 第三次 | 8月16日 | 暑假结束前 |
| 第四次 | 8月31日 | 新生报到前 |

## 查询与核对

| 项目 | 内容 |
| --- | --- |
| 查询方式 | 登录水电费管理系统 http://power.stu.edu.cn/ |
| 登录账号 | 校园网账号 |
| 核对时间 | 9月9日至13日上班时间 |
| 异议受理地点 | 水电中心（科技楼旁），电话 86502489 |
| 住宿名单不符 | 辅导员办公室（B座-106），电话 86503355 |

学生如发现账目有错漏，可填写《水电费核查申请表》并签名，于9月9日至13日上班时间提交至水电中心办理。所住宿舍与学生名单不一致的，可联系辅导员办公室处理。

## 缴费安排

| 事项 | 时间或说明 |
| --- | --- |
| 一卡通扣缴开始 | 9月16日起，由网络中心（电话 86503545）扣缴 |
| 正常缴费时间 | 9月16日至18日 |
| 逾期未缴 | 9月23日按学校有关规定处理 |
| 核对期结束后提出异议的更正 | 需3至5个工作日 |

资源管理处提醒，核对期满未提出异议即视为认可相关费用。由于更正申请需要多个部门协同处理，核对期结束后再提出的异议，预计需3至5个工作日才能完成修正。学校同时提醒学生及时为一卡通充值，以免因余额不足影响扣缴。
