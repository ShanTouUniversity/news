据悉，为纪念"12·5国际志愿者服务日"，汕头大学校团委将于12月7日在校园内举办"校内服务一条街"系列活动，动员各学院青年志愿者协会面向全校师生提供多样化特色服务。

本次活动由校青年志愿者工作部统筹，旗下九个青协分会各展所长：

| 青协 | 服务项目 |
| --- | --- |
| 文学青年协会 | 予温情送祝福 |
| 医学青年协会 | 心脏复苏、止血包扎演示 |
| 新闻青年协会 | 单反操作现场授课 |
| 商务青年协会 | 丝巾领带体态培训 |
| 理科青年协会 | 水垢清理技巧 |
| 法律青年协会 | 眼镜保养、法律咨询 |
| 艺术青年协会 | 心灵手巧DIY手作 |
| 工程青年协会 | 真情义修小家电 |
| 至诚常青藤志愿团 | 爱心墙互助活动 |

主办方希望通过此类贴近师生日常需求的服务活动，弘扬"奉献、友爱、互助、进步"的志愿精神，展现汕头大学青年学子的责任与担当。

> 来源：汕头大学 OA 通知（校团委）
