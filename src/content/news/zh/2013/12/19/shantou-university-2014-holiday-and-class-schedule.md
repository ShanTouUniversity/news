汕头大学党政办公室于2013年12月19日公布2014年部分节假日放假及调课安排。学校根据国务院办公厅当年发布的节假日安排，确定校内休假日期如下：

| 节日 | 当时公布的安排 |
| --- | --- |
| 元旦 | 1月1日放假1天 |
| 春节 | 1月31日至2月6日放假7天 |
| 清明节 | 4月5日放假，4月7日补休 |
| 劳动节 | 5月1日至3日放假，5月4日上班；5月2日课程与5月4日课程对调 |
| 端午节 | 6月2日放假，与周末连休 |
| 中秋节 | 9月8日放假，与周末连休 |
| 国庆节 | 10月1日至7日放假；9月28日、10月11日上班；10月6日课程与9月28日课程对调，10月7日课程与10月11日课程对调 |

通知还要求各单位在假期前开展安全和节能检查，并安排值班。校方表示，如上级要求或学校情况变化，假期及调课安排可能另行调整。

> 来源：汕头大学 OA 通知（党政办公室）
