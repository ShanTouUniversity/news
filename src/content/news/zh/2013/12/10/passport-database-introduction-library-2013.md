据悉，汕头大学图书馆于12月10日发布通知，介绍Passport数据库的使用方法及其资源特色。

Passport数据库是欧睿信息咨询公司（Euromonitor International）完全自主研究的旗舰产品，涵盖200多个国家的全球化市场信息咨询解决方案。数据库内容从宏观的国家地区信息，到中观的行业产业信息，再到微观的企业信息，层次分明，数据详实。

该数据库可帮助读者全面掌握各国商业环境及其变化趋势，适用于市场调研、商业分析、学术研究等多种用途。

## 数据库信息

| 项目 | 内容 |
| --- | --- |
| 数据库名称 | Passport |
| 出品公司 | 欧睿信息咨询公司（Euromonitor International） |
| 覆盖范围 | 200多个国家 |
| 内容层级 | 宏观国家地区 → 中观行业产业 → 微观企业信息 |
| 适用用途 | 市场调研、商业分析、学术研究 |
| 发布单位 | 图书馆 |

有需求的师生可前往图书馆了解更多使用方式。

> 来源：汕头大学 OA 通知（图书馆）
