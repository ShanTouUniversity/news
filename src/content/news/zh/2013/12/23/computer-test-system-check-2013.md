据悉，2013年下半年全国计算机水平考试系统测试即将进行。学校将于12月25日下午16:00开始在E座机房开放系统测试，按照先到先安排的原则进行。

## 测试安排

| 事项 | 内容 |
| --- | --- |
| 正式考试时间 | 2013年12月28日上午（分批进行） |
| 系统测试开始 | 12月25日下午16:00 |
| 测试地点 | E座机房 |
| 测试原则 | 先到先安排 |
| 语言机房 | E101机房：Access数据库（2003）/计算机应用（2003）等 |

考生可提前熟悉考试系统环境，确保正式考试顺利进行。

> 来源：汕头大学 OA 通知（教务处）
