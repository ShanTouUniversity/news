据悉，人事处于12月12日发布通知，经2013年12月10日第16次校领导会议研究，拟聘任刘文华为理学院院长，现予公示。

根据《汕头大学管理干部聘任试行办法》（汕大党字〔2009〕47号），公示安排如下：

| 事项 | 内容 |
| --- | --- |
| 拟聘职务 | 理学院院长 |
| 拟聘人选 | 刘文华 |
| 研究决定 | 2013年12月10日第16次校领导会议 |
| 公示截止 | 2013年12月18日前 |
| 受理方式 | 以书面形式向人事处反映；单位材料需加盖公章，个人材料需签署真实姓名 |
| 联系电话 | 86503390 |
| 邮箱 | rscgs@stu.edu.cn |
| 发布单位 | 人事处 |

> 来源：汕头大学 OA 通知（人事处）
