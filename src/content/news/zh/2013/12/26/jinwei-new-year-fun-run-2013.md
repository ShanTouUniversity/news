汕头大学体育部于2013年12月26日公布，260名在校学生报名参加汕头市迎新年“金味”万人健身跑。活动当时安排于12月28日举行，参赛学生计划从汕大校训碑集合乘车前往起点。

## 活动安排

| 项目 | 内容 |
| --- | --- |
| 报名人数 | 260人 |
| 集合时间 | 2013年12月28日早上6时 |
| 集合地点 | 汕大校训碑 |
| 活动起点 | 汕头市人民广场 |
| 活动终点 | 华侨公园 |
| 返校安排 | 乘原车返回校园并到体育馆领取纪念品 |

通知安排学校以39路公交车接送，并按学院（书院）分车。本文不转载附件中的参与者名单，也不刊载个人联系方式。
