据悉，学生处于8月21日发布通知，组织学生参加应香港廉政公署青年及德育组邀请举办的“诚信·承传”2013/14队际比赛。该计划以诚信为主题，由香港廉政公署与香港大专院校及青年服务机构合办。

## 比赛安排

| 事项 | 内容 |
| --- | --- |
| 组别 | （甲）推广计划书——向年青人推广诚信；（乙）专题研习报告（二选一：青年人面对诚信挑战的处理及明智抉择建议；青少年对金钱运用与丰盛人生的看法） |
| 参赛形式 | 2至4人组队，每队限在甲或乙组提交一份作品 |
| 作品要求 | 2500至3000字（中英文均可，不含附录等），A4单面打印、页码、2.5厘米边距、13号字，结尾注明总字数 |
| 提交截止 | 2013年10月10日 |
| 提交方式 | 纸质版交至行政中心106助学工作管理中心，电子版发至 zjliu@stu.edu.cn，邮件主题“诚信·承传”青年计划 |
| 评审 | 学校组织评审后报送筹办委员会；主委会从两组各选最多10队入围，入围队伍需以英语作10分钟简报及5分钟答问 |
| 奖励 | 入围队伍有机会获奖学金及资助（含往返机票及住宿），于2014年4月24至27日赴港参加交流活动及青年高峰会议 |
| 咨询 | 助学工作管理中心刘在军老师，电话 86502249，邮箱 zjliu@stu.edu.cn；计划网站 www.icac.org.hk.yip.html |
| 发布单位 | 学生处 |

> 来源：汕头大学 OA 通知（学生处）
