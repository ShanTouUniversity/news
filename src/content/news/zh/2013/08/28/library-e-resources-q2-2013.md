汕头大学图书馆通过 2013 年第 7 期《电子资源动态通报》（总第 13 期）公布 2013 年第二季度电子资源使用量。统计覆盖中文和外文数据库，指标包括下载次数、检索次数、点击量、播放次数、传递页数、阅读册数和曲目欣赏量等，各数据库的统计口径有所不同。

### 主要数据库使用量

| 数据库 | 使用量 | 指标 |
| --- | ---: | --- |
| CNKI 中国期刊网络出版总库 | 148,907 | 下载次数 |
| 库客数字音乐图书馆 | 147,037 | 曲目欣赏量 |
| 读秀知识库 | 76,365 | 传递页数 |
| 超星学术视频 | 53,388 | 播放次数（其中校内服务器 1,640 次） |
| 百万超星电子图书 | 36,297 | 阅读册数 |
| 维普中文科技期刊数据库（全文版） | 35,916 | 下载次数 |
| CNKI 中国优秀硕士论文全文数据库 | 32,886 | 下载次数 |
| 慧科新闻数据库 | 32,037 | 点击量 |
| 银符考试题库 B1 | 28,291 | 点击量 |
| Elsevier ScienceDirect | 24,982 | 下载次数 |
| EI Village | 22,300 | 检索次数 |
| JSTOR 西文过刊全文 | 18,958 | 下载次数 |
| Wiley Online Library | 12,997 | 下载次数 |
| Web of Science（SCI/SSCI/A&HCI） | 11,677 | 检索次数 |

### 中文数据库

其余中文资源中，CNKI 中国博士论文全文数据库本季度下载 10,241 次，本校超星电子图书阅读 12,622 册。中国资讯行下载 18,397 次，北大法意数据库点击 13,121 次，锐思（RESSET）金融数据库下载 4,884 次，国泰安 CSMAR 数据库下载 805 次，Westlaw China 万律检索 3,624 次。

### 外文数据库

其他外文数据库中，Springer 下载 9,988 次，美国数学会 MathSciNet 检索 10,682 次，IOP 下载 506 次，通报还记录了其余外文资源的使用情况。

> 来源：汕头大学 OA 通知（图书馆）
