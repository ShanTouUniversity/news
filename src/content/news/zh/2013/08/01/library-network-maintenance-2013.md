据悉，网络与信息中心于8月1日发布通知，图书馆网络机房所在区域空调将于8月2日至4日进行维修，施工期间该片区校园网络运行存在不确定性。

据介绍，维修期间机房环境温度可能升高，核心网络设备或出现异常，严重时可能导致片区网络中断。网络与信息中心表示，将采取应急措施，全力保障网络稳定运行。

| 事项 | 内容 |
| --- | --- |
| 维修时间 | 8月2日至8月4日 |
| 维修内容 | 图书馆网络机房所在区域空调维修 |
| 影响范围 | 图书馆及周边片区教学楼、办公楼网络 |
| 恢复安排 | 维修结束后逐步恢复正常，不另行通知 |
| 联系电话 | 86503400（校园短号 883400） |
| 联系邮箱 | stunic@stu.edu.cn |
| 发布单位 | 网络与信息中心 |

中心提醒相关楼宇师生提前做好安排，维修期间如遇网络异常可及时联系。

> 来源：汕头大学 OA 通知（网络与信息中心）
