据悉，汕头大学资源管理处基建办公室于2013年8月9日发布公示，就学生宿舍区变配电扩容项目的预增项情况作出说明。

该工程已于7月27日开工。施工过程中，为满足热泵机组的配电需要，工程需增加电缆过渡箱及铜排；同时，室外箱变还需增设防水及排水设施。上述内容均超出原合同范围。经初步估算，预增项约需增加造价2.50万元，累计预增造价在学校规定的10%以内。

根据《基建工程招标投标管理实施办法》，基建办公室现将该项目预增项予以公示。

## 公示信息

| 事项 | 内容 |
| --- | --- |
| 工程名称 | 学生宿舍区变配电扩容项目 |
| 开工日期 | 2013年7月27日 |
| 预增项内容 | 增加电缆过渡箱及铜排；增加室外箱变防水及排水设施 |
| 预增项造价 | 约2.50万元 |
| 造价范围 | 未超过学校规定的10% |
| 意见反馈截止时间 | 2013年8月12日17时30分 |
| 反馈部门 | 监察审计处或基建办 |
| 公示单位 | 基建办公室 |
| 公示日期 | 2013年8月9日 |

如有不同意见，可于8月12日17时30分前以书面形式向监察审计处或基建办反映。

> 来源：汕头大学 OA 通知（资源管理处）
