据悉，汕头大学人事处转发广东省物价局粤价函〔2013〕752号函件，就广东价格指数专家推荐工作作出安排。校内有意向的教师须按函件要求准备相关材料，并于9月9日前报送人事处。

| 事项 | 内容 |
| --- | --- |
| 来函单位 | 广东省物价局 |
| 文号 | 粤价函〔2013〕752号 |
| 校内受理单位 | 汕头大学人事处 |
| 材料报送截止时间 | 2013年9月9日 |
| 报送要求 | 按函件要求准备并提交相关材料 |
| 联系人 | 余培松 |
| 电话 | 86503390 |
