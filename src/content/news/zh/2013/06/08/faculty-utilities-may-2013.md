据悉，汕头大学资源管理处已公布教职工 **2013年5月份水电费**。本次抄表时间为 **6月1日、2日**，上次抄表时间为 **5月1日**。相关教职工可登录汕头大学水电费管理系统 `http://power.stu.edu.cn` 查询个人费用。

如对费用有疑问或异议，可于 **6月8日至14日** 前往水电中心核查，联系电话为 `2489`。核查期限结束后仍未提出异议的，相关费用将按学校财务安排收取；具体缴费方式以校内财务安排为准。

| 项目 | 信息 |
| --- | --- |
| 费用月份 | 2013年5月 |
| 本次抄表 | 2013年6月1日、2日 |
| 上次抄表 | 2013年5月1日 |
| 查询方式 | 登录汕头大学水电费管理系统查询 |
| 异议核查时间 | 2013年6月8日至14日 |
| 核查地点 | 水电中心 |
| 联系电话 | `2489` |
| 缴费方式 | 相关费用按学校财务安排收取，具体方式以校内通知为准 |

本文不转载个人水电费金额、住房信息或其他个人财务资料。

> 来源：汕头大学 OA 通知（资源管理处）
