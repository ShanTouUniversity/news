据悉，汕头大学2013届毕业典礼将于6月28日在学校体育馆举行。学校党政办公室面向各单位邀请100名教职员工代表出席观礼，与毕业生共同见证毕业时刻。

有意参加观礼的教职员工可向所在学院办公室申领门票；其他教学、教辅单位的教职员工到教务处申领，行政后勤部门教职员工到工会申领。通知要求各单位于6月26日下午下班前派员到新行政楼237机要科领取门票。

## 观礼名额分配

| 单位 | 门票数量 |
| --- | ---: |
| 文学院 | 8张 |
| 法学院 | 8张 |
| 理学院 | 12张 |
| 工学院 | 12张 |
| 医学院 | 12张 |
| 商学院 | 8张 |
| 长江新闻与传播学院 | 6张 |
| 长江艺术与设计学院 | 8张 |
| 其他教学、教辅单位 | 10张 |
| 行政后勤部门 | 16张 |
