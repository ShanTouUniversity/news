据悉，汕头大学科学技术协会第十二届年度总结表彰暨第十三届执委会选举大会已于6月7日晚在E阶204教室举行。大会审议并通过了第十二届科协主席所作的年度工作报告，表彰了一批优秀干部和干事，并以差额选举方式产生了科协第十三届执行委员会委员。

新一届执委会由9名委员组成，具体名单如下：

| 姓名 | 年级专业 | 职务 |
| ---- | -------- | ---- |
| 钟YH | 11级机电 | 主席 |
| 许ZM | 11级计算机 | 副主席 |
| 蔡J | 11级经济 | 副主席 |
| 胡JQ | 12级生物 | 执委会委员 |
| 黄SQ | 12级土木 | 执委会委员 |
| 陈DC | 12级机电 | 执委会委员 |
| 张K | 12级土木 | 执委会委员 |
| 邓WJ | 12级电子 | 执委会委员 |
| 陈ZH | 12级机电 | 执委会委员 |

其中，钟YH当选为科协第十三届主席，许ZM、蔡J分别当选副主席。

本次换届由共青团汕头大学委员会与汕头大学科学技术协会共同发布结果，标志着科协完成新老交替，新一届执委会将接续开展科普活动等各项工作。

> 来源：汕头大学 OA 通知（共青团汕头大学委员会）
