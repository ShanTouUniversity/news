汕头市咫尺互动网络科技有限公司联合汕头大学工学院开展暑期实习活动，面向全校 **10、11级学生及表现优秀的12级学生** 招募实习生。岗位涉及软件开发与网页开发、界面交互设计和平面设计，实习地点为汕头大学789学生创业园，具体时间安排在暑假期间。

## 招聘信息

| 项目 | 内容 |
| --- | --- |
| 招聘单位 | 汕头市咫尺互动网络科技有限公司、汕头大学工学院 |
| 实习岗位 | 软件开发、网页开发；界面交互设计；平面设计 |
| 实习地点 | 汕头大学789学生创业园；附件进一步注明为7号楼 |
| 实习时间 | 暑假期间，期末考试后开始，实习时长1至2个月 |
| 招聘对象 | 全校10、11级学生及表现优秀的12级学生 |
| 报名截止 | 2013年6月28日 |
| 报名邮箱 | `zctech@foxmail.com` |
| 面试安排 | 根据报名情况另行通知 |

## 岗位与条件

MT企业创新俱乐部成员、在项目方面表现优秀的学生以及具有项目经验者优先考虑。申请人需根据意向岗位填写报名表；报名表涉及姓名、性别、学号、院系、年级、专业、电子邮件、联系电话、自我介绍和技能特长等个人信息，本文不转载这些字段或申请材料。

实习部门包括开发部和设计部。附件介绍，实习期间可获得三餐补贴、办公室食品、定期聚餐和宵夜，并可按实习情况提供实习证明；具体待遇以招聘单位最终安排为准。

## 公司简介

随附材料将公司描述为一家成立于2013年5月、集移动网络产品开发、互动电子产品设计、体感交互设备设计与销售以及物联网技术研究与开发于一体的创意技术企业。公司材料列出的代表作品包括投影互动系统MAIA、广告互动系统MAIA-I、会议互动系统MAIA-II和微信通，并称相关产品已在香港、汕头、广州和深圳等地推广，为室内活动、会议等提供人机互动解决方案。

通知正文将招聘单位称为“汕头市咫尺互动网络科技有限公司”，附件公司简介的名称写作“咫尺互动网络科技（汕头）有限公司”，本文保留这一来源中的名称差异。
