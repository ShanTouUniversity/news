据悉，汕头大学学位评定委员会于6月25日发布文件（汕大学位发〔2013〕04号），经第八届学位评定委员会第二次会议于6月19日审议，决定授予2013届符合条件的本科毕业生学士学位。

本次授予对象为德、体合格，完成教学计划各项要求并取得规定学分的毕业生，共1538名，具体分布如下：

| 类别 | 人数 |
| --- | --- |
| 文学学士（普通高等教育） | 374人 |
| 法学学士（普通高等教育） | 99人 |
| 管理学学士（普通高等教育） | 183人 |
| 理学学士（普通高等教育） | 153人 |
| 工学学士（普通高等教育） | 258人 |
| 经济学学士（普通高等教育） | 84人 |
| 医学学士（普通高等教育） | 256人 |
| 文学学士（成人高等教育） | 1人 |
| 法学学士（成人高等教育） | 3人 |
| 管理学学士（成人高等教育） | 33人 |
| 工学学士（成人高等教育） | 7人 |
| 医学学士（成人高等教育） | 47人 |
| 理学学士（成人高等教育） | 40人 |
| 双学士学位 | 2人 |

完整名单见 OA 附件。为保护学生隐私，本文不转载完整名单。
