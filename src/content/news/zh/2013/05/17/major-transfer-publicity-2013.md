根据《汕头大学本科学生学分制学籍管理暂行规定》（汕大发〔2005〕67号），汕头大学教务处对本学期申请转专业学生的考核结果及相关材料进行审核后，公示拟批准转专业名单。公示名单共涉及 **38人**。

为保护学生隐私，本文不转载学生姓名、性别、学号和原所在专业，仅按接收专业汇总拟转入人数：

| 接收专业 | 拟转入人数 |
| --- | ---: |
| 法学 | 2 |
| 市场营销 | 1 |
| 国际经济与贸易 | 2 |
| 工商管理 | 2 |
| 土木工程 | 6 |
| 计算机科学与应用 | 3 |
| 电子信息工程 | 2 |
| 通信工程 | 1 |
| 应用化学 | 5 |
| 应用物理学 | 1 |
| 数学与应用数学 | 1 |
| 汉语言文学 | 1 |
| 广播电视新闻学 | 2 |
| 新闻学 | 1 |
| 临床医学（五年制） | 6 |
| 护理学 | 2 |

原通知将异议反馈截止时间写为 **2012年5月23日前**，与2013年5月17日发布的公示日期不一致；具体截止时间应以教务处后续通知为准。异议可采用书面、来访或电话方式向教务处反映，联系电话为 `0754-82902402`，电子邮箱为 `o_jwc@stu.edu.cn`。
