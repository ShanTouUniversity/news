汕头大学招生办公室启动 2012 级本科新生招生工作调查，面向全校 2012 级本科生收集对招生工作的意见和建议，以进一步改进相关工作并提升本科生源质量。

学生须于 **2013年5月19日（星期日）前** 自行登录招生专题调查页面 [http://zs.stu.edu.cn/vote/Default.aspx](http://zs.stu.edu.cn/vote/Default.aspx)，如实填写并提交问卷。

### 调查激励

按时提交有效问卷的学生均可获得汕大风景明信片 1 张，并参加抽奖。抽奖奖品包括：

| 奖品 | 数量 |
| --- | ---: |
| 汕大风景卡片式U盘 | 50名 |
| “因你特别”T恤衫 | 70名 |
| “因你特别”Polo衫 | 60名 |

抽奖结果和领奖方式将通过办公信息网另行公布。调查问卷的具体填写内容不在本文转载。

| 项目 | 信息 |
| --- | --- |
| 调查对象 | 全校2012级本科生 |
| 调查目的 | 收集对学校招生工作的意见和建议 |
| 提交方式 | 登录招生专题调查页面在线填写 |
| 提交截止 | 2013年5月19日前 |
| 调查页面 | [zs.stu.edu.cn/vote/Default.aspx](http://zs.stu.edu.cn/vote/Default.aspx) |
| 组织部门 | 招生办公室 |
