据悉，汕头大学商学院团委会将于5月15日举办第三期“生命教育”体验式活动。

## 活动安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 体验式生命教育系列活动及生命教育案例分享交流 |
| 目的 | 帮助学生理解生命意义，认识并珍爱生命，尊重他人生命，思索自身价值与定位 |
| 对象 | 商学院全体2012级本科生 |
| 名额 | 50人 |
| 时间 | 2013年5月15日 |
| 地点 | 学生活动厅 |
| 主办单位 | 商学院团委会 |

活动分为体验式生命教育系列活动及生命教育案例分享与交流两个环节，要求学员严格遵守纪律、具备良好身体素质、着运动服与运动鞋，全程参与中等强度训练，不得请假，结束后需提交书面心得体会。

## 报名方式

| 事项 | 内容 |
| --- | --- |
| 名额分配 | 随机抽取25个名额优先，其余自愿报名超额抽签 |
| 报名截止 | 2013年5月13日前 |
| 报名方式 | 将报名信息发送至指定邮箱 |
| 发布单位 | 商学院团委会 |

报名邮箱等信息已作隐私保护不在此转载。
