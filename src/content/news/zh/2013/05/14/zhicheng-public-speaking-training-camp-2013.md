至诚书院将于 **2013年5月18日** 举办“公众口才演说”特训营，邀请公众演说教练、聚成股份汕头分公司总经理吴昊到校开展专业训练与指导。活动面向书院宿生及全校大三（含大三）以上学生，共招收 **70 名**。

### 活动安排

训练分为上午和下午两个时段，地点为 **科学报告厅 205 会议室**。其中书院宿生 55 名，其他宿区学生 15 名。参加者须确保训练期间没有其他课程或活动安排，并服从现场管理和训练要求。

| 项目 | 信息 |
| --- | --- |
| 活动 | “公众口才演说”特训营 |
| 时间 | 2013年5月18日（星期六）8:30—12:00、14:00—17:30 |
| 地点 | 科学报告厅205会议室 |
| 招收人数 | 70名 |
| 名额分配 | 书院宿生55名，其他宿区学生15名 |
| 参加对象 | 书院宿生；全校大三及以上学生 |
| 报名截止 | 2013年5月16日14:00 |
| 结果通知 | 录取结果通过邮件告知 |

### 教练简介

吴昊担任聚成咨询集团高级讲师、青年创业教练和企业家演讲教练，并为多家企业提供经营顾问服务。公开简介称，他有超过 500 场、1,000 小时以上的演讲经历，并曾为数百家企业提供诊断咨询。

### 报名方式

书院宿生通过各组织负责人报名；其他学生下载并填写 OA 附件中的报名表，将报名电子表格发送至 `ATP@stu.edu.cn`。报名文件须按通知要求标注年级、专业、姓名和宿舍等信息，具体格式以原通知为准。

报名表包含姓名、性别、宿舍、专业年级、学号、E-mail、手机号码、现任职务、政治面貌和学生干部经历等个人字段，本文不转载报名表或候选人资料。

| 报名对象 | 方式 |
| --- | --- |
| 书院宿生 | 通过各组织负责人报名 |
| 其他符合条件学生 | 填写 OA 报名表并发送至 `ATP@stu.edu.cn` |
| 截止时间 | 2013年5月16日14:00 |

通知强调，训练要求参加者积极进取、虚心学习、接受严格训练、服从指挥，并以合作和礼貌的态度参与活动。
