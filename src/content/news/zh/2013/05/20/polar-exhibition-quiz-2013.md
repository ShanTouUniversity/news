据悉，学生处于5月20日发布通知，将在5月下旬至6月底举办“极地、海洋、探险、文化知识资料展”和“海洋生物及探险装备展”期间，开展网络有奖知识问答活动。

## 展览与活动安排

| 事项 | 内容 |
| --- | --- |
| 展览主题 | 极地、海洋、探险、文化知识资料展；海洋生物及探险装备展 |
| 展览地点 | 图书馆与行政中心 |
| 展览时间 | 2013年5月下旬至6月底 |
| 问答题量 | 每个展览10道题，共20道题 |
| 参与对象 | 在校生 |
| 答题方式 | 扫描展板二维码进入答题网页，或直接访问 http://expedition.stu.edu.cn/exhibit/mobile.aspx |
| 抽奖方式 | 活动结束后从全部答对的学生中随机抽奖 |
| 奖品 | 南极科考探险项目精美纪念速干T恤1件 |
| 获奖人数 | 50名 |
| 截止时间 | 2013年6月25日24:00 |
| 发布单位 | 学生处 |

> ⚠️ 展板二维码及答题链接请前往 OA 系统查看原文。
>
> 来源：汕头大学 OA 通知（学生处）
