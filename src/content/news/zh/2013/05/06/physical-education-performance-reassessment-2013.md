汕头大学学校考核领导小组办公室发布通知，通报体育部 2011—2012 学年度部分教师绩效考核结果重新考核事项。根据汕头大学教职工申诉处理委员会决议，原相关考核结果被撤销，学校考核领导小组同意体育部重新考核。

体育部完成重新考核后，推荐 **张晓红** 和 **李岳进** 为 2011—2012 学年度考核优秀等次人选，现予公示。

### 公示信息

| 项目 | 内容 |
| --- | --- |
| 重新考核单位 | 体育部 |
| 学年度 | 2011—2012学年度 |
| 推荐人选 | 张晓红、李岳进 |
| 推荐等次 | 考核优秀等次 |
| 异议截止时间 | 2013年5月10日17:30前 |
| 依据 | 汕头大学教职工绩效考核办法（试行）第七章第二十九条 |
| 发布单位 | 学校考核领导小组办公室 |
| 发布日期 | 2013年5月6日 |

对重新考核结果有不同意见者，可在截止时间前依照相关办法提出书面申诉或投诉。通知未公布原被撤销结果人员的具体情况，本文不作补充推测。

> 来源：汕头大学 OA 通知（学校考核领导小组办公室、人事处）
