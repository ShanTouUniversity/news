为推进校务公开、民主管理和民主监督，汕头大学校务公开工作监督小组启动 **2012—2013 学年度校务公开事项落实情况检查**。检查对象为校本部各职能部门，重点是对照此前报送的校务公开事项登记内容，核对实际落实情况。

### 检查安排

| 项目 | 内容 |
| --- | --- |
| 检查对象 | 校本部各职能部门 |
| 检查年度 | 2012—2013学年度 |
| 核对依据 | 2012年10月报送的校务公开事项登记表 |
| 提交材料 | 校务公开检查情况及落实情况登记表 |
| 书面材料提交地点 | 监察审计处，新行政中心422室 |
| 电子材料发送至 | `o_jj@stu.edu.cn` |
| 截止时间 | 2013年5月17日前 |

各职能部门需核对相关事项是否已按要求公开；应公开但尚未公开的事项，应在备注中说明原因，新增公开事项也应作出标注。登记表模板设置了公开范围、公开形式和落实情况等栏目。

学校校务公开工作监督小组将汇总各部门的落实情况，并在校内办公信息网上公布，接受师生员工监督。附件为内部填报登记表，本文不转载其中的填表人联系方式、签字等填报字段。

### 检查结果公布

5月29日，学校公布了各职能部门 2012—2013 学年度校务公开事项落实情况汇总表。汇总内容涉及党政办公室、国际交流合作处、组织统战部、宣传部、校工会、监察审计处、人事处、财务处、教务处、科研处、学生处、校团委、招生办公室、研究生学院和资源管理处等部门。

汇总表按学生、社会、教职工等公开范围，记录各事项的公开形式和落实状态。公开渠道包括学校主页、校内办公信息网、部门网站、办公自动化系统、会议通报、信息查询系统、校园网以及政府采购和建设工程信息平台等。表中多数事项标注为已公开，同时对尚在审批、未实施、未报审及新增项目等情况作出备注。

公开事项覆盖学校基本情况与发展规划、干部人事和招聘、财务预算与收费、教学与学籍管理、科研项目、学生管理与资助、招生信息、研究生培养，以及基建工程和招投标等领域。涉及个人薪金、奖助学金和学生管理的信息，本文仅作制度和公开渠道层面的概述，不转载个人查询内容或名单。

师生员工如对校务公开事项有疑问，可向校务公开工作监督小组反映，电话 `86502346`，邮箱 `o_jj@stu.edu.cn`。

> 来源：汕头大学 OA 通知（监察审计处，5月6日检查通知）；汕头大学 OA 通知（校务公开工作监督小组，5月29日结果公布）
