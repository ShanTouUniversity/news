据悉，长江艺术与设计学院艺术教育中心“五彩缤纷艺术季·2013春”特邀台湾莎士比亚的妹妹们的剧团来校演出《爱爱》，并将举办戏剧创意工作坊《翻桌倒椅之一起爱爱》。

## 工作坊安排

| 事项 | 内容 |
| --- | --- |
| 主题 | 《翻桌倒椅之一起爱爱》戏剧创意工作坊 |
| 主讲嘉宾 | 台湾莎士比亚的妹妹们的剧团 |
| 时间 | 2013年5月29日15:00—17:00 |
| 地点 | 艺术教育中心一楼舞蹈排练厅 |
| 报名对象 | 全校学生，不限专业 |
| 报名截止 | 2013年5月22日09:00前 |
| 报名方式 | 发送姓名、性别、学院、年级及联系手机至 o_ysjyzx@stu.edu.cn，名额有限先到先得，必要时面试筛选 |
| 主办单位 | 长江艺术与设计学院、艺术教育中心 |

工作坊具体介绍见 OA 附件，已作隐私保护不在此转载。欢迎对戏剧表演有兴趣的同学报名参加。
