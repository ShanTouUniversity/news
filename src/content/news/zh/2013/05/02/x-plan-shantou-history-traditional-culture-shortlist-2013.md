汕头大学学生处公布学生社区 X 计划之汕头历史及传统文化探寻活动入围结果。通知称，截至 **4月27日** 共有 **26 个参赛团队** 报名，评委根据团队综合表现进行评选，最终有 **13 个团队** 入围下一阶段。

### 入围团队调研主题

附件同时列出入围团队的调研主题。为保护学生隐私，本文不转载团队名称中可能包含的个人姓名、负责人姓名、年级专业及其他个人信息，仅保留调研主题：

| 序号 | 调研主题 |
| ---: | --- |
| 1 | 老市区历史遗迹与风土人情 |
| 2 | 汕头嵌瓷文化 |
| 3 | 汕头佛教文化 |
| 4 | 潮汕拜老爷文化 |
| 5 | 陈慈黉故居 |
| 6 | 最汕头 |
| 7 | 老区足迹 |
| 8 | 汕头慈善文化探寻 |
| 9 | 红头船和英歌舞文化 |
| 10 | 追寻鮀城的足迹 |
| 11 | 小公园附近美食及建筑 |
| 12 | 妈祖文化探寻 |
| 13 | 潮州纪实 |

学生处请入围团队按照活动安排准备下一阶段工作。本次通知未重新说明后续时间、经费或评奖安排，具体事项应以活动主办方后续通知为准。
