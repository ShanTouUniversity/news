汕头大学公布 2013 年度先进本科教育教学改革专项立项结果，共确定 **172 个项目**。本次立项依据《汕头大学自主办学综合改革试点实施纲要（2009年—2017年）》，由各单位组织申报、教务处组织评审，旨在推进先进本科教育目标的落实。

### 立项类别

| 项目类别 | 数量 |
| --- | ---: |
| 专业综合改革试点 | 9个 |
| 特色专业 | 8个 |
| 人才培养模式创新实验区 | 2个 |
| 实验教学示范中心 | 5个 |
| 大学生实践教学基地 | 7个 |
| 教学团队 | 11个 |
| 精品精品视频公开课 | 1门 |
| 精品资源共享课 | 20门 |
| 教学改革研究项目 | 109个 |
| **合计** | **172个** |

### 经费与项目管理

首期资助经费按教改专项单位（学院、部、中心）下拨，额度为总经费的 50%。教务处根据项目类别和评审结果提出建议资助经费，并为各单位配套机动经费；各单位教改专项总负责人可结合工作任务对本单位各项目经费进行再次调配，确定最终资助安排。

获立项项目按照校级教学改革项目管理，接受阶段性检查和结题验收。教务处将根据不同研究期限适时组织检查与验收，阶段性检查合格的项目可获得第二期资助经费。

各项目负责人应依据立项承诺的预期成果目标，结合 2013 年先进本科教育工作任务推进改革与实践，重点涉及整合思维、可适应性专业培养、一体化专业培养、质量保障与持续改进等方向。
