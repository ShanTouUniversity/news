据悉，为深入贯彻关于建设海洋强国的重要论述，落实省委"1310"具体部署、推动广东省海洋经济高质量发展，省科技厅拟于近期开展2026—2027年度广东省重点领域研发计划"海洋科技"专项指南编制工作，现面向行业主管部门、企业、高校、科研院所等征集海洋领域关键核心技术攻关项目指南建议。汕头大学科研处于8月21日转发通知，组织校内征集工作。

## 征集背景

本次征集聚焦广东海洋经济高质量发展面临的堵点、难点问题，围绕前沿颠覆性技术、关键核心技术、关键零部件及装备研发与应用开展。

## 征集要求

指南建议应与产业实际紧密结合，聚焦本领域堵点、难点问题，满足以下四项要求：

| 序号 | 要求 | 说明 |
| --- | --- | --- |
| 1 | 有产业化价值 | 解决产业关键核心技术问题，确保3年内取得可实际应用的新材料、新产品、新工艺、新技术、新装备等成果 |
| 2 | 有广东省内研究基础 | 省内应有3家以上的科研机构或科技企业在该方向具备较高技术水平、创新能力和产业化条件 |
| 3 | 有技术先进性 | 对比国内外研究进展，确保技术就绪度提升3级以上，具备行业领先水平 |
| 4 | 有独特创新性 | 近3年广东省重点领域研发计划已支持过的攻关内容不再重复布局 |

## 征集范围

针对海洋经济高质量发展堵点和难点，聚焦以下领域：

| 领域 |
| --- |
| 海洋装备制造 |
| 深海探测 |
| 海洋电子信息 |
| 海洋生物技术 |
| 海洋资源开发利用 |
| 海洋防灾减灾 |
| 海洋生态环境保护 |
| 人工智能+海洋科学 |

涵盖上述领域的前沿颠覆性技术、关键核心技术、关键零部件及装备研发与应用。

## 征集内容

指南建议须包括以下要素，内容应言简意赅，避免繁冗：

- 指南建议名称、选题背景及必要性、研究内容、考核指标；
- 项目计划总投入和拟申请省财政资助金额；
- 项目可行性分析、项目预期成果及国内外研究进展对标情况；
- 有实力参与本项目竞争的其他团队情况、建议人（团队）情况、前期研究基础、依托单位情况；
- 部门（单位）科技业务处室联络员等信息。

其中，背景介绍应回答"为什么做"；研究内容需阐明做什么、解决什么问题；考核指标应为科学、量化的指标，避免笼统、宏观表述。
