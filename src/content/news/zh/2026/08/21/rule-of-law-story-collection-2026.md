据悉，根据《广东省教育厅关于开展"我与法治"故事征集活动的通知》，广东省教育厅定于2026年8至9月在全省开展"我与法治"故事征集活动。汕头大学党委学生工作部（学生处）联合法学院在校内组织开展征集工作，并于8月21日发布通知明确报送安排，校内报送截止时间为2026年9月1日。

## 活动主题与对象

| 事项 | 安排 |
| --- | --- |
| 主题 | "我与法治"，作品须符合国家法律法规和政策规定，内容真实、积极向上 |
| 省级活动时间 | 2026年8至9月 |
| 校内组织单位 | 党委学生工作部（学生处）联合法学院 |
| 活动对象 | 全校师生 |

## 内容要求

作品聚焦在学习成长、教育教学、依法治校、工作实践过程中学习法律知识、宣传法治文化、践行法治精神的生动故事，内容包括但不限于以下两组：

### 学生组（500—2000字）

- 学习宪法法律知识的心得体会与成长感悟；
- 参与"学宪法 讲宪法"活动、法治讲座、模拟法庭、法治社会实践等活动的经历与收获；
- 运用法治思维、法律知识维护自身或他人合法权益，解决学习生活中实际问题的真实案例；
- 在日常生活中自觉遵守法律法规、校纪校规，践行社会主义核心价值观的生动故事等。

### 教师组（含专任教师和普通教职工，1000—3000字）

- 开展法治教育教学的创新方法、典型案例与心得体会；
- 遵循教育规律，结合学生年龄特点，将社会主义法治理念融入教育教学实践的创新做法与成效；
- 指导学生参与"学宪法 讲宪法"活动或其他法治实践活动的工作案例与经验总结；
- 将法治教育融入学科教学、班级管理、校园文化建设等学校教育管理各方面的实践探索与成效；
- 自觉尊法学法守法用法，做学生法治素养的培育者、校园法治建设的推动者的故事等。

## 作品形式

| 要求 | 说明 |
| --- | --- |
| 体裁 | 不限 |
| 图文要求 | 需图文并茂，配故事相关清晰图片2至5张，单张大小500KB以内 |
| 简介与封面 | 附150字以内的内容简介和1张封面图（横版，500KB以内） |
| 作者信息 | 报送时需填写作者姓名、所在单位等基本信息 |

## 报送方式

各单位须广泛发动、积极创作，并做好报名推荐、遴选审核等工作，确保报送作品正确的政治方向和价值导向。

| 事项 | 安排 |
| --- | --- |
| 校内报送截止时间 | 2026年9月1日前，逾期不予受理 |
| 接收单位 | 法学院团委 |
| 接收邮箱 | o_fxytw@stu.edu.cn |
| 材料内容 | 作品电子版、简介及封面图等 |
| 命名规范 | X学院+"我与法治"故事材料 |

## 其他事项

- 参与作品应为2026年完成的原创作品，作者须拥有完整知识产权，不得抄袭、模仿，不得报送AI作品，一经查实将取消参与资格并通报选送单位或学校；
- 广东省教育厅对本次活动全部作品享有发表、出版、宣传等处置权，以及网络出版等其他版权；作品持有人享有署名权。
