据悉，为贯彻落实党的二十大精神及关于加强关键核心技术攻关的重要部署，按照省委、省政府关于科技创新的相关部署及《广东省重点领域研发计划"十五五"行动方案》，省科技厅现启动2027年度广东省重点领域研发计划"芯片设计与制造"专项项目申报工作。汕头大学科研处于8月21日转发通知，明确有关申报事项，网上集中申报时间至2026年9月16日。

## 申报指南获取

申报指南请登录"广东省科技业务管理阳光政务平台（http://pro.gdstc.gd.gov.cn）"查看，具体内容可到所在地科技主管部门或省科技厅查阅。

## 申报要求

### （一）申报单位

项目牵头申报单位须为省内注册、具有独立法人资格的企业、科研院所、高校、其他事业单位和行业组织等，以及港澳特区高等院校和科研机构。牵头单位应在该领域具有显著优势，具备较强研发实力或资源整合能力，承担核心研究组织任务。应注重产学研结合、整合省内外优势资源，优选合作单位，原则上同一项目牵头单位与参与单位总数不超过5家，任务分工须清晰明确，各参与单位均须承担实质性攻关任务。

### （二）经费预算

须认真做好经费预算、按实申报并符合指南要求。申报项目必须有自筹经费投入：

| 情形 | 自筹经费要求 |
| --- | --- |
| 指南明确须由企业牵头申报 | 项目总投入中自筹经费原则上不少于70% |
| 未明确须由企业牵头申报 | 项目总投入中自筹经费原则上不少于50% |

鼓励项目所在地市联合资助。各单位所分得财政资金应与承担任务量相适配，牵头单位原则上应分配最大财政资金份额，省外企业不参与分配财政资金。

### （三）限项要求

省重点领域研发计划申报单位总体不受在研项目数限项约束，但不鼓励同一团队或同一单位分散力量。在申报同一专项时，同一法人单位（高等院校除外）原则上只允许牵头及参与不超过3项；近三年年均研发费用不低于5000万元的高新技术企业可放宽至不超过6项（牵头不超过2项）。

### （四）项目负责人

项目负责人应统筹领导，原则上来自牵头单位，能实质性参与组织实施，防止挂名现象。确需由非牵头单位人员担任负责人的，须提供聘用协议、原单位同意函及本人（含团队）投入时间承诺函等佐证材料。

### （五）材料真实性

项目内容须真实可信，不得夸大实力与技术、经济指标。申报单位须对材料真实性负责，落实《科学技术活动违规行为调查处理规定》（科技部令第24号）和《广东省科学技术厅科技计划项目科研管理诚信管理办法》（粤科规范字〔2024〕2号），加强审核把关，杜绝弄虚作假。申报单位、项目负责人须签署《申报材料真实性承诺函》（模板可在阳光政务平台下载，须加盖公章）。项目一经立项，技术、产品、经济等考核指标无正当理由不予修改调整。

### （六）不得申报或不予通过资格审查的情形

有下列情形之一的项目负责人或申报单位不得申报或不通过资格审查：

1. 项目负责人有广东省级科技计划项目3项以上（含3项）未完成验收（平台类、普惠性政策类、后补助类除外）、有项目逾期一年未验收或当年度已申报2项；
2. 项目负责人有在研广东省重大科技专项项目、重点领域研发计划项目未完成验收（该负责人仍可作为参与人员）；
3. 同一项目通过变换课题名称等方式多头或重复申报；
4. 项目主要内容已由该单位单独或联合其他单位申报并已获得省科技计划立项；
5. 省内单位项目未经科技主管部门组织推荐；
6. 有尚在惩戒执行期内的科研严重失信行为记录、法院失信被执行人等"黑名单"记录；
7. 其他相关情形。

### （七）其他要求

申报项目须符合申报指南各专题方向的具体条件，科学研究须严格遵循技术标准和伦理规范，遵守国家法律法规。

## 申报方式

| 事项 | 安排 |
| --- | --- |
| 申报形式 | 在线申报、无纸化方式 |
| 申报平台 | 广东省科技业务管理阳光政务平台 http://pro.gdstc.gd.gov.cn |
| 账号开通 | 无系统账号的申请人请将姓名、所在部门、电子邮箱、手机号码发送至 o_kjxmptk@stu.edu.cn 开通 |
| 支撑材料 | 技术、财务、知识产权、合作协议、承诺函、推荐函等以附件形式上传；企业须上传上一年度企业所得税纳税申报表；牵头与参与单位存在关联关系的须如实说明并上传 |
| 线下申报 | 确有不宜通过网络提交的，由申报单位书面申请、经省科技厅审核后可线下申报 |
| 指南使用 | 指南文件仅供申报参考，不得转载发布 |
| 立项后材料 | 按程序立项后，项目申报书、任务书纸质件再一并报送至省科技厅综合业务办理大厅（均需签名、盖章，时间另行通知） |

项目评审评估过程中需提供书面材料的，由专业机构另行通知提交。

## 评审及立项说明

省重点领域研发计划项目由第三方专业机构组织评审，对背景、依据、技术路线、科研能力、时间进度、经费预算、绩效目标等进行评审论证，并开展技术创新就绪度和知识产权等专业化评估：

| 评估项 | 说明 |
| --- | --- |
| 技术创新就绪度 | 本专项主要支持技术就绪度3—6级的项目，项目完成时一般应达到7—9级，原则上提高3级以上。各单位应在可行性报告中阐述并提供佐证材料 |
| 查重及技术先进性分析 | 利用大数据技术对拟立项项目进行查重和先进性分析 |
| 知识产权分析评议 | 研究成果一般应有高质量知识产权，须按高质量知识产权分析评议指引提出高质量知识产权目标，并在可行性报告中阐述并提供佐证材料，勿简单以专利、论文数量作为目标 |
| 项目库管理 | 立项项目按程序审核报批后纳入项目库，视年度财政预算及落地情况分批出库支持，结合进展分阶段拨付资金 |
| 竞争择优原则 | 同一申报方向（或项目）如有效申报不足3家，视为竞争性不足，不进入评审、不予立项（指南有特殊说明除外）；达3家及以上经评审后原则上只立项支持1项 |

可行性报告提纲、高质量知识产权分析评议指引、技术创新就绪度相关说明等可在阳光政务平台系统下载查看。
