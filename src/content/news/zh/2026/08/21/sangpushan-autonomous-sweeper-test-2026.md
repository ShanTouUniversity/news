据悉，为推进校园保洁工作提质升级、检验无人化智能作业设备的可行性，汕头大学资源管理处于8月21日发布通知，将于近期在桑浦山校区开展无人清扫车现场应用测试。

## 测试安排

| 事项 | 安排 |
| --- | --- |
| 测试内容 | 无人清扫车现场应用测试 |
| 测试范围 | 桑浦山校区主干道路及人行道 |
| 测试时间 | 近期（具体时段以现场作业为准） |
| 发布单位 | 资源管理处 |
| 发布时间 | 2026年8月21日 |

## 注意事项

资源管理处提醒，为保障测试工作安全有序进行，过往师生需配合以下要求：

| 序号 | 要求 |
| --- | --- |
| 1 | 测试期间无人清扫车自动作业，请主动避让，与设备保持1—2米以上安全距离 |
| 2 | 禁止触摸、磕碰设备雷达、摄像头、操作按钮等部件，严禁私自操作、调试设备 |
| 3 | 设备作业期间请勿围观、追逐设备，严禁抛掷物品、阻挡设备行进，自觉爱护校园环境，积极配合测试工作 |
| 4 | 如发现设备故障或运行异常，切勿擅自处置，请及时向物业部门反馈 |
