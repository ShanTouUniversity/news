为保持校园建筑外墙整洁、提升校园整体形象，汕头大学资源管理处将于2026年8月3日至30日组织开展桑浦山校区部分建筑外墙清洗施工。施工将按建筑分时段进行，具体安排如下。

## 施工安排

| 建筑 | 计划施工时间 |
| --- | --- |
| 文科楼 | 8月5日至7日 |
| 长江新闻与设计学院 | 8月8日至10日 |
| 讲堂楼 | 8月11日 |
| 理科楼 | 8月12日至14日 |
| 工科楼 | 8月15日至17日 |
| 行政楼 | 8月18日至20日 |
| 学院实验楼 | 8月21日至24日 |
| 气膜篮球馆 | 8月25日 |
| E座教学楼 | 8月26日至27日 |
| 图书馆 | 8月28日至29日 |

## 施工期间安全提示

施工期间，过往人员和车辆应密切留意现场施工警示标识，按提示绕行，避免进入施工现场或在周边停留。遇到紧急情况，请及时联系现场工作人员。
