据悉，共青团汕头大学委员会于8月25日发布通知，启动中国青年志愿者第29届（汕头大学第1届）研究生支教团组建工作，全校范围内选拔志愿者赴新疆开展为期一年的基础教育服务。

## 招募背景

该项工作依据上级有关文件要求开展，遵循公开招募、自愿报名、择优选拔的原则。作为汕头大学首次组建研究生支教团，本届为中国青年志愿者第29届研究生支教团序列。

## 服务内容与地点

| 项目 | 安排 |
| --- | --- |
| 服务地点 | 新疆南疆地区，具体地点待定 |
| 服务期限 | 1年 |
| 主要任务 | 基础教育工作 |
| 拓展任务 | 乡村振兴、志愿服务等相关工作 |
| 兼职安排 | 可兼任所在乡镇、学校团委副书记 |

## 选拔名额

| 类别 | 名额 | 说明 |
| --- | --- | --- |
| 优秀应届本科毕业生 | 3名 | 服务期满后回校攻读本校研究生 |
| 在读研究生 | 不限名额 | 需经导师同意 |

学校遴选阶段拟确定入选3名、候补3名。

## 报名条件

申请人须同时满足以下基本条件：

- 优秀应届本科毕业生须符合《汕头大学推荐本科生免试攻读硕士学位研究生工作管理办法》第七条相关规定；在读研究生须经导师同意；
- 为共青团员，拥护党的领导，具备相应政治素养；
- 诚实守信，无考试作弊、剽窃他人学术成果记录，无违纪违法记录；
- 身心健康，能够胜任西部地区基础教育志愿服务工作。

在同等条件下，具备下列情形之一者优先考虑：

| 优先情形 |
| --- |
| 中共党员（含预备党员） |
| 担任过校级、院级或学生社团主要学生骨干 |
| 获得省市级以上"五四"表彰 |
| 已取得教师资格证或已报名参加教师资格考试 |
| 志愿服务经历丰富者 |

## 遴选程序

遴选分为本人申请、学院推荐、学校遴选及心理测评与体检等环节。

### 1. 本人申请

申请人按附件7要求准备相关材料，根据所在学院具体通知提交。需特别注意，研究生支教团专项推免与学院普通推免不得重复申报。

### 2. 学院推荐

由二级学院团组织对申请人进行考察，报学院研究生支教团招募工作小组审议，经学院党组织审批并公示不少于2天。公示无异议后，由学院统一报送材料。

| 事项 | 安排 |
| --- | --- |
| 公示时长 | 不少于2天 |
| 材料报送截止时间 | 9月7日前 |
| 电子版报送邮箱 | o_tw@stu.edu.cn |
| 纸质版报送地点 | 桑浦山校区行政中心223（校团委） |
| 报送主体 | 二级学院（不接受个人直接报送） |

### 3. 学校遴选

学校层面遴选包括资格复审、综合考察、公示等环节。

**综合考察计分方式：**

| 构成项 | 权重 | 说明 |
| --- | --- | --- |
| 综合考察分 | 85% | 含面试、专业能力等方面的综合考核 |
| 附加分 | 15% | 按相关加分细则认定 |

综合得分 = 综合考察分 × 85% + 附加分 × 15%

学校将根据综合得分排序，公示不少于3天后，组织心理测评与体检。心理测评或体检不合格者，从候补名单中按序递补。最终名单上报学校推免工作领导小组审定。名单一经上报，原则上不得无故放弃。

### 4. 心理测评与体检

入选及候补人员须按学校统一安排参加心理测评和体检。

## 政策保障

| 保障类别 | 具体政策 |
| --- | --- |
| 学籍与培养 | 应届本科毕业生保留1年研究生入学资格，在读研究生保留1年学籍；服务期间党团组织关系临时转至服务地 |
| 生活补助 | 服务期间按西部计划标准发放：西部地区每人每年3万元，南疆四地州每人每年4万元，按月发放生活补贴 |
| 社会保障 | 承担服务期间社会保险单位缴纳部分；统一购买重大疾病、人身意外伤害等商业保险 |
| 地区津贴 | 发放艰苦边远地区津贴 |
| 服务认定 | 服务期满经考核审定《研究生支教团志愿者服务鉴定表》，记入个人档案，并颁发志愿服务证书 |
| 荣誉表彰 | 服务期满考核合格者，授予"优秀共青团员"称号 |
| 基层就业奖励 | 按《汕头大学引导和鼓励毕业生面向基层就业奖励办法》，给予本科应届毕业生成员每人6000元奖励 |
