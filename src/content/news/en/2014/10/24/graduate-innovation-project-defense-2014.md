It is reported that the Graduate School of Shantou University will host an initial review and defense session for graduate innovation practice projects on October 29 in room G404, providing a阶段性 evaluation and guidance for each submitted project.

## Session Details

| Item | Details |
| --- | --- |
| Time | 3:00 PM, Wednesday, October 29, 2014 |
| Venue | G404 |
| Format | Project team PPT presentation + Q&A |

Each project team is required to prepare a 5- to 10-minute PPT presentation covering: project introduction, application rationale, implementation plan, distinctive features and innovations, budget, team member profiles, and expected outcomes. The review panel will provide comprehensive evaluations and improvement suggestions to help advance each innovation practice project.
