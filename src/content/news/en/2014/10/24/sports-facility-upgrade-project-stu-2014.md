It is reported that the Resource Management Office of Shantou University has announced the official launch of the STU Sports Facility Upgrade Project, supported by the Li Ka Shing Foundation. The project will comprehensively upgrade multiple sports facilities across campus to improve the exercise experience for faculty and students.

## Renovation Scope

| Facility | Renovation |
| --- | --- |
| Outdoor basketball courts | 8 courts, install sport-specific modular flooring |
| Tennis courts | 2 courts, install sport-specific modular flooring |
| Volleyball courts | 3 courts, install sport-specific modular flooring |
| Football pitch | 1 sand pitch converted to artificial turf |
| Lighting system | Install high-efficiency energy-saving lighting |
| Other | Redesign fencing and install card-access management system |

According to organizers, the upgrade aims to enhance both the safety and usability of campus sports facilities, better serving daily exercise needs and sports event hosting. The renovated venues will be fully open to faculty and students upon completion.
