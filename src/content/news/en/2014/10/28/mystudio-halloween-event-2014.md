It is reported that MYSTUdio of the Network and Information Center will host a Halloween event on the evening of Friday, October 31, from 7:30 to 9:00 PM at MYSTUdio.

## Event Details

| Item | Details |
| --- | --- |
| Time | 19:30–21:00, Friday, October 31, 2014 |
| Venue | MYSTUdio |
| Places | First 50 registered students |
| Dress Code | Costumes required (Halloween theme) |
| Activities | Games, prize distribution, Best Costume Award |
| Organizer | MYSTUdio |
| Registration Deadline | October 30, 2014 |

The event features multiple interactive games with prizes for participants. A Best Costume Award will also be presented to encourage creativity in dress-up. As the event coincides with Halloween, all participants are required to come in costume.

> Source: STU OA Notice (Network and Information Center)
