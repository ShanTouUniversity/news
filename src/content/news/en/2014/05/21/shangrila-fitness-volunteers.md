It is reported that a physical fitness test is being organized for Shantou University's "Return to Shangri-La" intermediate outdoor development program, and the university's Snow Leopard Outdoor Association is recruiting student volunteers to assist with the first round of fitness selection.

## How to Apply

Applicants should download the application form and rename the file using the format "grade + major + name" (for example, "2013 Law Li M — 2014 STU Snow Leopard Outdoor Association Summer Yunnan Shangri-La Project First-Round Fitness Selection Volunteer Application Form"), then send the completed electronic copy to the association's email address at snowleopardstu@163.com.

| Item | Details |
| --- | --- |
| Program | "Return to Shangri-La" intermediate outdoor development project |
| Position | First-round fitness selection volunteer |
| Application email | snowleopardstu@163.com |

Details such as the number of openings, working hours, duties and benefits are set out in the original notice and its attachments. Students who wish to learn more about the program can also follow the association's Weibo account for updates.

> Source: STU OA Notice (Student Affairs Office)
> ⚠️ The registration QR code and event attachments are available on the OA system.
