To support the Ministry of Finance requirement that universities implement a new higher-education accounting system from 2014, Shantou University\'s Finance Office upgraded the supporting financial query system. Units and project leaders at the main campus could use the system according to the new login and user guide.

Questions about using the upgraded query system could be directed to the Finance Office at 86503358 or 86502446.

> ⚠️ The upgraded system's login and user guide are available in the OA attachment.
