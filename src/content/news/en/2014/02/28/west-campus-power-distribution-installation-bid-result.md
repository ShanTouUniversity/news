Shantou University’s Infrastructure Construction Office published the bidding result for the west campus power supply and distribution facilities installation project on February 28. Following the recommendation of the university’s Tendering and Bidding Leading Group, the Shantou Branch of Guangdong Runmin Jian’an Engineering Co., Ltd. was selected as the winning bidder. The bid amount was RMB 534,229.50 after deducting RMB 103,635 for an optional project.

## Bid Information

| Item | Details |
| ---- | ------- |
| Project | STU west campus power supply and distribution facilities installation |
| Winning bidder | Guangdong Runmin Jian’an Engineering Co., Ltd., Shantou Branch |
| Bid amount | RMB 534,229.50, after deducting RMB 103,635 for an optional project |
| Publicity period | February 28 to March 3, 2014 |
