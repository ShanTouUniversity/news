Shantou University’s Infrastructure Construction Office published the bidding result for the campus project to remove and install steel doors and aluminum window sashes on February 28. Following the recommendation of the university’s Tendering and Bidding Leading Group, Shantou Donghua Construction Co., Ltd. was selected as the winning bidder, with a bid amount of RMB 20,506.

## Bid Information

| Item | Details |
| ---- | ------- |
| Project | Campus steel door and aluminum window sash removal and installation |
| Winning bidder | Shantou Donghua Construction Co., Ltd. |
| Bid amount | RMB 20,506.00 |
| Publicity period | February 28 to March 3, 2014 |

## Contact Information
