Shantou University’s Infrastructure Construction Office published the bidding result for the construction and installation of steel railings along the drainage ditch on February 28. Following the recommendation of the university’s Tendering and Bidding Leading Group, Shantou Yueli Building Decoration Engineering Co., Ltd. was selected as the winning bidder, with a bid amount of RMB 48,800.

## Bid Information

| Item | Details |
| ---- | ------- |
| Project | Drainage ditch steel railing construction and installation |
| Winning bidder | Shantou Yueli Building Decoration Engineering Co., Ltd. |
| Bid amount | RMB 48,800.00 |
| Publicity period | February 28 to March 3, 2014 |

## Contact Information
