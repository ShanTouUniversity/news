It is reported that the Academic Affairs Office issued a notice on September 19, 2014, to begin registration for the second 2014 National College Computer Proficiency Exam of this semester.

## Exam Details

| Item | Details |
| --- | --- |
| Exam time | From 08:00, January 3, 2015, in batches; 105 minutes per subject per batch |
| Format | Computer-based online exam |
| Subjects | Level 1: Computer Application (2010); Level 2: Visual Basic Programming, Visual FoxPro Programming, C++ Programming, Access Database (2003), Photoshop Image Processing, Web Production Basics, Flash Animation, Office 2010 Advanced Applications, Java Programming, E-Commerce (up to two subjects per candidate, across levels allowed) |
| Registration period | September 19 – October 7, 2014 |
| How to register | Log in to the credit system: My Course Selection → Qualification Exam Registration |
| Fee | 38 yuan per person per subject |
| Payment | Deducted from the campus card account on October 8 by the Finance Office via the Network Center; insufficient balance will result in registration failure |
| Issued by | Academic Affairs Office |

> Source: STU OA Notice (Academic Affairs Office)
