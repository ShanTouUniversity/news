It is reported that the Shantou University Library has launched a trial service for the Chaoxing "Chinese Discovery System," and all faculty and students are welcome to try it.

## System Overview

| Item | Details |
| --- | --- |
| System Name | Chaoxing "Chinese Discovery System" |
| Trial Start | Available from today |
| Data Coverage | Chinese books, journals, papers, newspapers, standards, patents, videos and more |
| Key Features | Daily updated metadata indexing; integrated with the Library OPAC catalog system and Duxiu full-text service |

The system uses internet search engine technology to comprehensively index metadata from diverse Chinese resource types — including books, journals, academic papers, newspapers, standards, patents and videos — with daily updates. Search results are linked to the Library's OPAC catalog system and the Duxiu full-text service, providing a one-stop Chinese academic resource discovery experience.
