It is reported that the Academic Affairs Office of Shantou University will organize a review of undergraduate innovation and entrepreneurship training program projects **launched in 2012 with an 18-month duration**, combining written materials with a public defense.

According to the arrangements, each project team must submit written materials in triplicate to the Academic Affairs service window on the third floor of the New Administrative Center **by December 6, 2013**, and send an electronic version identical to the paper copies to yjguo@stu.edu.cn. Electronic files should be named in the format "school - project number - project leader's name" (for example, "College of Liberal Arts - 1056011001 - Zhang San").

The public defense is scheduled for **December 18, 2013**, with specific times, venues, and group assignments to be announced later.

Key arrangements:

| Item | Details |
| ---- | ---- |
| Scope | 2012 projects with an 18-month duration |
| Format | Written materials + public defense |
| Material deadline | By Dec 6, 2013, in triplicate |
| Submission point | Service window, 3rd floor, New Administrative Center |
| Electronic version | Sent to the designated email, named per convention |
| Public defense | Dec 18, 2013 |

> Source: STU OA Notice (Academic Affairs Office)
> ⚠️ Review forms and related attachments are available on the OA system.
