It is reported that the Academic Affairs Office has issued a notice launching registration for this semester's National College Computer Proficiency Examination, with online registration open from September 13 to October 7 through the credit-based system.

## Exam Details

| Item | Details |
| --- | --- |
| Exam date | From 08:00 on December 28, 2013, in batches, with each subject lasting 105 minutes in every batch |
| Format | Computer-based network examination |
| Subjects | Level 1: Computer Applications; Level 2: Visual Basic Programming, Visual FoxPro Programming, C++ Programming, Access Database (2003), Photoshop Image Processing and Production, Web Page Production Basics, Flash Animation Production, Java Programming |
| Subject limit | Each candidate may register for up to two subjects per exam, at the same or different levels |
| Registration period | September 13 – October 7, 2013 |
| How to register | Online through the credit-based system (My Course Selection → Qualification Examination Registration) |
| Fee | 38 yuan per person per subject |
| Payment | The Finance Office, through the Network Centre, will deduct the fee from registrants' campus card accounts on October 8; registrants should keep sufficient balance in advance, and an unsuccessful deduction will result in registration failure |

> Source: STU OA Notice (Academic Affairs Office)
