It is reported that the system check for the second half of 2013 National Computer Proficiency Test is approaching. The university will open the E-building computer labs for system practice starting 4:00 PM on December 25, on a first-come, first-served basis.

## Check Schedule

| Item | Details |
| --- | --- |
| Official Exam Date | Morning of December 28, 2013 (batched) |
| System Check Opens | December 25, 4:00 PM |
| Location | E-building computer labs |
| Allocation Principle | First come, first served |
| Language Labs | E101: Access Database (2003) / Computer Applications (2003), etc. |

Students are encouraged to familiarize themselves with the exam system in advance to ensure a smooth testing experience.

> Source: STU OA Notice (Academic Affairs Office)
