It is reported that the Network and Information Center issued a notice on April 19, 2013, that new features for the MYSTU teaching platform have been released.

## New Features

| Feature | Details |
| --- | --- |
| New feature introduction | Available via the page title bar, with introductions and tutorial videos on new features and operations |
| Advanced Activities | Added to the “My Courses” preparation page, allowing teachers to add “Tags,” launch “Votes,” and enrich course activities |
| Help page | Updated with tutorial videos for each module and answers to frequently asked questions |

The center asked users to inform each other. For questions during use, contact 0754-86503400-5 or help@stu.edu.cn.

> Source: STU OA Notice (Network and Information Center)
