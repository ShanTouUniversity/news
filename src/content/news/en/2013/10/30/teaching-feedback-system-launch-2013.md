The Academic Affairs Office at Shantou University announced on October 30 that the credit system now features an "In-Semester Teaching Feedback" function. The tool allows students to anonymously submit teaching suggestions and feedback, while teachers can view and respond interactively — giving students a voice and helping instructors better understand learner needs to improve classroom outcomes. The feature will remain active through Week 14.

Student navigation: Credit System → Course Evaluation → In-Semester Teaching Feedback → Select course → Submit message.
Teacher navigation: Credit System → Course Evaluation → In-Semester Teaching Feedback → View student feedback → Click reply.

| Role | Navigation Path |
|------|-----------------|
| Student | Credit System → Course Evaluation → In-Semester Teaching Feedback → Select course → Submit message |
| Teacher | Credit System → Course Evaluation → In-Semester Teaching Feedback → View feedback → Click reply |
| Availability | Through Week 14 |

> Source: STU OA Notice (Academic Affairs Office)
