It is reported that Shantou University’s Network and Information Center has completed the first phase of the campus cloud desktop application system and opened it for trial use by all faculty, students, and staff. Based on server virtualization, the system provides virtual cloud desktops, virtual applications and personal data storage, with 50 GB of storage available for each user.

## Available Services

Users may choose one of three desktop types when applying: dedicated, static or dynamic. The available operating systems are Chinese Windows 7, English Windows 7, Chinese Windows XP and English Windows XP. Because hardware resources are currently limited, each user may apply for only one virtual desktop.

## Application and Allocation

| Item | Details |
| --- | --- |
| Trial users | All faculty, students, and staff |
| Application | Sign in with a campus network account and password at [cloud.stu.edu.cn](http://cloud.stu.edu.cn) to apply online |
| User guide | [cloud.stu.edu.cn/help.aspx](http://cloud.stu.edu.cn/help.aspx) |
| Responsible unit | Network and Information Center |

For approval and resource allocation, priority is given to frontline teaching and research faculty who need the service for classroom teaching and preparation. Foreign faculty members teaching in multimedia classrooms receive first priority and are assigned static desktops in principle. University faculty members teaching in multimedia classrooms receive second priority; static desktops are allocated where possible, and dynamic desktops are assigned when static capacity is insufficient. Other users generally receive dynamic virtual desktops in the order applications are received. Applications for static and dedicated desktops are reviewed according to these allocation principles.
