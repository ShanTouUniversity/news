It is reported by the Network and Information Center that the server IP address of the office automation system has been switched to 192.168.48.5.

If the document client cannot find the database after logging in, users should follow these steps: in the client menu, select File > Database > Open, and enter the domain name notes.stu.edu.cn or 192.168.48.5 in the server address field to locate the Notes database.

> Source: STU OA Notice (Network and Information Center)
