It is reported that the Labor Union of Shantou University has announced that, at the request of many pilates enthusiasts, the Wednesday and Friday pilates training classes will continue this semester, with a new Monday session added. Classes are held Monday, Wednesday and Friday from 17:35 to 18:35.

| Item | Details |
|------|---------|
| Program | Pilates Training Class |
| Sessions offered | Monday (new), Wednesday, Friday |
| Class time | Mon/Wed/Fri 17:35–18:35 |
| First Monday class | February 27, 2012 |
| First Wednesday class | February 29, 2012 |
| First Friday class | March 2, 2012 |
| Returning students deadline | February 28, 2012 |
| Monday class registration deadline | February 27, 2012, 12:00 |
| Registration phone | 2654 (campus short no. 678222) |
| Issued by | Labor Union |

Space is limited and enrollment is on a first-come, first-served basis. Returning participants should confirm their session by the deadline. Those who need to change or cannot attend should notify the association in advance.

> Source: STU OA Notice (Labor Union)
