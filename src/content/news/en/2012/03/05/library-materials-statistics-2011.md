It is reported that the annual statistics work on university library materials for 2011 has commenced. To advance the effort, the Shantou University Library issued work arrangements to all reading rooms (resource rooms) on the main campus on March 5.

According to the arrangements, each reading room must complete its library materials data using the attached form and send the filled-in form to the Library's designated email address, gnweng@stu.edu.cn, by March 15, after which the Library will compile and report the figures.

| Item | Details |
| ---- | ---- |
| Task | 2011 annual university library materials statistics |
| Units involved | Reading rooms on the main campus |
| Reporting requirement | Fill in data according to the attached form |
| Deadline | By March 15 |
| Submission | Send to the Library's designated email |

The statistics form part of the provincial annual survey of university library materials, and the relevant forms can be obtained from the Library.
