Shantou University Library is offering trial access to the PressDisplay global newspaper database for readers across the university. The database provides more than 2,200 digitized newspapers and other prominent publications from 95 countries in 55 languages, including Chinese, English, Russian, German, Japanese, and Korean. Readers can access daily updated newspaper content on the platform.

| Item | Details |
| --- | --- |
| Database | PressDisplay global newspaper database |
| Coverage | More than 2,200 publications from 95 countries in 55 languages |
| Content feature | Daily access to updated digital newspaper content from around the world |
| Trial end date | December 31, 2012 |
| Access | <http://www.lib.stu.edu.cn/dbdetail.aspx?id=359> |
| Feedback | Library Subject Services, 86503247 |

The library welcomes students and faculty members to use the database during the trial and to send evaluations and comments to its Subject Services team.
