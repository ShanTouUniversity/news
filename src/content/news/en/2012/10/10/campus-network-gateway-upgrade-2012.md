It is reported that the Network and Information Center issued a notice on October 10, 2012, that gateway equipment and storage systems will be upgraded as part of the campus network upgrade plan.

| Item | Details |
| --- | --- |
| Upgrade | Campus network gateway and storage system upgrade |
| Impact time | 00:00–06:00, October 11, 2012 |
| Impact scope | Internet access for all campus network users and key campus systems such as email |
| Recovery | No further notice will be issued |
| Contacts | Phone 0754-82903413-100 / 86503400 (883400), mobile 13592895188 (665188), email stunic@stu.edu.cn |
| Issued by | Network and Information Center |

Users are asked to inform each other and apologize for any inconvenience.
